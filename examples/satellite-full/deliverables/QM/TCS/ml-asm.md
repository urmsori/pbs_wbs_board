# MLI 단열재 (QM/TCS) — 조립체 산출물

잎 Work들이 결과를 한 줄씩 덧붙이고, 조립체 취합 Work가 판정을 남긴다.

- [QM-TCS-ML-01] 설계 갱신 완료 — 설계 파라미터 업데이트 완료
- [QM-TCS-ML-02] 인증부품 구매 완료 — 부품 공급처 확보 완료
- [QM-TCS-ML-03] 입고 검사 완료 — 입고 완료 및 품질 확인 OK
- [QM-TCS-ML-04] 제작 완료 — 기계 가공/제조 완료
- [QM-TCS-ML-05] 조립 완료 — 부품 조립 완료
- [QM-TCS-ML-06] 워크맨십 검사 완료 — 육안 검사 완료 — 결함 없음
- [QM-TCS-ML-07] 진동시험 완료 — 진동 시험 통과 — 1.5g 범위 내
- [QM-TCS-ML-08] 충격시험 완료 — 충격 시험 통과 — 최대 25g
- [QM-TCS-ML-09] 열진공시험 완료 — TVAC 통과 — -40~+85°C, 배출가스 OK
- [QM-TCS-ML-10] EMC 시험 완료 — EMC 시험 통과 — 복사 간섭 < -20dBm
- [QM-TCS-ML-11] 수명·번인시험 완료 — 번인 시험 통과 — 1000시간 무고장
- [QM-TCS-ML-12] 비적합 처리 완료 — NCR 처리 완료
- [QM-TCS-ML-13] 시험데이터 분석 완료 — 데이터 분석 및 리포트 작성 완료
- [QM-TCS-ML-14] 인증검토 자료 완료 — CDR 자료 준비 완료
- [QM-TCS-ML-15] 형상문서 갱신 완료 — 형상 관리 갱신 완료
- [QM-TCS-ML-16] 인증보고 완료 — 인증 보고서 제출 완료
