# EM 탑재컴퓨터(OBC) 취합 산출물

조립체 6건의 판정을 취합해 서브시스템 단위 결과를 정리한다.

| 조립체 | 판정 | 비고 |
|---|---|---|
| EM-OBC-PR (프로세서보드) | 합격 | 클럭 1200MHz 성능 목표 충족 |
| EM-OBC-MM (대용량메모리) | 합격 | 메모리 2GB 용량·무결성 확인 |
| EM-OBC-IO (IO보드) | 합격 | 외부 인터페이스 I/O 안정화 확인 |
| EM-OBC-WD (감시회로) | 합격 | 워치독 타임아웃 500ms 이상 감지 확인 |
| EM-OBC-SW (비행소프트웨어) | 합격 | 소프트웨어 검증 및 기능시험 완료 |
| EM-OBC-BP (백플레인) | 합격 | 커넥터·전원/신호 배분 무결성 확인 |

## 서브시스템 소견

프로세서·메모리·IO·워치독·소프트웨어·백플레인 6개 조립체가 각각 잎 Work 14건을 전부 완료했고, 조립체 취합에서도 전원·신호·인터페이스 간 정합성에 이상이 발견되지 않았다. 서브시스템 내부 상호 인터페이스(프로세서-메모리 버스, IO-백플레인 커넥터)에서 상충 없이 EM 결과보고까지 도달했다.

판정: **합격**
