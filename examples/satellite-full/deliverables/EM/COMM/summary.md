# EM 통신계(COMM) 취합 산출물

조립체 6건의 판정을 취합해 서브시스템 단위 결과를 정리한다.

| 조립체 | 판정 | 비고 |
|---|---|---|
| EM-COMM-AN (안테나) | 합격 | 링크마진 +1.9 dB, 데이터율 1.4 Mbps |
| EM-COMM-DP (다이플렉서) | 합격 | 대역 격리·삽입손실, 링크마진 +2.6 dB |
| EM-COMM-LG (저이득안테나) | 합격 | 전방향 커버리지, 링크마진 +4.1 dB |
| EM-COMM-RF (RF케이블) | 합격 | 경로 손실 관리 범위 내, 링크마진 +4.1 dB |
| EM-COMM-TR (S대역 트랜시버) | 합격 | 송수신 성능, 링크마진 +4.1 dB |
| EM-COMM-TX (고속송신기) | 합격 | 출력 전력·데이터율 1.4 Mbps, 링크마진 +4.1 dB |

## 서브시스템 소견

6개 조립체가 모두 잎 Work 14건을 완료했으며, 안테나 계열은 +1.9~+4.1 dB 범위의 링크마진을 확보해 데이터율 1.4 Mbps 목표를 안정적으로 충족한다. AN의 마진이 상대적으로 낮으나 여전히 양(+)의 여유를 갖고 있어 취합 판정에 영향을 주지 않는다.

판정: **합격**
