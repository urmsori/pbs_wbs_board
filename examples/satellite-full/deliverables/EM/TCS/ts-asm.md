# 서미스터 (EM/TCS) — 조립체 산출물

잎 Work들이 결과를 한 줄씩 덧붙이고, 조립체 취합 Work가 판정을 남긴다.

- [EM-TCS-TS-01] 요구 할당 완료 — 센서 범위 -50~100°C, 정밀도 ±2°C 할당
- [EM-TCS-TS-02] 개념 설계 완료 — Pt100 저항식 센서 4개 배치안
- [EM-TCS-TS-03] 상세 설계 완료 — 센서 배선 실드선 상세설계
- [EM-TCS-TS-04] 구조·강도 해석 완료 — 센서 프로브 인장강도 280MPa 확인
- [EM-TCS-TS-05] 열 해석 완료 — 센서 응답시간 2.3초 확인
- [EM-TCS-TS-06] 부품 선정 완료 — Pt100 1/3 DIN 센서 4개 선정
- [EM-TCS-TS-07] 인터페이스 정의 완료 — 센서 출력신호 4-20mA, 응답 1Hz
- [EM-TCS-TS-08] 시제 제작 완료 — 센서 4개 교정 및 패키징 완료
- [EM-TCS-TS-09] 기능시험 절차 완료 — 센서시험 절차 10개: 정확도, 응답시간
- [EM-TCS-TS-10] 기능시험 완료 — 센서 정확도 ±2°C 이내 확인
- [EM-TCS-TS-11] 성능 측정 완료 — 센서 정밀도 ±1.5°C 측정 완료
- [EM-TCS-TS-12] 문제점 조치 완료 — 발견 이슈 2건(교정, 응답) 조치 완료
- [EM-TCS-TS-13] 설계검토 자료 완료 — PDR 자료 7건 완성: 교정증명서
- [EM-TCS-TS-14] EM 결과보고 완료 — EM 최종결과 발행: 인증 획득
