# 온도조절기 (EM/TCS) — 조립체 산출물

잎 Work들이 결과를 한 줄씩 덧붙이고, 조립체 취합 Work가 판정을 남긴다.

- [EM-TCS-TC-01] 요구 할당 완료 — 제어 정확도 ±1°C, 응답시간 5초 할당
- [EM-TCS-TC-02] 개념 설계 완료 — 피드백 제어루프 게인 조정안
- [EM-TCS-TC-03] 상세 설계 완료 — PID 제어루프 상수값 결정
- [EM-TCS-TC-04] 구조·강도 해석 완료 — 제어기 마운트 응력 안전계수 2.5
- [EM-TCS-TC-05] 열 해석 완료 — 제어부 정상상태 온도 35°C 이하
- [EM-TCS-TC-06] 부품 선정 완료 — 32bit ARM 제어기 및 SSR 10개 선정
- [EM-TCS-TC-07] 인터페이스 정의 완료 — 제어신호 CAN버스 500kbps 정의
- [EM-TCS-TC-08] 시제 제작 완료 — 제어기 기판 조립 및 프로그래밍 완료
- [EM-TCS-TC-09] 기능시험 절차 완료 — 제어시험 절차 15개: 기능, 정확도, 반응
- [EM-TCS-TC-10] 기능시험 완료 — 제어정확도 ±1°C 달성 확인
- [EM-TCS-TC-11] 성능 측정 완료 — 제어정밀도 ±0.8°C 측정 완료
- [EM-TCS-TC-12] 문제점 조치 완료 — 발견 이슈 4건(소프트웨어) 조치 완료
- [EM-TCS-TC-13] 설계검토 자료 완료 — PDR 자료 12건 완성: 회로도, 펌웨어
- [EM-TCS-TC-14] EM 결과보고 완료 — EM 최종보고서 발행: 통합 합격
