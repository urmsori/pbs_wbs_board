# EM 탑재체(PAY) 취합 산출물

조립체 6건의 판정을 취합해 서브시스템 단위 결과를 정리한다.

| 조립체 | 판정 | 비고 |
|---|---|---|
| EM-PAY-CM (광학카메라) | 합격 | 해상도·광학계 정렬 확인 |
| EM-PAY-FC (포커스기구) | 합격 | 구동 정밀도·반복 위치결정 확인 |
| EM-PAY-DT (검출기) | 합격 | 감도·신호 대 잡음비 확인 |
| EM-PAY-IP (영상처리보드) | 합격 | 처리 속도·인터페이스 정합 확인 |
| EM-PAY-DC (데이터압축기) | 합격 | 압축률·처리 지연 확인 |
| EM-PAY-CL (교정장치) | 합격 | 기준광원 정밀도·교정 절차 확인 |

## 서브시스템 소견

카메라·포커스기구·검출기·영상처리보드·데이터압축기·교정장치 6개 조립체가 잎 Work 14건씩 전부 완료했다. 광학계(CM·FC)에서 검출기(DT)로, 다시 영상처리보드(IP)·데이터압축기(DC)로 이어지는 영상 처리 체인이 EM 최종보고서까지 일관되게 확인되었고, 교정장치(CL)가 전체 계통 교정을 뒷받침한다.

판정: **합격**
