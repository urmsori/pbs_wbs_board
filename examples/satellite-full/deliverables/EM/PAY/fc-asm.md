# 포커스기구 (EM/PAY) — 조립체 산출물

잎 Work들이 결과를 한 줄씩 덧붙이고, 조립체 취합 Work가 판정을 남긴다.

- [EM-PAY-FC-01] 요구 할당 완료 — 해상도 0.5m, MTF 0.65, SNR 45dB 목표 설정
- [EM-PAY-FC-02] 개념 설계 완료 — 개념 선정 완료 (고정식 카메라, 3개 소자)
- [EM-PAY-FC-03] 상세 설계 완료 — 광학 설계 최종화, 렌즈 배치 완료
- [EM-PAY-FC-04] 구조·강도 해석 완료 — 최대응력 125MPa (여유율 1.8×)
- [EM-PAY-FC-05] 열 해석 완료 — 최고온 42°C, 최저온 -15°C (제어 범위)
- [EM-PAY-FC-06] 부품 선정 완료 — 동급 부품 6개 선정 완료
- [EM-PAY-FC-07] 인터페이스 정의 완료 — 전기, 기계, 광학 인터페이스 정의됨
- [EM-PAY-FC-08] 시제 제작 완료 — 시제 조립 완료, 무게 285g
- [EM-PAY-FC-09] 기능시험 절차 완료 — 시험 절차 문서 승인
- [EM-PAY-FC-10] 기능시험 완료 — 모든 기능시험 통과
- [EM-PAY-FC-11] 성능 측정 완료 — 해상도 0.48m, MTF 0.68, SNR 47dB
- [EM-PAY-FC-12] 문제점 조치 완료 — 발견된 2개 이슈 조치 완료
- [EM-PAY-FC-13] 설계검토 자료 완료 — PDR 자료 작성 완료
- [EM-PAY-FC-14] EM 결과보고 완료 — EM 최종보고서 제출
