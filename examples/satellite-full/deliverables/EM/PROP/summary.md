# EM 추진계(PROP) 취합 산출물

조립체 6건의 판정을 취합해 서브시스템 단위 결과를 정리한다.

| 조립체 | 판정 | 비고 |
|---|---|---|
| EM-PROP-TK (추진제탱크) | 합격 | 구조강도·내압 2.5 bar 건전성 확인 |
| EM-PROP-PL (배관) | 합격 | 내압·누설 시험 2.5 bar 통과 |
| EM-PROP-VV (밸브) | 합격 | 개폐 응답·기밀 유지 확인 |
| EM-PROP-FV (충전밸브) | 합격 | 기밀성·충전압 2.5 bar 유지 |
| EM-PROP-PS (압력센서) | 합격 | 측정 정확도·계통압 추종 확인 |
| EM-PROP-TH (추력기) | 합격 | 목표 추력 150 mN 확인 |

## 서브시스템 소견

탱크·배관·밸브·충전밸브·압력센서·추력기 6개 조립체가 잎 Work 14건씩 전부 완료했고, 공통 설계 기준값인 추력 150 mN, 계통압 2.5 bar가 전 조립체에서 일관되게 확인되어 서브시스템 내 정합성에 문제가 없다.

판정: **합격**
