# K-SAT 2 시스템 요구사항 (SYS-REQ v1)

Work F001의 산출물. 모든 서브시스템·형상 Work의 최상위 입력.

## 임무
- 저궤도(500 km) 광학 지구관측, 임무수명 3년, 발사 질량 ≤ 150 kg.

## 최상위 예산
| 항목 | 배분 |
|---|---|
| 발사 질량 | ≤ 150 kg (STR 40, TCS 8, EPS 25, AOCS 15, OBC 6, COMM 8, PROP 18, PAY 25, 마진 5) |
| 궤도평균전력 | ≥ 180 W 발생, 버스+탑재체 소비 ≤ 150 W |
| 지향 정확도 | ≤ 0.05° (3σ), 안정도 ≤ 0.01°/s |
| 다운링크 | X-band ≥ 50 Mbps, S-band TT&C 상향 64 kbps |
| 추진 | ΔV ≥ 40 m/s (궤도 유지·이탈) |

## 형상 단계 정의 (최종 위성만 해당)
- **EM**: 설계·해석·시제 기능검증. **QM**: 인증 수준 환경시험.
- **FM**: 비행품 제작·수락시험·인도. 서브시스템·조립체의 내부 단계는 각자
  정한다(잎 Work 12~16건, 형상마다 다름).

## 레벨-에이전트 등급 배정 (규칙 4절)
| 레벨 | 대상 | 등급 |
|---|---|---|
| L0~L1 | 루트·형상 취합 | claude (판단·취합) |
| L2~L3 | 서브시스템·조립체 취합 | sonnet-* |
| L4 | 잎 Work (수행) | haiku-* |

검증: 질량 배분 합 145+마진 5 = 150 kg, 전력 150/180 W — 예산 정합 확인.
