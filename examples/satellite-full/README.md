# 예시: K-SAT 2 위성 상세 개발 (실규모, Work 2,000건 이상)

PBS WBS Board 규칙(../../RULES.md)을 실제 위성 개발 규모의 분해에 적용한
예시다. 앞의 examples/satellite(16건)가 입문이라면, 이 보드는 레벨 5 ×
게시글 2,190건으로 **레벨-에이전트 등급**(규칙 4절)과 **대용량 뷰**(규칙
5절)를 실증한다.

- **보드**: [board/](board/) — 게시글 2,190건.
- **현황**: `python3 tools/build_board_view.py examples/satellite-full/board`
  실행 후 [board.html](board.html). 큰 보드라 요약 중심 뷰로 렌더링된다.
- **골격 생성기**: [tools/gen_wbs.py](tools/gen_wbs.py) — Work F002의 산출물.
  규칙 1절 "미리 올려 두기"를 스크립트로 수행했다.
- **실행목록**: [runlists/](runlists/) — 서브시스템×형상별 잎 Work 순서표.

## 분해 구조와 에이전트 등급

| 레벨 | 무엇 | 수 | 집는 에이전트 |
|---|---|---|---|
| L0 | 루트 (K-SAT 2) | 1 | claude (판단·취합) |
| L1 | 형상 EM→QM→FM + 시스템 Work | 3+2 | claude |
| L2 | 서브시스템 취합 (8계통 × 3형상) | 24 | sonnet-* |
| L3 | 조립체 취합 (6개 × 8계통 × 3형상) | 144 | sonnet-* |
| L4 | 잎 Work (형상별 12~16건/조립체) | 2,016 | haiku-* |

- 최종 위성 형상만 EM→QM→FM. 조립체의 잎 구성은 형상마다 다르다:
  EM 14건(설계·해석·시제), QM 16건(인증시험), FM 12건(제작·수락).
- 잎 Work는 조립체 산출물 파일 하나에 결과를 한 줄씩 덧붙인다(부분 갱신 —
  PBS에는 파일이 한 번만 나타난다). 조립체·서브시스템 취합이 판정을 남긴다.
- 순서는 전부 `after`로만: 조립체 안 잎은 직렬 체인, 조립체·서브시스템은
  병렬, 형상은 직렬(EM→QM→FM). 도구(tools/post.py)가 선행 미완 집기를
  거부한다.
