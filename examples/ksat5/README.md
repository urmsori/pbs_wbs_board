# 예시: K-SAT 5 (규칙 v2.7~v2.8 — 전체를 아는 사람은 없다)

시작 게시글은 7건뿐이었다: 루트, 시스템 요구, 그리고 SE의 **결과 요청**
4건("모듈을 인도해 달라")과 통합 1건. 나머지는 전부 **필요의 주인이 그때그때
발행**했다.

- **보드**: [board/](board/) · **현황**: `python3 tools/build_board_view.py
  examples/ksat5/board` → [board.html](board.html)

## 보드가 자란 방식 (7건 → 44건)

| 누가 | 무엇을 발행 | 언제 |
|---|---|---|
| SE | 결과 요청 4 + 통합 1 + 요구 1 | 킥오프 (이것이 전부) |
| 각 팀 리드 | 팀 내부 인수인계 19건 (STR 5·EPS 5·AOCS 4·COMM 5) | 요청을 집은 뒤, 아는 만큼만 |
| 당사자들 | ICD 협상 8건 (SE 발행 0건) | 설계하다 상대 정보가 필요해진 순간 |
| AIT | 인수 시험 4건 + 시험 장비 필요 7건 | **모듈이 도착해 열어본 순간** |

## v2.7이 실증된 장면들

1. **SE는 ICD를 하나도 발행하지 않았다.** 8건 전부 당사자 요청(STR↔EPS/AOCS/
   COMM 발자국, EPS↔AOCS/COMM 전력 프로파일, COMM↔STR/EPS)으로 만들어졌다.
2. **AOCS 모듈이 도착하고 나서야** AIT는 그 시험에 EGSE SW(센서 자극·4모드
   트리거)와 10채널 하니스가 필요함을 알았다 — NEED-SW-AOCS, NEED-HAR-AOCS는
   킥오프 계획에 존재할 수 없었던 게시글이다. 모듈마다 발견된 장비도 달랐다
   (STR 치구, COMM RF 감쇠기·더미로드).
3. **정직한 협상이 재작업을 만들었다**: EPS가 "현 5V 레일로는 송신 시 유지
   불가"를 수치로 회신 → COMM이 전원 아키텍처를 rev.2로 재설계.
4. **통합만이 잡을 수 있는 결함**: 8.4V 레일을 AOCS 구동기와 COMM PA가
   공유하는데 동시 최악 부하(≈2.08A)를 어느 팀 ICD도 확인하지 않음 — AIT가
   통합 시점에 발견, COMM EOD 링크마진 0dB와 함께 FM 승계 리스크로 기록.

## FM 단계 (44건 → 80건): 승계 리스크가 낳은 필요

EM 인도(INT) 뒤 FM 인도가 새 필요로 확실해지자 루트를 재취합 상태로 되돌리고
(4절), SE는 다시 **결과 요청 4건(M2-\*)과 통합 1건(INT2)만** 올렸다. 나머지
31건은 전부 필요의 주인이 발행했다.

1. **리스크가 필요를 낳았다**: EM에서 승계된 RISK-RAIL(공유 8.4V 레일 동시
   부하 ≈2.08A)을 EPS가 집고, 판정에 필요한 데이터를 **당사자에게 직접**
   요청했다(REQ-RAIL-AOCS/COMM). AOCS는 "통신 중 미발생이 설계 의도지만
   지터 시 최대 5초 겹침 가능"을, COMM은 "동시성 여부는 COMM이 답할 수 없다"
   를 — 각자 아는 것과 모르는 것을 정직하게 회신했다.
2. **판정도 정직했다**: EPS의 rail-budget.md는 퓨즈 선택성(분기 2.0A/1.25A,
   상위 3.0A)으로 하드웨어를 종결하면서도 "하드웨어만으로 종결 아님"을
   명시해 운용 제약 4건(guard band 15s 상향 등)을 AIT/AOCS로 이관했다.
3. **RISK-LINK는 재설계로**: COMM이 트레이드 3안을 비교해 안테나 피드망
   재최적화를 채택(코딩이득 변경은 지상국 리스크, 송신 부스트는 RISK-RAIL
   악화로 각각 기각) — EOD 마진 0 → +1.5dB 설계, 챔버 실측 7.8dB.
4. **각 팀은 FM 체인을 스스로 세분**: 설계갱신→제작→검사/교정→수락시험→인도
   를 사람(역할) 단위 20건으로 발행·수행했다(STR-FM-\*, EPS-F\*, FM-AOCS-\*,
   COMM-FM-\*). STR은 이월됐던 배터리 브래킷 건이 기존 산출물 2건으로 이미
   해소됐음을 확인하고 **요청을 올리지 않았다** — 발행 권한 규칙의 절제 사례.
5. **도착 시 발견, 2라운드**: FM 모듈 4개가 도착하자 AIT는 EM 장비 재사용
   판단(신규 0건)을 기록하고, **실모듈 동시부하 재현 리그 1건만** 새로
   발행했다(NEED-FM-DUALLOAD) — EPS 번인의 전자부하 시뮬레이션과 실모듈
   재현을 구분한 근거 포함. GSE가 병렬로 이행해 폴링 0회에 도착.
6. **통합 판정이 리스크를 닫았다**: INT2-TST에서 실모듈 동시부하 2.08A/5s
   재현(레일 6.83V 유지·퓨즈 미동작), 링크마진 7.8dB 통합 재확인. INT2는
   승계 리스크 2건의 종결을 근거·수치와 함께 명시하고 마감됐다.

에이전트 투입 12회(EM: 팀 4·AIT·지원, FM: 팀 재개 4·AIT·GSE — sonnet/haiku
혼용)가 역할 40여 명을 나눠 맡았다. 시험 SW·하니스·리그가 필요해진 순간은 전부
"모듈이 도착해 열어본 순간"이었다.
