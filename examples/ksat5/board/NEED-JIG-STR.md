AIT-TST의 필요: STR EM 모듈(module-em.md)을 인수하려는데, STR-05
끼워맞춤 검사는 STR 팀 내부 자체 검사(자기 검증)이고 1개 항목(EPS
배터리 브래킷)은 "잠정 합격"으로 이월됐다 — AIT가 독립적으로 각
서브시스템 장착 패턴에 실제 정합되는지 재확인할 지그가 없다.
mounting-interfaces.md(module-em.md §"끼워맞춤 검사" 표 근거 문서)를
읽고 확인한 구체 체결 패턴:

| 대상 | 체결 홀 패턴 |
|---|---|
| EPS 태양전지판 몸체 패널(2면) | M2.5×4, 코너 5mm 인셋, 표준 6U 레일 피치 |
| EPS PCU | M3 코너 4점, 90.17×96.13mm PC/104 피치 |
| EPS 배터리(잠정) | M3×4, 95×90×20mm 발자국 — **잠정 합격 항목, 재확인 필요** |
| AOCS 리액션휠×3 | M3×3, PCD40, 직교 3축 개별 브래킷 |
| AOCS 마그네토토커×3 | 양단 클램프 2점, 직교 3축 |
| AOCS 스타트래커 | M3×4, PCD 50×50, 평면도 5μm |
| AOCS 자이로 | M2.5×4, PCD 30×30 |
| AOCS 태양센서×2 | M2×2, PCD 14×14, 패널 관통 |
| COMM 트랜시버 | M3 코너 4점, 82×88mm 대각 피치 |
| COMM 안테나×4 | M3×4, 더블러부, -Z 패널 대칭 배치, 돌출 ≤8mm |

요청: 위 10종 체결 패턴에 맞는 정합 지그(핀/게이지) 세트 — 특히
EPS 배터리 브래킷(잠정 합격) 항목을 최종 발자국 기준으로 재확인할
수 있는 지그 포함.
산출물: (지원 역할이 정함)
