# COMM 링크버짓 및 아키텍처 (EM)
입력: examples/ksat5/deliverables/sysreq.md

## 요구사항 요약
- 데이터율: UHF 9.6 kbps
- 요구 마진: ≥ 6 dB
- 질량 배분: 1.2 kg (통신 서브시스템 전체 — 트랜시버 + 안테나 + 하네스)

## 아키텍처
- 반이중(half-duplex) UHF 트랜시버 1식 + 접이식 모노폴/다이폴 안테나 1식
- 지상국: 9.6 kbps GMSK, 수신 시스템 잡음온도 500 K 가정(공개 지상국 표준값)

## 링크버짓 (하향, 위성→지상, 최악 궤도 고도 저앙각 기준)
| 항목 | 값 |
|---|---|
| 송신 출력 (Pt) | 33 dBm (2 W) |
| 송신 안테나 이득 (Gt) | 0 dBi (준-등방) |
| 경로손실 (자유공간, 550 km, 435 MHz, 최악 앙각) | −152 dB |
| 수신 안테나 이득 (지상국, Gr) | 15 dBi |
| 시스템 손실 (편파·지향·케이블) | −3 dB |
| 수신 전력 (Pr) | −107 dBm |
| 요구 Eb/N0 (GMSK, BER 1e-5) | 10.5 dB |
| 수신 시스템 잡음전력밀도 (N0, 500K) | −198.6 dBm/Hz |
| 데이터율 (9.6 kbps) | 39.8 dBHz |
| 필요 Pr (Eb/N0 + N0 + 데이터율) | −148.3 dBm |
| **마진 (Pr − 필요Pr)** | **≈ 6.3 dB** — 요구(≥6 dB) 충족, 여유 0.3 dB |

## 확정 사항 (COMM-02·COMM-03 입력)
- 트랜시버 송신 출력: 2 W (33 dBm), 요구 시 소비전력 산정에 반영할 것(COMM-02)
- 안테나: 준-등방(0 dBi) 접이식 모노폴/다이폴, 전개 기구 필요(COMM-03)
- 마진 여유가 0.3 dB로 작아 안테나 이득·정합 손실 관리가 중요함을 COMM-03에 전달

검증: 링크버짓 합산 결과 마진 6.3 dB ≥ 요구 6 dB 확인(수기 계산).
