# STR 1차 구조 설계 (프레임·패널, 6U 표준 포락선)
입력: examples/ksat5/deliverables/sysreq.md

## 포락선
- 6U CubeSat 표준 포락선(CDS 기준): 366 x 226.3 x 100 mm (deploy 이전 stowed 기준).
- 알루미늄 6061-T6 압출 레일 4개 + 상/하/양 측 패널 6매 + 내부 데크 3단(1U 슬롯 3개
  상당, EPS/AOCS/COMM 서브시스템 보드 스택 수용).

## 1차 질량 예산 (구조 자체, STR 배분 3.0 kg 대비)
| 항목 | 질량 (kg) |
|---|---|
| 레일 4개 (Al 6061-T6) | 0.55 |
| 외곽 패널 6매 | 0.70 |
| 내부 데크·스탠드오프 3단 | 0.60 |
| 체결류(볼트·인서트·helicoil) | 0.15 |
| 마진 (20%) | 0.40 |
| **1차 합계** | **2.40** |

세부 장착 브래킷·컷아웃(STR-02에서 확정) 예비 질량 0.60 kg을 남겨
배분 3.0 kg 이내(2.40 + 0.60 = 3.00)로 관리한다.

## 데크 배치 (개념)
- 데크 1단(+Z 인접): EPS 보드 스택 예약 구역.
- 데크 2단(중단): AOCS 보드·리액션휠 예약 구역.
- 데크 3단(-Z 인접): COMM 트랜시버 보드 예약 구역.
- 태양전지판·안테나 등 외부 장착품 위치는 STR-02에서 EPS/AOCS/COMM의
  실제 질량·발자국(ICD-STR-EPS, ICD-STR-AOCS, ICD-STR-COMM 회신)과
  AOCS·COMM이 제기한 정렬/전개 요구(ICD-AOCS-STR, ICD-COMM-STR)를
  받아 확정한다 — 이 문서는 그 전 단계의 1차 프레임 개념까지만 다룬다.

## 검증
질량 배분: 1차 구조 질량 2.40 kg + 예비 브래킷 마진 0.60 kg = 3.00 kg
≤ STR 배분 3.0 kg (sysreq.md) 충족. 포락선 366x226.3x100 mm은 6U 표준
범위 내.
