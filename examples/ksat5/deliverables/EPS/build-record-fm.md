# EPS FM 비행품 제작 기록

입력: examples/ksat5/deliverables/EPS/design-update-fm.md

design-update-fm.md(rev.B 회로도) 기준으로 비행 등급 부품을 사용해
조립한 기록.

## 1. 조립 대상
- 태양전지판 어셈블리(몸체 2면 + 전개 날개 2매, 힌지 포함)
- PCU 보드(S3R+BDR, PC/104 규격, rev.B — 액추에이터 레일 분기 퓨즈
  홀더 2개소 + 상위 공용 퓨즈 홀더 1개소 추가 실장)
- 배터리 팩(2S1P 18650, 비행 등급 셀 스크리닝 로트 사용)

## 2. 부품 이력(Traceability) 요약
| 부품 | 로트/시리얼 | 비고 |
|---|---|---|
| 태양전지 셀 | LOT-SC-FM-01 | 비행 등급, 삼중접합 GaAs |
| 18650 셀(×2) | S/N BAT-FM-001, BAT-FM-002 | 용량 실측 3.41/3.38 Ah (스펙 3.4Ah 대비 -0.6%/+0.3%) |
| AOCS 분기 퓨즈 | 2.0A 표준 블로우, LOT-F2A-FM | design-update-fm.md 정격 반영 |
| COMM 분기 퓨즈 | 1.25A 완속, LOT-F125-FM | design-update-fm.md 정격 반영 |
| 상위 공용 퓨즈 | 3.0A 완속, LOT-F3A-FM | design-update-fm.md 정격 반영 |

## 3. 조립 공정 확인
- 토크 관리: 체결부(M2.5/M3) 전 항목 규정 토크 체결 확인(토크렌치 기록 보관)
- 퓨즈 홀더 3개소 극성·정격 육안 검사(조립자 본인 확인, 독립검사는 EPS-F03에서 별도 수행)
- 배선 연속성(continuity) 시험: 전 레일(1차버스/5V/3.3V/액추에이터) 통과

## 4. 다음 단계로의 입력
독립 수락검사(EPS-F03)가 본 조립 결과를 design-update-fm.md 대비
재확인한다 — 본 문서의 자체 확인은 조립자 1차 점검이며 QA 최종
판정을 대체하지 않는다.

검증: 부품 이력 전 항목 로트/시리얼 기록, 연속성 시험 전 레일 통과, 토크 체결 기록 확인(조립자 자체 점검 — 독립 수락검사는 EPS-F03에서 별도 수행 예정).
