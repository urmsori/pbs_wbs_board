# EPS FM 번인시험(Burn-in Test)

입력: examples/ksat5/deliverables/EPS/test-plan.md,
examples/ksat5/deliverables/EPS/acceptance-inspection-fm.md,
examples/ksat5/deliverables/EPS/rail-budget.md

수락검사(acceptance-inspection-fm.md) 합격품에 대해 EM test-plan.md의
5개 시험 항목을 재수행하고, FM 전용 항목(장시간 통전 스크리닝,
rail-budget.md 검증)을 추가한다.

## 1. EM 시험 항목 재수행 결과
| 항목 | 결과 |
|---|---|
| 태양광 시뮬레이터 발생 시험 | BOL 피크 발생 실측 97W(설계 101W 대비 -3.9%, 기준 -10% 이내) — 합격 |
| 버스 레귤레이션 시험 | 5V/3.3V/1차버스 리플·정전압 전 레일 기준 이내 — 합격 |
| 부하 스텝 시험 | sag/overshoot ≤5%, 복구 ≤1ms 기준 충족 — 합격 |
| 보호회로 시험 | UVLO/OVP 트립점 설계치 ±5% 이내 — 합격 |
| 액추에이터 레일 확인 | 6.8~8.4V 전 구간 정상, 배터리 확정치 기준 재확인 완료 — 합격 |

## 2. FM 추가 항목 — 장시간 통전 스크리닝
- 조건: 상온 통전 72시간 + 온도사이클 3회(-20℃~+50℃, 열진공 챔버)
- 결과: 초기고장 없음, 파라미터 드리프트(버스 전압·션트 듀티) 전
  구간 규정 이내

## 3. FM 추가 항목 — 공유 레일 동시부하 실증 (rail-budget.md 검증)
rail-budget.md가 정한 정격이 실물에서 실제로 트립 없이 통과하는지
전자부하로 재현 시험한다.

| 시나리오 | 인가 조건 | 결과 |
|---|---|---|
| AOCS 분기 단독 | 1.34A, 60s | 2.0A 퓨즈 트립 없음(정상) — 합격 |
| COMM 분기 단독 | 0.74A, 240s 연속 | 1.25A 완속 퓨즈 트립 없음(nuisance trip 없음 확인) — 합격 |
| 동시(최악 재현) | 2.08A, 5s(AOCS+COMM 중첩) | 상위 3.0A 완속 퓨즈 트립 없음, 버스 전압 6.8V 이상 유지 — 합격 |
| 고장 모사(단락) | AOCS 분기 단락 인가 | AOCS 분기 퓨즈(2.0A)만 트립, COMM 분기·상위 퓨즈 건전 유지(선택성 실증) — 합격 |

## 4. 종합 판정
전 시험 항목 합격. rail-budget.md의 퓨즈 정격 설계가 실물 시험으로
실증됐다 — 계산상 여유(83% 이하)뿐 아니라 실제 전자부하 재현으로도
트립 없음과 선택성이 확인됐다.

검증: EM 5개 항목 전건 합격 재확인, 72h 통전+온도사이클 3회 초기고장 없음, 공유레일 4개 시나리오(단독2·동시1·고장모사1) 전건 설계대로 동작 확인.
