# EPS 배터리 용량 설계

입력: examples/ksat5/deliverables/EPS/power-generation.md,
examples/ksat5/deliverables/EPS/power-conditioning.md,
examples/ksat5/deliverables/COMM/icd-eps-comm-power.md,
examples/ksat5/deliverables/AOCS/icd-eps-aocs-power-profile.md

COMM·AOCS의 부하 전력 프로파일 회신(ICD-EPS-COMM, ICD-EPS-AOCS)을
받아 배터리 용량을 확정한다.

## 1. 부하 합산

| 부하 | 상태 | 전력 |
|---|---|---|
| OBC/하우스키핑(5V 레일, 가정치) | 상시 | 2.0 W |
| AOCS NOMINAL(지향 유지) | 상시 | 3.2 W |
| COMM 대기(수신) | 상시 | 0.5 W(5V) + ≈0.05 W(액추에이터 레일 누설) |
| **베이스라인 합계** | | **≈5.75 W** |
| COMM 송신(피크, PA는 rev.2에서 액추에이터 레일로 이설) | 궤도당 ≈4분 | 5.0 W(액추에이터) + 0.6 W(5V) = 5.6 W (베이스라인 대비 +≈4.55W) |
| AOCS 슬루(첨두) | 최대 60s/회 | 9.1 W (베이스라인 AOCS 3.2W 대비 +5.9W) |
| AOCS 모멘텀덤프(마그네토토커) | 최대 300s, 궤도당 1~2회 | +3.0 W |

OBC 부하는 확정 자료가 없어 EPS-02 5V 레일 검토 시 사용한 가정치
(0.4A@5V)를 그대로 사용한다 — 추후 OBC 팀 확정치로 갱신 필요(가정임을
명시).

## 2. 궤도·식(蝕) 조건
- 궤도 주기 ≈95분(COMM 회신 가시구간 산정 기준과 정합)
- 일조 60% / 식 40% (EPS-01) → 식 구간 ≈38분(0.633h)
- 지상국 교신은 궤도당 1회, COMM 송신 지속시간 ≈4분 — 최악 조건으로
  식 구간 내 발생한다고 가정(마진 확보 목적)
- AOCS 슬루 2회(식 구간 내, 각 60s), 모멘텀덤프 1회(300s) 동시 가정

## 3. 식 구간 에너지 수요
| 항목 | 계산 | 에너지 |
|---|---|---|
| 베이스라인(38분) | 5.75W × 0.633h | 3.64 Wh |
| COMM 송신 증분(4분) | 4.55W × 0.0667h | 0.30 Wh |
| AOCS 슬루 증분(2×60s) | 5.9W × 0.0333h | 0.20 Wh |
| 모멘텀덤프 증분(300s) | 3.0W × 0.0833h | 0.25 Wh |
| **소계** | | **4.39 Wh** |
| 설계 마진 30%(가정치 부하·컨버터 효율 불확실성 반영) | ×1.3 | **5.71 Wh** |

## 4. 배터리 선정
- 구성: 2S1P Li-ion 18650, 셀 용량 3.4 Ah(대표 COTS 셀 기준)
- 전압: 공칭(만충) 8.4V, EOD 하한 6.8V(EPS-02 정의), 평균 방전전압 ≈7.6V
- 팩 에너지: 3.4Ah × 7.6V ≈ 25.8 Wh
- 소요 에너지(마진 포함 5.71Wh) 대비 DoD ≈ 22%(마진 미포함 시 17%) —
  LEO Li-ion 장수명 기준(통상 DoD ≤25~30%) 이내로 여유 있음
- 첨두 전류 확인: 최악 동시부하(베이스라인+COMM송신+AOCS슬루)
  ≈2.0+3.2+5.6+9.1-3.2(AOCS슬루가 NOMINAL 대체)≈16.7W, EOD 6.8V 기준
  전류 ≈2.46A — 대표 18650 셀 연속방전 정격(수 A~수십 A급) 이내로 여유

## 5. 질량 확정
셀 2개(2S1P) + 홀더/BMS 추정 질량 ≈0.22 kg — ICD-STR-EPS 잠정치(0.25kg)
대비 근접, STR에는 확정치로 재회신 필요(본 Work 범위 밖, EPS-05에서
모듈 통합 시 반영).

## 6. 인터페이스 관련 확인
COMM 회신(icd-eps-comm-power.md)에서 PA가 액추에이터 레일로 이설(rev.2)
되었음을 확인 — ICD-COMM-EPS 회신에서 EPS가 권고한 조치와 일치하며,
5V 레일 여유 문제는 해소된 것으로 판단한다. COMM이 언급한 EOD 6.8V에서의
링크마진 잠식 우려(0.3dB)는 COMM-04(COMM 담당)의 확인 사항으로, 배터리
용량 설계 자체에는 영향 없음(전압 범위 6.8~8.4V 자체는 본 설계와 일치).

검증: 식 구간 에너지 수요(마진 포함 5.71Wh) 대비 선정 배터리 에너지(25.8Wh)로 DoD 22% 산출, LEO Li-ion 통상 DoD 한도(25~30%) 이내 확인. 최악 첨두전류(≈2.46A)가 대표 셀 방전정격 이내임을 확인.
