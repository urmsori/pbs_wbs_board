# EPS 전력 발생계(태양전지판) 설계

입력: examples/ksat5/deliverables/sysreq.md

## 요구사항 반영
- 발생 전력 ≥ 20 W (sysreq)
- EPS 질량 배분 ≤ 3.0 kg (sysreq)
- 6U 폼팩터

## 어레이 구성
- 삼중접합 GaAs 태양전지, BOL 효율 29.5%, EOL(수명 1년, LEO) 효율 저하 계수 0.92
- 구성: 몸체 장착 패널 2면(6U 측면, 고정) + 전개형 날개 2매(각 6U 크기, 원웨이 전개)
- 패킹 팩터 0.90(셀 간 여백·배선 포함)
- 총 셀 면적: 약 0.28 m² (몸체 0.06 m² + 전개 날개 0.22 m²)

## 발생 전력 예산 (태양 지향 시, 궤도 평균)
| 항목 | 값 |
|---|---|
| 태양상수 | 1361 W/m² |
| BOL 면적당 발생 (효율×패킹) | 1361 × 0.295 × 0.90 ≈ 361 W/m² |
| BOL 총 발생 (0.28 m², 태양 지향) | ≈ 101 W (피크, 지향 오차 0.5° 이내 손실 무시) |
| 궤도 평균 계수(자세·식(蝕) 반영, 500 km LEO, 일조 60%) | 0.20 |
| BOL 궤도 평균 발생 | ≈ 20.2 W |
| EOL 저하 계수 | 0.92 |
| **EOL 궤도 평균 발생** | **≈ 18.6 W** |

EOL 궤도 평균이 요구치 20 W에 못 미치므로, 몸체 패널 1면을 추가
전개형으로 변경하거나 전개 날개 면적을 10% 확대해 여유를 확보하는
설계 변경을 EPS-02(전력조절계) 확정 전에 반영한다. 잠정 조치로 전개
날개 면적을 0.22 → 0.245 m²로 확대(패널 프레임 내 여유 있음)하면
EOL 궤도 평균 ≈ 20.6 W로 요구치를 만족한다.

## 질량 예산
| 항목 | 질량(kg) |
|---|---|
| 태양전지 패널(몸체+전개 날개, 확대분 포함) | 0.55 |
| 전개 메커니즘·힌지 | 0.20 |
| 배선·커넥터 | 0.05 |
| **EPS-01 소계** | **0.80** (배분 3.0 kg 중, 나머지는 PCU·배터리·하니스에 배분) |

## 다음 단계로의 입력
- 버스단 입력 전압: 어레이 개방전압 기준 약 12~14 V(직렬 스트링 3S 기준) — EPS-02에서 레귤레이션 방식 결정에 사용.
- EOL 궤도 평균 발생 전력 20.6 W — EPS-03 배터리 용량 산정 시 발생측 값으로 사용.

검증: BOL/EOL 궤도 평균 발생 전력이 sysreq 요구치(≥20 W) 이상임을 표 계산으로 확인(EOL ≈20.6 W). 질량 0.80 kg는 EPS 배분 3.0 kg 이내.
