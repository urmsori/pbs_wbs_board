# ICD 회신: EPS 모듈 질량·장착 발자국 (STR-02 요청 대응)

입력: examples/ksat5/deliverables/EPS/power-generation.md, examples/ksat5/deliverables/EPS/power-conditioning.md

STR-02(EPS-DSN)의 요청에 대한 EPS 팀 회신. 배터리 팩(EPS-03)은 아직
설계 확정 전이므로 잠정치를 제시하고, 확정되는 대로 갱신 회신한다.

## 1. 태양전지판 장착부 (확정, EPS-01 기준)
| 항목 | 값 |
|---|---|
| 구성 | 몸체 장착 패널 2면(고정) + 전개 날개 2매 |
| 몸체 패널 발자국 | 6U 측면 규격(≈100 mm × 340 mm), 2면 |
| 전개 날개(개별) | ≈100 mm × 245 mm(면적 확대분 반영), 힌지 1개소/매 |
| 체결 홀 패턴 | 몸체 패널: M2.5, 4개소, 코너에서 5 mm 인셋, 표준 6U 레일 피치 정렬 |
| 전개 힌지 브래킷 체결 | M3, 2개소/힌지, STR 데크 마운트 러그와 결합(러그 위치는 STR-02가 최종 확정) |
| 질량 | 패널+힌지+배선 합계 0.80 kg (EPS-01 산출물 표 참조) |

## 2. PCU(전력조절계) 보드
| 항목 | 값 |
|---|---|
| 형태 | 스택형 보드, PC/104 유사 규격 |
| 외형 치수 | 96 mm × 90 mm × 15 mm (부품 높이 포함) |
| 체결 홀 패턴 | 4코너 M3, 90.17 mm × 96.13 mm 피치(PC/104 표준) |
| 커넥터·하니스 인출 | 보드 한 변(스택 배면)에 34핀 백플레인 헤더 1개(버스 전력 + 하위 레일 인출), RF/외부 인터페이스 없음 |
| 질량(잠정) | ≈0.15 kg |

## 3. 배터리 팩 (잠정 — EPS-03 확정 전)
| 항목 | 값(잠정) |
|---|---|
| 구성 가정 | 2S Li-ion, 1U 슬롯 내 실장 |
| 외형 치수(잠정) | ≈95 mm × 90 mm × 20 mm |
| 체결 홀 패턴(잠정) | 4코너 M3, 브래킷 고정(셀 홀더 별도) |
| 커넥터 | 2핀 전력 + 온도센서 서미스터 1핀, 팩 상단 인출 |
| 질량(잠정) | ≈0.25 kg — 용량 확정(EPS-03, 외부 부하 프로파일 대기 중) 후 갱신 |

## 4. EPS 모듈 총 질량 요약
| 항목 | 질량(kg) |
|---|---|
| 태양전지판(장착부 포함) | 0.80 |
| PCU | 0.15 |
| 배터리(잠정) | 0.25 |
| 하니스 여유 | 0.10 |
| **소계(잠정)** | **1.30** |
| EPS 배분(sysreq) | 3.0 |
| 잠정 여유 | 1.70 |

## 5. STR-02에 대한 안내
- 확정 수치: 1항(태양전지판), 2항(PCU) — STR 브래킷·컷아웃 설계에 바로 사용 가능.
- 잠정 수치: 3항(배터리) — EPS-03 완료(외부 부하 프로파일 도착) 후 최종 발자국·질량으로
  본 문서를 갱신해 재회신한다. 현재 잠정치로 설계해도 여유(≈1.70 kg) 내에서
  큰 변경 가능성은 낮음.

검증: 1·2항은 EPS-01·EPS-02 확정 산출물 수치와 정합. 3항은 EPS-03 완료 전 잠정치임을 명시(정직하게 표기), 총 질량이 EPS 배분(3.0kg) 이내임을 합산으로 확인.
