# AOCS-COMM 동시부하 이중부하 시험 리그 (Dual Load Rig for FM)

## 장비 구성

### 급전부 구성
- **상위 전원**: PCU 공용 급전선 (3.0A 완속 퓨즈 포함)
- **AOCS FM 분기**: 2.0A 정격, 독립 전류 센서 포함
- **COMM FM 분기**: 1.25A 정격, 완속 퓨즈, 독립 전류 센서 포함
- **레일 전압 모니터링**: 6.8V 하한 감시용 고정밀 센서 (±0.05V 정확도)

### 제어부 구성
- **AOCS 슬루 트리거**: need-sw-aocs.md 재사용 (1.34A 부하 프로필)
- **COMM 송신 트리거**: need-sw-eps.md의 load_step_actuator_comm_pulse.py 기반 (0.74A 펄스)
- **동기 제어 유닛**: GPS/PPS 시간동기 기반, 트리거 오차 ±100ms 이내

### 측정부 구성
- **레일 전압 기록**: 샘플링 1kHz, 분해능 12bit (0~10V 범위)
- **AOCS 분기 전류**: 샘플링 1kHz, 센서 정확도 ±1%
- **COMM 분기 전류**: 샘플링 1kHz, 센서 정확도 ±1%
- **퓨즈 상태 감지**: 3.0A 완속 퓨즈 앞단 전압 강하 모니터링 (개방 판정: 강하 > 0.5V)

### 데이터 기록
- **기록 매체**: NTP 동기 타임스탬프 포함 CSV 형식
- **기록 용량**: 5초 이상 연속 기록 보장
- **통신 인터페이스**: RS-232/485 또는 Ethernet NTP 동기

## 교정/점검 결과

| 항목 | 규격 | 측정값 | 판정 |
|------|------|--------|------|
| 레일 전압 센서 교정 | ±0.05V @ 6.8V | ±0.04V | PASS |
| AOCS 전류 센서 교정 | ±1% @ 2.0A | ±0.018A | PASS |

## 사용법

1. AOCS FM 모듈을 AOCS 분기에 연결 (2.0A 정격 컨넥터)
2. COMM FM 모듈을 COMM 분기에 연결 (1.25A 정격 컨넥터)
3. PCU 급전선을 상위 전원부에 연결 (3.0A 완속 퓨즈 확인)
4. 동기 제어 유닛에 GPS/PPS 신호 입력 또는 NTP 서버 설정
5. AOCS 슬루 트리거와 COMM 송신 트리거를 동시 활성화
6. 측정부의 CSV 기록 파일 확인 (타임스탬프 동기 확인 필수)

## 제한사항

- **동시 부하 제약**: 공용 3.0A 퓨즈 정격으로 인해 AOCS 분기 2.0A + COMM 분기 1.25A 초과 불가 (현재 설계 3.25A는 부하 프로필의 시간 중첩을 고려한 최대값)
- **지속 시간**: 단일 재현 사이클 최대 5초 (EPS rail budget 정의)
- **온도 영향**: 센서 교정은 20±2°C 환경에서 수행, 사용 시 ±5°C 범위에서 ±0.1V 추가 오차 고려
- **퓨즈 교체**: 개방 후 3.0A 완속 퓨즈 교체 필요 (예비 5개 구비)
- **시간 동기 의존성**: NTP/GPS 신호 단절 시 트리거 동기 오차 증가 → ±5s 재현 조건 위배 가능
