# AOCS 지향정확도 예산 배분 및 센서/액추에이터 선정 (EM)
입력: examples/ksat5/deliverables/sysreq.md

## 1. 상위 배분
- AOCS 질량 배분(SYS-REQ): ≤ 2.0 kg
- 시스템 지향 요구(SYS-REQ): ≤ 0.5°(3σ, 전체 오차 예산)

## 2. 지향오차 예산 세분 (3σ, RSS 배분)
| 오차원 | 배분 | 비고 |
|---|---|---|
| 자세결정 오차(스타트래커+자이로 융합) | 0.15° | 센서 정렬오차 포함 |
| 제어오차(리액션휠 제어루프) | 0.30° | 외란토크·휠 포화 여유 포함 |
| 정렬/열변형 여유 | 0.35° | 장착 정렬 공차·구조 열변형(ICD-AOCS-STR로 협상) |
| RSS 합계 | ≈ 0.49° | ≤ 0.5° 목표 만족(여유 0.01°) |

## 3. 질량 배분(2.0 kg 내)
| 구성품 | 질량(kg) |
|---|---|
| 스타트래커 1식 | 0.35 |
| 관성센서(자이로) | 0.20 |
| 태양센서 2식 | 0.10 |
| 리액션휠 3축 | 0.90 |
| 마그네토토커 3축 | 0.30 |
| 하니스/브라켓 여유 | 0.15 |
| 합계 | 2.00 |

## 4. 센서/액추에이터 후보 선정
- 자세결정: 스타트래커(주) + MEMS 자이로(보조, 고속 슬루 구간) + 태양센서(coarse, 안전모드용)
- 자세제어: 리액션휠 3축(정밀 지향) + 마그네토토커 3축(휠 각운동량 덤핑)

## 5. 하위 Work로 넘기는 항목
- 알고리즘/SW 설계 → AOCS-02 (본 배분·선정 결과를 입력으로 사용)
- 센서 장착 설계(정렬·강성) → AOCS-03, 구조 인터페이스는 ICD-AOCS-STR로 STR과 협상 중

검증: 지향오차 RSS 합계(0.49°) ≤ SYS-REQ 지향 요구(0.5°) 확인,
질량 배분 합계(2.00 kg) = SYS-REQ AOCS 배분(2.0 kg) 확인.
