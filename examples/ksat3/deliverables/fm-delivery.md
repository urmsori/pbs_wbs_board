# K-SAT 3 FM 인도 기록 (Work K90의 산출물)

입력: examples/ksat3/deliverables/sat-em-test.md, str-fm.md, eps-fm.md, comm-fm.md, sysreq.md

## FM 이관 항목 종결 확인

| EM에서 이관된 항목 | 처리 | 근거 |
|---|---|---|
| EPS 총질량 미보고 | 종결 — 0.70/0.80 kg | eps-fm.md |
| 버스트 하드웨어 검증 | 종결(해석 기반 잠정 통과, 실측 한계 명시) | eps-fm.md |
| 트레이 높이·방열패드 | 종결 — 26mm 스택 수용, 패드 반영 | str-fm.md |
| 진동 경계조건 | 종결(발사체 규격 가정 명시) | str-fm.md |
| 안테나 상세치수 | 종결 — 30mm 개구부 정합, 질량 297g | comm-fm.md |

## 시스템 판정

- 질량 합계: STR 0.80 + EPS 0.70 + COMM 0.297 ≈ 1.80 kg + 하니스·여유
  ≤ 2.6 kg 예산 이내.
- 링크버짓 12W 기준 유지(EPS 해석 잠정 통과 전제) — 잔여 리스크(실측
  미실시)는 인도 문서에 그대로 승계한다. 숨긴 미결 없음.
- **판정: K-SAT 3 FM 인도 가능.**

검증: 세 FM 산출물의 입력 사슬(각 파일 머리 "입력:")을 따라 sysreq까지
역추적 가능함을 확인 — 입력 없는 산출물은 sysreq.md 하나뿐이다.
