# K-SAT 3 시스템 요구사항 (SYS-REQ v1)

입력: 없음 (루트 요구 — 이 프로젝트에서 외부 입력 없이 만들어지는 유일한 산출물)

## 임무
- 2U 큐브샛, 저궤도 기술검증(신형 UHF 트랜시버 + 박막 태양전지), 수명 1년.

## 예산
| 항목 | 배분 |
|---|---|
| 질량 | ≤ 2.6 kg (STR 0.9, EPS 0.8, COMM 0.5, 하니스·여유 0.4) |
| 궤도평균전력 | ≥ 6.0 W 발생, 평시 소비 ≤ 4.5 W |
| 송신 버스트 | 최대 10초, 이때 버스 전압 ≥ 7.0 V 유지 |
| 다운링크 | UHF 9.6 kbps, 링크마진 ≥ 6 dB |

## 형상 단계
- EM(기능 통합 검증) → FM(비행품·수락). 트랙 내부 단계는 각 Work가 정한다.

검증: 배분 합 2.6/2.6 kg, 송신 버스트 조건이 EPS·COMM 양쪽에 걸린 교차
요구임을 명시(통합시험 K40에서 검증된다).
