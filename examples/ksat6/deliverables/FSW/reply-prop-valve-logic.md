# FSW → PROP 회신: 밸브 구동·잠금 로직 요구 반영 확인

입력: examples/ksat6/deliverables/FSW/comm-payload-sw.md, examples/ksat6/deliverables/FSW/architecture.md

REQ-PROP-FSW(PROP-01) 회신 — 밸브 구동·잠금 로직을 comm-payload-sw.md의
"FDIR/밸브류 액추에이터 안전 로직" 태스크(TASK_COMM 내 서브루틴)에 아래와
같이 반영한다.

## 반영 내용
| 요구(PROP-01) | FSW 반영 |
|---|---|
| 래치밸브 이중코일 펄스구동(50ms) | 코일별 50ms 펄스 타이머 명령, 코일A/B 교차확인 후 실행 |
| 안전모드 소프트웨어 인터록 | 안전모드 진입 시(FSW-ARCH 안전모드 상태기계) 밸브 구동 명령 자체를 소프트 인터록으로 차단 |
| 스러스터 밸브 연속구동시간 제한 | 구동시간 상한 파라미터(초) 설정, 초과 시 자동 차단 + 이벤트 TM |
| 위치 텔레메트리 상시 보고 | HK 태스크(TASK_HK, 0.1Hz)에 밸브 위치 상태 필드 추가, 이벤트 발생 시 즉시 TM |

## 인터록 로직 순서
1. 지상/시퀀서 명령 수신 → 2. 사전조건 검사(압력·온도 범위, 안전모드 아님,
연속구동시간 이내) → 3. 이중 확인(두 번째 확인 명령 또는 타임태그 일치)
→ 4. 코일 펄스 실행 → 5. 위치 텔레메트리 즉시 보고.

이 로직은 comm-payload-sw.md 검증 케이스 5("밸브 명령 인터록 미충족 시
명령 거부")로 이미 검증 대상에 포함되어 있다.

검증: PROP-01의 4개 요구 항목이 모두 FSW 반영표에 1:1 대응됨을 확인, comm-payload-sw.md 검증케이스5와 교차확인.
