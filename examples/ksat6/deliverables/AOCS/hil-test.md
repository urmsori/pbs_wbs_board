# AOCS 폐루프(HIL) 시험
입력: examples/ksat6/deliverables/AOCS/star-tracker-accept.md, gyro-accept.md, rwa-accept.md, magnetorquer.md, pointing-budget.md, fsw-if-reply.md

## 시험 구성
별추적기·자이로·반작용휠 4기·마그네토커 실제 비행품(수락시험 통과품)을
다이나믹스 시뮬레이터(위성체 6자유도 모델)에 실시간 연동한 HIL 루프. 제어
법칙은 fsw-if-reply.md에서 확정한 20Hz 대표 제어법칙(FSW 비행코드 자체는
INT 단계 별도 통합시험 대상).

## 결과
| 항목 | 요구(sysreq) | 실측 | 판정 |
|---|---|---|---|
| 지향정확도(3σ, 정상추적) | 0.05° | 0.034° | PASS |
| 지향안정도(0.5s 윈도, 노출시간 중) | 0.005°/s | 0.0028°/s | PASS |
| 획득→정상추적 전이시간 | (참고) | 42s | 기록 |
| 모멘텀덤핑 세션 중 지향 이탈 | (참고) | 0.02° | 기록(정상추적과 배타 확인) |

pointing-budget.md의 예측(0.031°/0.0024°/s)과 실측(0.034°/0.0028°/s)의
차이는 실측이 실물 하드웨어 결합 잡음(예측에 없던 상호결합 항)을 반영하기
때문 — 실측이 최신 확정치이므로 pointing-budget.md 예측치보다 실측치를
채택한다(규칙 4절 취합 모순 처리).

검증: 실측 0.034° ≤ 0.05°(마진32%), 0.0028°/s ≤ 0.005°/s(마진44%) — sysreq
AOCS 항목(지향0.05°/안정도0.005°/s) 최종 충족.
