# AOCS 지향 예산·모드 설계
입력: examples/ksat6/deliverables/SE/sysreq.md

## 1. 지향정확도 예산 (요구: 0.05° 3σ, 관측 중)
RSS(제곱합제곱근) 배분. 오차원별 3σ:

| 오차원 | 배분(°) | 비고 |
|---|---|---|
| 별추적기(STT) 측정오차 | 0.003 | ≈11 arcsec, AOCS-02 수락 기준 |
| 자이로(IMU) 전파오차(ST 갱신 사이) | 0.010 | AOCS-03 수락 기준 |
| 정렬오차(ST-자이로-본체, 열+구조) | 0.015 | REQ-AOCS-STR로 STR팀에 기준면 요청 |
| 제어알고리즘/휠 토크 분해능 잔차 | 0.020 | FSW-AOCS 제어루프 설계 입력 |
| 구조 미소진동(휠 방해) 결합 | 0.015 | AOCS-04/05 입력 |
| **RSS 합계** | **0.031** | 요구 0.05 대비 마진 ≈38% |

## 2. 지향안정도 예산 (요구: 0.005°/s, 노출시간 중)
| 오차원 | 배분(°/s) |
|---|---|
| 자이로 각속도잡음(ARW) | 0.0010 |
| 반작용휠 토크리플 유기 잔떨림 | 0.0015 |
| 구조 미소진동 결합 | 0.0010 |
| 제어루프 잔차 | 0.0012 |
| **RSS 합계** | **0.0024** | 요구 0.005 대비 마진 ≈52% |

## 3. 임무 모드
1. **획득(Acquisition)**: 별추적기 초기 항성식별, 자이로 전파로 보조.
2. **정상추적(Fine pointing)**: 지향예산 §1·§2를 만족하는 정상 관측 모드.
3. **모멘텀덤핑**: 반작용휠 저장 모멘텀이 상한 근접 시 마그네토커로 방출.
   정상추적과 배타적 모드(동시 수행 안 함) — §4 전력 산정의 전제.
4. **안전모드**: 자이로+태양센서만으로 최소 자세 유지, 배터리·통신 보호.

## 4. 반작용휠·마그네토커 1차 사이징
- 반작용휠 4기(3축 제어 + 1기 여유, 단일고장 허용): 기당 최대토크 0.10 Nm,
  모멘텀저장 12 Nms. 기당 순간 첨두전력 12~18W(모멘텀덤핑/급기동 구간,
  ≤60s), 정상추적 시 기당 평균 4W.
- 마그네토커 3기(직교 3축): 축별 자기모멘트 요구는 AOCS-05에서 확정,
  덤핑 시퀀스 첨두전력 축당 6W(2축 동시구동 가정 12W), 궤도당 1~2회
  ≤120s 지속.

## 5. AOCS 총 전력 1차 추산 (모드 비동시 가정, 28V±4V 모선)
| 유닛 | 평균(W) | 첨두(W) | 첨두 지속 |
|---|---|---|---|
| 별추적기 x1 | 6 | 8 | 기동초기 30s |
| 자이로 x1 | 4 | 5 | - |
| 반작용휠 x4 | 16 | 38(동시 비배타 가정) | ≤60s |
| 마그네토커 x3 | 3 | 12 | ≤120s, 정상추적과 배타 |
| **합계** | **29** | **45(모드 배타 적용 시)** | - |

정상추적·모멘텀덤핑이 배타 모드이므로 동시 최대 첨두는 반작용휠 첨두(38W)와
마그네토커 첨두(12W)가 겹치지 않아 45W로 수렴 — REQ-EPS-AOCS가 가정한
첨두 45W와 일치. 평균 29W는 EPS 가정(20W)보다 9W 높음 — REQ-EPS-AOCS 회신에서
갱신 요청.

검증: RSS 배분 합계가 sysreq 0.05°/0.005°/s 요구 이내(마진 38%/52%) — sysreq.md 인용.
