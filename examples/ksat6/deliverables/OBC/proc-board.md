# OBC 프로세서보드 설계

입력: examples/ksat6/deliverables/SE/sysreq.md

## 선정
- CPU: LEON4 기반 방사선내성 쿼드코어, 클럭 100 MHz(내성 등급), 이중화(핫스탠바이) 구성.
- FPU/보조: 부동소수 연산 유닛 내장, 별도 SpW 프로토콜 브리지 IP 코어 포함.

## 부하 분석·처리여유
| 태스크군 | 주기(Hz) | 코어 점유율(%) |
|---|---|---|
| 자세제어(AOCS 인터페이스) | 10 | 12 |
| 전력·열 관리 | 1 | 4 |
| 통신·탑재 관리(명령/TM) | 1~10 | 8 |
| 탑재체 데이터 핸들링(버퍼링) | 상시 | 18 |
| OS/스케줄러 오버헤드 | - | 6 |
| **합계 사용률** | | **48%** |
| **처리여유** | | **52%** |

- 판정(sysreq OBC "처리여유 ≥50%"): 52% ≥ 50% → **충족**.

## 전력
- 프로세서보드 소비전력: 6.5 W(정상 운용, 이중화 대기 코어 포함).

## 이중화·고장허용
- 주/부 코어 핫스탠바이, 워치독 타이머로 전환. EDAC은 메모리보드(OBC-MEM)와 연동.

검증: 대표 태스크 셋(위 표)의 실행시간을 사이클 예산 대비 합산해 처리여유 산출.
