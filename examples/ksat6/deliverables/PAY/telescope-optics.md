# PAY 망원경 광학계 (연마·코팅) 설계
입력: examples/ksat6/deliverables/SE/sysreq.md

## 1. 광학계 1차 설계
- 구경: D = 300mm (sysreq 요구치)
- 궤도고도 h = 700km, 요구 GSD = 3m, 검출기 픽셀피치 p = 10µm 가정 시
  초점거리 f = h·p / GSD = 700,000mm × 0.010mm / 3m... (환산) ≈ **2,333mm**
  → f/수 = f/D ≈ **f/7.8** (동축 2반사경 콤팩트 배치로 포장 가능한 범위)
- 회절한계 스팟 크기(550nm 기준): λf/D ≈ 5.2µm < 픽셀피치 10µm →
  광학계가 검출기 대비 과소표본이 아님(§4 MTF 목표의 전제).

## 2. 파면오차(WFE) 예산 — Maréchal 기준 (Strehl≥0.8 → WFE ≤ λ/14 ≈ 39nm RMS @550nm)
| 오차원 | 배분(nm RMS) |
|---|---|
| 주경 연마 형상오차 | 15 |
| 부경 연마 형상오차 | 12 |
| 조립/정렬 잔차 | 15 |
| **열변형(궤도상 ΔT)** | **12** |
| 코팅/제작 잔차 | 10 |
| **RSS 합계** | **28.9** | 요구 39nm 대비 마진 ≈26% |

## 3. 열변형 예산 → 초점면 온도안정도 환산 (REQ-PAY-TCS 근거)
아써말라이즈드(athermalized) 설계 감도계수 ≈ 24nm WFE/°C 가정 시,
열변형 배분 12nm RMS를 지키려면:
**ΔT_허용 = 12nm / (24nm/°C) = 0.5°C** → 촬영(노출) 구간 초점면/광학벤치
온도안정도 **±0.5°C** 요구 (sysreq PAY "기내 보정" 판정 근거 중 하나).

## 4. 데이터율 1차 산출 (REQ-PAY-OBC 근거)
- 지상속도(700km SSO 근사) ≈ 7.5 km/s → 라인시간 = GSD/속도 = 3m/7500m/s
  = 0.4ms → 라인율 ≈ **2,500 line/s**
- 교차궤도 화소수 가정 6,000px(스와스 ≈18km), 12bit/px:
  원시 데이터율(판) = 6,000 × 12bit × 2,500/s = **180 Mbps**(판코로매틱)
  멀티스펙트럼 포함 시 약 **230 Mbps**
- 온보드 압축(~2:1) 후 **100~115 Mbps** → X-band 150Mbps 하향 예산(sysreq) 이내.

## 5. 광학 성능 목표 (PAY-04 판정 기준)
- 시스템 MTF @나이퀴스트(1/(2×10µm)=50 cyc/mm) ≥ **0.20**
- 왜곡 ≤ **0.1%** (전 FOV)

검증: WFE RSS 28.9nm ≤ 요구 39nm(마진26%), 구경 300mm·TDI(PAY-02 인터페이스)·
기내보정(PAY-03 인터페이스) 경로로 sysreq PAY 항목을 충족하도록 배분함.
