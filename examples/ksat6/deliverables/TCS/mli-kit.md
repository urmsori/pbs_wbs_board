# MLI 킷 사양
입력: examples/ksat6/deliverables/TCS/thermal-analysis.md

## 레이어 구성
- 10레이어 Al-Kapton MLI, 유효 방사율 ε* ≈ 0.015.
- 외피 6면 전체 + 라디에이터 개구부(TCS-04에서 정할 면적)만 노출.

## 재단·부착
| 부위 | 재단 매수 | 부착 |
|---|---|---|
| +X/-X 패널 | 각 1매 | 벨크로+접착 스탠드오프 |
| +Y/-Y 패널(SA 힌지 개구부 제외) | 각 1매 | 벨크로+접착 스탠드오프 |
| +Z(안테나 개구부 제외)/-Z(광학 개구부 제외) | 각 1매 | 벨크로+접착 스탠드오프 |
| 배관·하니스 관통부 | 그로밋 12개소 | 개별 실링 |

## 확인
열해석(thermal-analysis.md) 고온 케이스 흡수열 저감을 위한 외피 전면 도포로,
저온 케이스 히터 부담(25W 예산)을 늘리지 않는 범위에서 개구부를 최소화했다.

검증: 재단도 대비 실측 재단 매수 일치, 접지 저항 <10Ω(정전기 방전 방지) 확인.
