# SA 셀 스트링 레이업 (K-SAT 6)
입력: examples/ksat6/deliverables/SE/sysreq.md

## 셀·전력밀도
- 셀: GaAs 3접합, BOL 효율 29.5%, 패킹계수 0.85, 태양상수 1367 W/m²(AM0).
- BOL 전력밀도 = 1367 × 0.295 × 0.85 = 342.7 W/m² (수직입사)
- 3년 LEO 방사선·열싸이클 열화계수 0.88 → EOL 전력밀도 = 301.6 W/m² (수직입사)

## 면적·스트링 구성
- 요구: sysreq "SA: EOL 340W(수직입사)"
- 필요 총면적 = 340 / 301.6 = 1.128 m² → 2윙이므로 윙당 0.564 m² 최소.
- 셀 1매 80×40mm = 32 cm² = 0.0032 m². 배터리 모선 28.8V(8S) 대비 스트링 전압
  여유 필요 → 스트링 직렬 19셀(EOL 고온 Vmp 2.0V/cell → 38.0V > 33.6V 목표, 여유 확보).
- 윙당 10스트링×19셀 = 190셀 → 윙 면적 = 190×0.0032 = 0.608 m² (요구 0.564 m² 대비 7.8% 여유)
- 2윙 총면적 = 1.216 m² → EOL 총출력 = 1.216 × 301.6 = **366.7 W** (요구 340W 대비 마진 7.8%)

## 형상(1차, MECH REQ 회신 전 가정)
- 윙당 전개 길이 1.6 m × 폭 0.38 m (3분할 패널), 힌지축 기준.
- 셀+커버글라스+상호배선 areal mass 0.7 kg/m² → 셀층 질량 = 0.608×0.7 = 0.426 kg/wing
  (패널 기판 구조 질량은 SA-02에서 별도 산출)

## 판정 (sysreq 인용)
- sysreq "SA: EOL 340W(수직입사)" → 산출 EOL 366.7W ≥ 340W, **충족**(마진 7.8%).
- 전개 후 1차모드 ≥0.8Hz 판정은 힌지 강성(REQ-SA-MECH 회신)이 필요해 SA-04에서 확인한다.

검증: EOL 전력밀도·면적 계산으로 sysreq EOL 340W 요구 충족 확인(366.7W, 마진 7.8%).
형상치(길이·폭)는 REQ-SA-MECH 회신 전 잠정 가정이며 SA-04에서 재확인한다.
