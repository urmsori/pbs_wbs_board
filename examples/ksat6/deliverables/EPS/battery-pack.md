# EPS 배터리팩 설계 (K-SAT 6)
입력: examples/ksat6/deliverables/EPS/power-budget.md

## 팩 구성
- 셀: 18650 Li-ion, 3.4 Ah/cell, 3.6V 공칭.
- 구성: 8S3P (직렬8×병렬3) → 팩 공칭 28.8V, 용량 10.2 Ah(293.8 Wh, BOL).
- 질량: 셀 24× 45g = 1.08 kg + BMS·구조 오버헤드(30%) ≈ 1.40 kg.

## DoD 판정 (sysreq: 일식 35분, DoD≤25%)
- EPS-01 일식 에너지 필요치 49.0 Wh(84W×35/60h).
- BOL DoD = 49.0 / 293.8 = **16.7%** ≤ 25%(충족, 마진 8.3pt).
- EOL(3년, 용량열화 20% 가정) 용량 = 293.8×0.80 = 235.0 Wh → EOL DoD = 49.0/235.0 = **20.9%** ≤ 25%(충족, 마진 4.1pt — 수명말기까지 여유 확보).

## 전압 정합
- 팩 전압 범위(2.8~4.2V/cell) = 22.4~33.6V → PCDU 조절모선 28V±4V(24~32V) 범위와 정합(충전종지 33.6V는 PCDU측 배터리 직결단에서만 순간적으로 보임, 조절모선 출력은 24~32V로 별도 레귤레이션).

## 판정 (sysreq 인용)
- sysreq "EPS: ... 일식 35분 배터리 심방전 ≤25%" → BOL 16.7%, EOL 20.9% 모두 충족.

검증: EPS-01 일식 에너지 산출치로 BOL/EOL DoD 계산, 8S3P 18650 팩 구성으로 sysreq DoD≤25% 요구 3년 수명 전 구간 충족 확인.
