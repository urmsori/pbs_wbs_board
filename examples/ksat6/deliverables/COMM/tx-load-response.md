# COMM 송신 부하 회신 (REQ-EPS-COMM 답변)
입력: examples/ksat6/deliverables/COMM/link-budget.md

EPS 전력예산(EPS-01)의 가정치(첨두 55W/듀티 8%)에 대한 COMM 측 실계산
회신이다. 링크 버짓(C-LB) 결론의 X-band RF 10W·효율 30% 가정을 그대로
전력값으로 환산했다. **가정치보다 낮다 — 최신 값으로 EPS 예산을 갱신해
달라.**

## S-band TT&C 상시부하
- 수신기 상시 ON + 송신기 대기바이어스 포함 **8 W** (28V 버스 기준 평균전류 약 0.29A).

## X-band 송신 시 첨두전류·듀티 (28V 버스 기준)
| 항목 | 값 | 근거 |
|---|---|---|
| SSPA RF 출력 | 10 W | 링크버짓 결론 |
| SSPA DC 입력(효율 30%) | 33.3 W | 10W/0.30 |
| 모뎀/여자기/하우스키핑 | 5.0 W | 잠정 설계치 |
| 정재파비 여유 등 | 1.7 W | 잠정 5% |
| **첨두 DC 부하** | **≈40 W** | 33.3+5.0+1.7 |
| **첨두 전류(28V)** | **≈1.43 A** | 40W/28V |
| 일일 총 송신시간 | 53.3분/일 | 60GB/일 ÷ 150Mbps |
| 궤도주기 | 98.8분 (700km SSO) | 2π√(a³/μ) |
| 궤도/일 | 14.6궤도 | 1440분/98.8분 |
| **1궤도당 평균 송신시간** | **약 3.7분** | 53.3분/14.6궤도 (지상국 가시 궤도에 집중, 무가시 궤도는 0) |
| **duty(1궤도 평균)** | **약 3.7%** | 3.7분/98.8분 |

## EPS 가정치와의 차이
- 첨두전력: 가정 55W → 실계산 40W (완화, EPS 여유 증가).
- duty: 가정 8% → 실계산 약 4% (완화).
- EPS-01 전력예산·PCDU 퓨즈 정격 산정 시 이 값으로 갱신 요청.

검증: 링크버짓 EIRP 산출에 쓰인 RF 10W·효율 30% 가정을 DC 부하로 역산,
60GB/일 데이터 예산을 150Mbps로 나눠 일일 송신시간 산출, 700km SSO 궤도주기
공식으로 궤도당 duty 환산.
