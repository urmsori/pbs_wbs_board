# COMM 링크 버짓 (S/X-band)
입력: examples/ksat6/deliverables/SE/sysreq.md

## 공통 가정
- 궤도: 700km SSO, 최소 운용 앙각 10°.
- 최악 슬랜트 레인지: r = sqrt(Re²sin²(el) + 2·Re·h + h²) − Re·sin(el),
  Re=6378km, h=700km, el=10° → **r ≈ 2155 km** (계산상 여유로 2200km로 반올림해 사용).
- FSPL(dB) = 20log10(d_km) + 20log10(f_GHz) + 92.45.
- 기타 손실(대기·편파·지향오차, 강우 제외 clear-sky) = 2.0dB(S-band), 2.5dB(X-band).
- k(볼츠만 상수 항) = −228.6 dBW/Hz/K.

## S-band 하향 (TT&C 텔레메트리, 2Mbps)
| 항목 | 값 |
|---|---|
| 주파수 | 2.2 GHz |
| 위성 송신전력 | 2W = 33dBm = 3dBW |
| 송신단 손실 | 1.0dB |
| 위성 안테나 이득(준전방향, 반구 커버) | 3dBi |
| EIRP | **5.0 dBW** |
| FSPL(d=2200km) | 166.15 dB |
| 기타 손실 | 2.0 dB |
| 지상국 G/T | 5.0 dB/K (중소형 S-band 국 가정) |
| C/N0 | 5.0 −166.15 −2.0 +5.0 +228.6 = **70.45 dBHz** |
| 데이터율(dBHz) | 10log10(2×10⁶) = 63.01 |
| Eb/N0 | **7.44 dB** |
| 요구 Eb/N0(부호화 BPSK, BER 1e-5 + 구현손실 1.5dB) | 6.0 dB |
| **마진** | **+1.44 dB — 여유가 빠듯하다.** 앙각 10° 근방 저앙각 패스에서는 마진이 사실상 소진된다. |

**마진 부족 조치(잠정)**: 운용상 하향 텔레메트리 패스를 앙각 ≥15°로
제한하거나(재계산 시 마진 +2.5dB 수준으로 개선 예상), 위성 안테나 이득을
+2dB 높이는 재설계가 필요하다 — 이번 버짓에서는 안테나 이득을 3dBi로 두고
운용 앙각 제한을 GS 팀(G-OPSPROC)에 정직하게 통보한다.

## S-band 상향 (명령, 64kbps)
| 항목 | 값 |
|---|---|
| 지상국 EIRP | 47 dBW (100W급 송신기 + 접시 이득 약 30dBi 가정) |
| FSPL(d=2200km, 2.1GHz) | 166.0 dB (근사 동일) |
| 기타 손실 | 2.0 dB |
| 위성 G/T | −24 dB/K (준전방향 3dBi 안테나, 시스템 잡음온도 ≈500K) |
| C/N0 | 47 −166.0 −2.0 −24 +228.6 = **83.6 dBHz** |
| 데이터율(dBHz) | 10log10(64×10³) = 48.06 |
| Eb/N0 | **35.5 dB** |
| 요구 Eb/N0 | 6.0 dB |
| **마진** | **+29.5 dB — 매우 여유 있음**(상향은 지상국 고출력이 지배). |

## X-band 하향 (페이로드, 150Mbps)
| 항목 | 값 |
|---|---|
| 주파수 | 8.2 GHz |
| 송신기 RF 출력 | 10W = 40dBm = 10dBW |
| 송신단 손실 | 1.5dB |
| 위성 안테나 이득(지향형, 단일) | 15dBi |
| EIRP | **23.5 dBW** |
| FSPL(d=2200km) | 177.58 dB |
| 기타 손실 | 2.5 dB |
| 지상국 G/T | 22 dB/K (X-band 전용/겸용 중형 국 가정) |
| C/N0 | 23.5 −177.58 −2.5 +22 +228.6 = **94.02 dBHz** |
| 데이터율(dBHz) | 10log10(150×10⁶) = 81.76 |
| Eb/N0 | **12.26 dB** |
| 요구 Eb/N0(QPSK+LDPC, BER 1e-6 + 구현손실 1.5dB) | 6.0 dB |
| **마진** | **+6.26 dB — 양호.** 강우감쇠(clear-sky 제외) 별도 마진으로 소진 가능하니 강우 지역 지상국은 링크가용도 재검토 필요. |

## 결론 (다음 유닛 입력)
- X-band 안테나 이득 15dBi, 지향 반각 조건 → REQ-COMM-STR로 STR에 FOV 확인 요청.
- X-band 송신기 RF 10W(효율 30% 가정 시 DC 입력 ≈33.3W) → REQ-COMM-EPS로 EPS에 첨두전력 허용치 확인 요청.
- OBC↔송신기 데이터 인터페이스(버퍼·프로토콜) → REQ-COMM-OBC로 OBC에 확정 요청.
- S-band 하향 마진 +1.44dB(빠듯함)를 GS 운용 절차(G-OPSPROC)에 앙각 제한으로 반영 요청.

검증: FSPL·C/N0·Eb/N0 계산식 재계산으로 표 수치 확인. 마진 부족(S-band 하향)은
숨기지 않고 위 표에 그대로 기록.
