# 안테나 설계 (S-band 2기 · X-band 1기)
입력: examples/ksat6/deliverables/COMM/link-budget.md, examples/ksat6/deliverables/STR/interface-comm.md

## X-band 안테나 (1기)
| 항목 | 값 |
|---|---|
| 형식 | 패치 배열(지향형) |
| 이득 | 15 dBi (링크버짓 EIRP 산출과 일치) |
| 빔폭(반전력) | 약 22° (±60° 원뿔 내 이득 -3dB 이상 유지하려면 배열 확대 필요 — 아래 주의 참조) |
| 장착 | -Z면(지구지향) 중앙, 본체 최외곽 50mm 돌출, 좌표 (0,0,-450)mm, M4×4 볼트원 φ80mm(STR 회신 그대로 채택) |
| VSWR | ≤1.5:1 |

**주의(정직 기록)**: STR이 확보한 시야는 보어사이트 기준 반각 ±60°(무간섭
기준)이지만, 본 안테나의 실제 반전력 빔폭은 ±11°에 불과하다 — ±60°는 기계적
비간섭 여유이지 안테나 방사패턴 요구가 아니다. 앙각 10°까지 사용하려면
위성이 다운링크 중 안테나 보어사이트를 지상국 방향으로 자세 기동(지구지향
+요잉)해야 한다는 뜻이며, 이는 AOCS 조율이 필요한 사항이다(이번 설계 범위
밖 — 후속 필요시 AOCS에 REQ 발행 권고로 기록만 남김).

## S-band 안테나 (2기, 상호 반대편)
| 항목 | 값 |
|---|---|
| 형식 | 패치(준전방향) |
| 이득 | 3 dBi (링크버짓과 일치) |
| 빔폭 | 약 130° |
| 장착 #1 | +Y면 (0,+400,0)mm |
| 장착 #2 | -Y면 (0,-400,0)mm |
| SA 힌지부 이격 | ≥15° (STR 회신 확인치) |
| 선택 방식 | 자세와 무관하게 항상 한쪽 이득이 확보되도록 수신전력 기준 자동 절체(다이오드 스위치), 두 안테나 동시 결합은 하지 않음(위상간섭 방지) |
| VSWR | ≤1.5:1 |

검증: 이득값이 link-budget.md의 EIRP/G-T 역산치와 일치, 장착좌표·이격이
STR 회신(interface-comm.md)과 일치. X-band 빔폭-FOV 불일치는 숨기지 않고
기록.
