## 구성

- 주 구조: 알루미늄 프레임 (φ260mm 킨네마틱 마운트 인터페이스)
- 리프팅 메커니즘: 볼 스크류 기반 3점 지지 (각 3톤 용량)
- 정렬 시스템: 미세 조정 나사 3축 (XYZ + 회전)
- 안전 장치: 과부하 감지 센서, 긴급 정지 버튼

## 교정/검증 결과

- **질량 지지 능력**: 35kg 적재 시 처짐 ≤ 0.2mm (목표: 유지)
- **각 변위 정확도**: ±0.008° (목표: ≤±0.01°)
- **병진 정확도**: ±8µm (XYZ 각축, 목표: ≤±10µm)
- **반복성**: 10회 반복 측정 편차 ±2µm 이내
- **하중 안정화 시간**: <30초 (안정성 ±0.1µm)

## 사용법

1. 치구를 AIT 스탠드에 견고히 고정
2. 킨네마틱 마운트 상부에 PAY 모듈 올리기
3. 수동 미세 조정 나사로 수평 맞추기 (정수기 사용)
4. 하중이 세 점에 균등하게 분산되는지 확인
5. 최종 위치 확인 후 고정 나사로 락

## 제한사항

- **최대 적재량**: 35kg (이상 적재 금지)
- **동적 하중**: 정적 지지만 가능 (진동 환경 미사용)
