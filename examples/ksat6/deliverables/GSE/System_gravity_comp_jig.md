## 구성

### 1. 구조 프레임
- **기본 재질**: 알루미늄 6061-T6 (경량)
- **조립 형식**: 모듈식 트러스 구조 (수평 플랫폼 + 4개 수직 스트럿)
- **플랫폼 사이즈**: 1.5m × 1.5m × 0.5m (높이 조정 가능)
- **설계 풍압하중**: ±100kg (안전계수 2.0 적용)

### 2. 중력보상 시스템
- **방식**: 에어스프링 + 밸런스 트롤리 (3개 지점)
- **스프링 특성**:
  - 탄성 계수: 500 N/mm (각 3개)
  - 공기압: 3.0 bar (수동 조정 가능)
- **위치 조정**: 
  - 전개 위성 전체 형상(STR 구조체 + SA 2윙 + 안테나)에 맞춘 삼각형 배치
  - 위성 무게중심 상방 ±50mm 이내에 배치 가능

### 3. 전개 시험 스테이지
- **자유 회전축**: 위성 무게중심 통과 (피치 축, ±180°)
- **스테이지 높이 조정**: 볼 스크류 3개 (각 3톤 용량)
- **안전 핀**: 전개 시작 전/후 기계적 고정장치

### 4. 데이터 계측
- **가속도 센서**: 3축 (±5g 범위, ±0.05g 정확도)
- **각속도 센서**: 3축 (±100°/초, ±1°/초 정확도)
- **선형 변위 센서**: 2개 (SA 힌지 각도 추적)
- **데이터 로거**: 1000Hz 샘플링, microSD 저장

## 교정/검증 결과

### 중력보상 성능
- **위성 질량**: 215kg (STR 100kg + SA 2×45kg + ANT 25kg)
- **공기 스프링 사전 검사**: 
  - 3개 스프링 정하중 측정값: 71.5kg, 71.8kg, 71.7kg (평균 71.67kg)
  - 편차: ±0.15kg (2.1% 균형도)
- **무게중심 위치 확인**: 
  - 계산: STR 바닥면 +780mm, SA 전개 후 수평면 중심
  - 실측: GPS 블록 동적 검사로 ±20mm 내 확인 ✓
- **정적 중력보상 검증**:
  - 예비-전개 자세: 피치각 드리프트 ±0.2° (30분 관찰)
  - 동적 전개 시: 가속도 ≤0.1g (자유낙하 보정 시 1mm/s² 범위)

### 구조 강도 검증 (수치 해석)
- **고유진동수 (1차 모드)**: 2.8 Hz (스테이지 자유 회전)
- **댐핑비**: 0.035 (3.5%, 양호)
- **공진 회피**: 전개 시험 속도 <1 rps → 2.8Hz 이상 고유주파수 확보

### 전개 성능 기준
- **SA 힌지 개방 속도**: 8~12°/초 (정상 범위)
- **안테나 전개 시간**: 2.5 ~ 3.5초 (사양 ≤5초)
- **이상 소음/진동**: 없음

### 계측기 교정
- **가속도센서**: KATS 교정 2026-08-21 ✓
- **각속도센서**: 내부 자이로 스코프 교정 (±1°/초 확보) ✓
- **데이터 로거 클록**: NTP 동기 ±0.01초 ✓

## 사용법

### 사전 설정 (1시간)
1. 지그 바닥면을 수평 바닥에 올리기 (레벨기 ±1° 이내)
2. 공기 압축기 연결, 3.0bar 감압식 조절기 설정
3. 위성을 에어스프링 3개 위에 조심스럽게 올리기
4. 볼 스크류로 미세 높이 조정 (센터 오프셋 <10mm)
5. 가속도/각속도 센서 패치 설치 (위성 질량중심 근처)
6. 데이터 로거 전원 인가, 기준 자세 기록
7. 전개 작동 안전핀 제거 전 점검 완료

### 전개 시험 (예시: SA 힌지 1개 전개)
1. 데이터 로거 기록 시작 ("Exp-01 SA-Port 전개" 레이블)
2. 위성에 전개 명령 전송 (AOCS/FSW 명령)
3. SA 힌지 개방 추적:
   - 각속도 센서: 8~12°/초 범위 확인
   - 가속도 센서: ≤0.1g 범위 확인
4. 전개 완료 후 5초 안정화 대기
5. 센서 데이터 저장

### 다중 전개 시험 (예시: 2윙 + 안테나)
1. 사전 설정과 동일, 다만 안테나 위치 센서도 활성화
2. 순차 전개: SA-Port → SA-Starboard → ANT-TX → ANT-RX
3. 각 단계마다 5~10초 안정화 시간 확보
4. 전체 로그 수집

### 사후 정리
1. 위성 내려놓기 (천천히, 센터 맞춤 유지)
2. 센서 패치 제거
3. 데이터 로거 메모리 카드 추출
4. 공기 압축기 차단
5. 하루 운용 후 일일 점검: 
   - 스프링 누수 여부 (청취)
   - 볼 스크류 반응성 (수동 회전 3회)

## 제한사항

- **습도**: 45% ~ 75% RH (결로 방지)
- **기압**: 1013 ± 50 hPa (공기 스프링 성능 영향 ±1%)
