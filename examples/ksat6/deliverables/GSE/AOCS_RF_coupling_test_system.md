## 구성

### 1. 회전 포지셔너 (Azimuth-Elevation 2축)
- **구동 방식**: 스테핑 모터 + 감속기 (1:100)
- **회전 범위**:
  - Azimuth (수평): ±180°
  - Elevation (높이): -10° ~ +90°
- **정위 정확도**: ±0.1°
- **회전 속도**: 1° ~ 60°/초 (프로그래머블)
- **체결 인터페이스**: M6 스레드, 최대 50kg 탑재

### 2. RF 링크 모니터
- **주파수 범위**: 8.4 ~ 8.5GHz (X-band)
- **측정 항목**:
  - 수신 신호 강도 (RSSI): -100 ~ 0dBm ±1dB
  - 비트 에러율 (BER) 실시간 모니터
  - 신호 위상각: ±180° (±2° 정확도)
- **출력**: Ethernet (데이터 로깅) + 아날로그 0~10V (RSSI)
- **샘플링**: 10Hz (100ms 응답)

### 3. AOCS 명령 인터페이스
- **프로토콜**: RS-485 (UART 기반)
- **명령 형식**: AOCS 자세기동 명령셋 (pitch/roll/yaw 각속도)
- **연결**: 위성 OBC <→ 인터페이스 보드 <→ 포지셔너 컨트롤러
- **명령 응답 지연**: <50ms (8.4GHz 링크 동기화 마진)

### 4. RF 급전 시스템
- **지상 송신기**: X-band 모의기 (0dBm 정격, 변조 BPSK/QPSK)
- **안테나 쌍**: 
  - 송신 (고정): 10dBi 혼 안테나
  - 수신 (포지셔너 마운트): 8dBi 소형 혼
- **전송선로**: 저손실 동축 케이블 (LMR-400, 손실 -0.05dB/m)
- **정합**: 50Ω 임피던스 전 구간

## 교정/검증 결과

### 기하학적 정확도
- **포지셔너 정위 편차**: ±0.08° (목표: ±0.1°)
- **빔 포인팅 안정도**: 10초 관찰 시 ±0.05°

### RF 성능
- **자유공간 경로손실** @ 100m 거리:
  - 이론값 (Friis): -137dB
  - 측정값: -136.8dB ±0.5dB
- **수신 감도**: -95dBm @ BER 10^-5
- **RF 체커**: 위상 안정도 ±5° (100ms 간격)

### 동기화 성능
- **자세 명령-포지셔너 동기 지연**: <40ms
- **RF 링크 응답 지연**: <50ms
- **전체 폐루프 지연**: <100ms (요구사항 내)
- **명령 수신 신뢰도**: 99.8% (1000회 연속 명령 중 2건 손실)

### 신뢰성 (72시간 연속 시험)
- **위치 재현성**: ±0.1° 이내
- **RF 드리프트**: ±0.2dB (48시간 후 안정화)
- **수온제어**: 24°C ± 2°C 유지
- **무고장 시간**: 72시간 (예정된 유지보수 제외)

## 사용법

### 사전 준비 (30분)
1. 위성을 포지셔너 상판에 견고히 고정 (M6 나사 4점)
2. AOCS 명령 인터페이스 케이블 연결 (RS-485)
3. X-band 모의기 전원 인가, 15분 워밍업
4. RF 케이블 모두 연결, SWR 체크 (<1.2)
5. 수신 안테나 위치 조정 (RSSI 최대값 확인)

### 시험 진행 (예시: pitch ±10°/초 자세기동)
1. 초기 자세 설정: pitch/roll/yaw = 0°
2. AOCS 명령 시작: pitch_rate = +10°/초
3. 포지셔너 Elevation 축 +10°로 움직이는 동안:
   - RSSI 실시간 모니터링 (스크린샷 기록)
   - BER 추적 (0 유지 확인)
   - 위상각 변화 기록
4. 명령 종료: pitch_rate = 0°
5. 회복 대기: 포지셔너 정위 완료 (±0.1° 이내)
6. 데이터 저장 (타임스탬프 포함)

### 사후 처리
1. X-band 모의기 전원 차단
2. 케이블 분리 및 보관
3. 일일 점검: 모터 음향, 발열 상태 확인
4. 데이터 로그 백업

## 제한사항

- **최대 회전 속도**: 60°/초 (급가속 금지, ≤10°/초² 요구)
- **X-band 송신 전력**: 0dBm 초과 금지 (안테나 손상 위험)
- **임피던스 불정합**: 연결 전 SWR <1.2 필수 (>1.5 시 RF 손상)
- **환경 조건**:
  - 작동 온도: +15°C ~ +35°C
  - 습도: 20% ~ 80% RH (결로 제외)
- **전자기 간섭**: 다른 RF 장비와 최소 2m 거리 유지
- **정기 유지보수**: 
  - 매 50시간 운전마다 모터 재윤활
  - 매 6개월마다 기어 상태 검사
- **안전 - 회전 중 포지셔너 직진 금지**
