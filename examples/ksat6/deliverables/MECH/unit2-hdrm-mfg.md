# 홀드다운·릴리즈(HDRM) 제작 기록
입력: examples/ksat6/deliverables/MECH/unit2-hdrm-design.md

## 제작 실적
- HDRM 4점(윙당 2점×2윙) 조립, 각 점 주+예비 NEA 장착, 케이블 예압 실측.

## 실측값
| 항목 | 설계치 | 실측(4점 평균) |
|---|---|---|
| 예압 하중 | 320 N | 315 N |
| 주 NEA 구동전류 | 규격 이내 | 규격 이내(전수 확인) |
| 예비 NEA 절연저항 | ≥10MΩ | 12.4MΩ |

주 NEA 단독 구동 모의방출 시험(예비 미작동 가정): 정상 방출 확인 — 단일고장 허용 설계 실증.

검증: 예압315N(설계320N 대비 오차1.6%), 주NEA 단독 방출 성공(단일고장 허용 실증).
