# SA→AOCS 회신: 태양전지판 전개 구조모드·외란 인터페이스

입력: examples/ksat8/deliverables/SE/sysreq.md

## 전개 후 1차모드·감쇠비 (설계 목표치, SA-U1-DSN 착수 시점 잠정)
- 2윙 대형 패널(3접힘 패널×2윙, 리지드 패널+힌지) 전개 후 1차모드(윙 굽힘)
  설계 목표: **0.12 Hz**(sysreq 0.1Hz 대비 마진 20%).
- 구조 감쇠비: ζ ≈ 0.5%(전형적 태양전지판 알루미늄 허니콤+힌지 마찰 감쇠,
  실측 전 가정치).
- MECH 힌지강성 회신(REQ-SA-MECH-힌지, 회신 대기 중) 확정 시 재계산 필요
  — 현재는 힌지강성 잠정 6,000 N·m/rad 기준값.

## 태양추적(SADA, 1축 구동) 외란 토크
- SADA 스테퍼 구동 스텝 외란: 첨두 **0.05 N·m**, 스텝 주파수 1/60 Hz
  (분당 1스텝, 저주파 준정적 — AOCS 대역폭과 직접 간섭 가능성 낮음).
- 연속 추적 모드(옵션, 고분해능 스테핑) 시 등가 외란: 첨두 0.01 N·m,
  주파수 성분 0.1~0.5 Hz 대역 — SA 1차모드(0.12Hz)와 근접하므로 AOCS
  대역폭 설계 시 이격 확인 요청.

## 이격 마진 판정 요청
- SA 1차모드(0.12Hz 목표)가 AOCS 제어대역폭의 5배 이상이 되려면 AOCS
  대역폭은 **0.024 Hz 이하**여야 함 — 귀 팀 설계 대역폭 회신
  (REQ-SA-AOCS-플러터, 발신) 바람. 회신 전까지 SA는 위 목표치로 설계를
  진행하며, 대역폭이 이보다 크면 노치필터 또는 힌지강성 상향이 필요할 수
  있음(리스크 기록).

검증: 1차모드 0.12Hz(목표)·감쇠비0.5%·SADA 외란 0.05N·m(스텝)/0.01N·m
(연속) 회신, 이격 마진 조건(대역폭≤0.024Hz) 제시.
