# OBC → FSW 회신: 레지스터 맵·드라이버 인터페이스

1. **레지스터 맵**: 0x0000–0x0FFF TM 수집 버퍼(서브시스템별 블록,
   §2 배정), 0x1000–0x13FF TC 디코더 큐, 0x1400–0x14FF 이중화 상태
   레지스터(주/예비 헬스 비트·절체 사유 코드·마지막 절체 시각),
   0x1500– 워치독/전원 상태.
2. **드라이버 인터페이스**: `bus_read(addr,len)`/`bus_write(addr,buf,len)`
   폴링 API + 인터럽트 벡터 IRQ4(TC 수신)·IRQ5(버스 오류)·IRQ0(워치독,
   1s 미갱신 시 하드웨어 리셋).
3. **이중화 절체 조건·소요시간**: 워치독 무응답 3회 연속 또는 버스 오류
   플래그 연속 5프레임 시 콜드 절체 트리거, 절체 소요 ≤500ms(부팅
   제외) — FSW는 절체 트리거 직전 크리티컬 상태(모드·최근 TC 시퀀스
   번호)를 EEPROM 스냅샷에 주기 기록해야 한다(주기 1s 권고).

검증: obc-design.md §3과 동일 출처, FSW-U1 설계 입력으로 즉시 사용 가능.
