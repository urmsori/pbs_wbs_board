# OBC → COMM 회신: TM/TC 데이터 인터페이스

1. **버스·전기규격**: MIL-STD-1553B 이중 버스(주/예비), 1Mbps, 트랜스포머
   결합, 커넥터는 9핀 트라이엑스 등가(표준 1553 스텁 커플러).
2. **TM 프레임**: 32워드/프레임, 프레임 주기 1Hz(고속 TM은 서브프레임
   4Hz), COMM 배정 TM 500점은 이 프레임 구조로 충분히 수용된다
   (obc-design.md §2).
3. **TC 프레임**: 16워드/프레임, 수신률 최대 10cmd/s, 이중화는 콜드
   스탠바이(주 계통 버스 오류 시 예비 버스로 자동 절체, §3의 이중화
   상태 레지스터 IRQ5로 통지).

검증: obc-design.md의 버스·레지스터 정의와 정합.
