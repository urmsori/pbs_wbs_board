# OBC 기본설계 — 이중화 위성관리컴퓨터 (OBC-U1-DSN)

## 1. 아키텍처
- 이중화 구성: 주(Prime)/예비(Redundant) OBC 유닛 각 1식, 상호 콜드
  스탠바이(예비는 전원 OFF, 워치독 무응답 시 지상 명령 또는 자동
  절체 시퀀서가 기동). 절체 소요시간 목표 ≤500ms(전원 인가~부팅 완료
  별도, 콜드 절체는 초 단위이므로 크리티컬 루프는 핫 백업 레지스터
  스냅샷을 EEPROM에 주기 저장해 재기동 시 상태 복원).
- CPU: 방사선내성 32비트 프로세서(LEON류 등급) 이중 코어, 워치독 타이머
  하드웨어 내장.
- 메모리: 코드 EEPROM(부팅), 작업 RAM(SEU 대비 EDAC), TM 순환버퍼용
  대용량 플래시(최근 24시간 TM 로그).

## 2. TM/TC 처리 예산 (sysreq: TM 8,000점·TC 2,000점)
| 구분 | 배정 | 비고 |
|---|---|---|
| EPS | 900점 | 전압/전류/온도/SOC 채널 |
| TCS | 700점 | 온도센서·히터 상태 |
| PROP | 600점 | 탱크압력·밸브·추력기 |
| AOCS | 900점 | 자세·휠·센서 |
| COMM | 500점 | TT&C 상태 |
| PAY | 2,600점 | 24채널 × 채널별 다점(REQ-OBC-PAY-TM 회신으로 확정) |
| OBC 자체(이중화 상태·버스 헬스) | 800점 | |
| 여유 | 1,000점 | 설계 마진 |
| **합계** | **8,000점** | TC 2,000점은 위 배정의 1/4 비율로 채널별 산정(예비 포함) |

PAY 채널당 TM 점수는 REQ-OBC-PAY-TM 회신(잠정, 아래 §4)으로 채널당
~100점(고속 50 + 저속 50)을 반영해 24채널×~108점 ≈ 2,600점으로 배정했다.

## 3. 버스·레지스터 맵 (FSW·타 트랙 공통 인터페이스)
- 서브시스템 버스: MIL-STD-1553B 이중 버스(주/예비), 1Mbps.
- 레지스터 맵 구조(오프셋은 예시):
  - 0x0000–0x0FFF: TM 수집 버퍼(서브시스템별 블록, §2 배정 순서)
  - 0x1000–0x13FF: TC 디코더 큐(명령 수신·검증 상태)
  - 0x1400–0x14FF: 이중화 상태 레지스터(주/예비 헬스 비트, 절체 사유
    코드, 마지막 절체 시각)
  - 0x1500–: 워치독·전원 상태
- 드라이버 인터페이스: 서브시스템 버스 드라이버는 폴링 API
  `bus_read(addr,len)`/`bus_write(addr,buf,len)` + 인터럽트 벡터
  IRQ4(TC 수신), IRQ5(버스 오류), 워치독 IRQ0(SW 미갱신 시 하드웨어
  리셋, 주기 1s).
- I/O 커넥터: 아날로그/디스크리트 모니터링 채널 96핀 이중화 커넥터
  2식(주/예비 계통 분리), 실드 접지핀은 커넥터 외곽 4핀(1,32,65,96)에
  배치해 하니스 실드와 단일점 접지.

## 4. 잠정 처리한 외부 인터페이스
COMM(TT&C 버스 규격)·PAY(채널당 TM 점수)는 REQ-OBC-COMM-IF·REQ-OBC-PAY-TM으로
요청했다. 회신 전까지 위 §2·§3은 sysreq.md의 COMM(TT&C S-band 상시)·
PAY(24채널) 요약에 근거한 잠정치이며, 정식 회신 도착 시 정정한다.

검증: TM 8,000점/TC 2,000점 예산 배정이 sysreq 합계와 일치, 이중화 절체
경로 명시.
