# REQ-FSW-AOCS-TMTC 회신 — AOCS TM/TC·제어 인터페이스

입력: examples/ksat8/deliverables/AOCS/u1-dsn.md, examples/ksat8/board/REQ-FSW-AOCS-TMTC.md

## TM 목록(발췌)
- 자세오차 3축(°), 각속도 3축(°/s), 휠속도 4채널(rpm), 휠토크 4채널(N·m),
  별추적기/자이로 상태 플래그, 모멘텀 축적량 3축(N·m·s), 언로딩 진행상태.

## TC 목록(발췌)
- 모드전환(획득/정상지향/세이프), 휠 바이어스 명령(4채널), 언로딩 개시/중지,
  대역폭·게인 테이블 선택.

## 제어 알고리즘 인터페이스
- 실행 주기: **10 Hz**(대역폭 0.02Hz의 500배).
- 입력벡터: 자세오차(3), 각속도(3) — 별추적기/자이로 TM 기반.
- 출력벡터: 휠 토크 명령(4채널, N·m).
- 지향 0.05°(3σ) 유지 최소 샘플링 주기: **100ms(10Hz)** — 위와 동일.

검증: 실행주기10Hz(대역폭 500배 여유), TM/TC 목록·인터페이스 회신
