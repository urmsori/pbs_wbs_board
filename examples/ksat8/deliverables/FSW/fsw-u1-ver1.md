# 검증 1단계 — 코드리뷰·단위시험

- 코드리뷰: 태스크 7종(§1) 각각이 설계서의 주기·로직과 1:1 대응하는지
  확인 — AOCS 태스크가 실제로 10Hz 틱에 바인딩됐는지, PROP 잠금 계층이
  TC 디코더보다 앞단에 배치됐는지 코드 경로 추적으로 확인. 이상 없음.
- 단위시험: TCS 히터 이력제어 로직에 경계값(설정점±데드밴드 정확히
  일치하는 온도)을 주입해 상태 전이가 표에 명시된 대로 동작함을 확인.
  PAY 시퀀서 큐에 동시 3건 전환 명령을 주입해 100ms 간격 순차 실행을
  확인.

검증: 태스크-설계 1:1 대응 확인, 경계값 단위시험 통과.
