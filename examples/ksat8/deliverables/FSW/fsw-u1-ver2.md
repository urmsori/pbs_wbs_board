# 검증 2단계 — 통합·HIL 시험

- OBC 하드웨어 시뮬레이터(1553B 버스 모사)에 관리 SW 로드 — 7태스크
  동시 실행 중 AOCS 10Hz 틱 지터 <2ms(요구 대비 여유), 나머지 1Hz
  태스크 지연 없음.
- PROP 잠금 계층 통합시험: 자세안정 플래그 미설정 상태에서 추력기
  점화 TC 주입 → 정상 거부(NAK) 확인, 플래그 설정 후 재주입 → 정상
  arm+fire 2단계 수락 확인.
- 워치독 kick 누락 주입(강제 1.2s 지연) → IRQ0 리셋 경로 정상 트리거
  확인(fsw-hw-reply.md 요구와 일치).
- COMM TC 검증 파이프라인(잠정 로직)은 통과했으나 **COMM-U1 확정 후
  재시험 필요**로 기록.

검증: 7태스크 동시 실행 스케줄링 정상, PROP 인터락 정상 거부/수락,
워치독 리셋 경로 정상. COMM 항목은 잠정 통과(정정 시 재시험).
