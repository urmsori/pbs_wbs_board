# 반사판 2기+SA 2윙 동시전개 대형 중력보상 지그(INT-TST-1용) - 장비 준비 기록

## 장비 구성
- **대형 중력보상 프레임**
  - 위성 본체 전체 지지(600×600×800mm, ~150kg 수용)
  - 4축 독립 중력보상 아암 (반사판 2기×2축, SA 2윙×2축)
  - 각 축별 스프링-태아로-풀리 시스템 (클리어런스 ±5mm)
  - 프레임 강성: 고유진동수 >100Hz
- **전개 축 모니터링**
  - LVDT 센서: 4축 변위 측정 (±500mm 범위, 0.1mm 분해능)
  - 발화선(pyro-cutter) 구동 신호 모니터
  - 구동 충격·전개각 및 상호 간섭 감지
- **안전 장치**
  - 비상 멈춤 브레이크 (4축 각 1개)
  - 전개 충격 흡수 댐퍼 (각 기구 말단)
  - 위성 본체 낙하 방지 안전핀
- **이전 소형 지그**
  - 반사판 단독 전개(MECH-U1-TST 재확인용)
  - 사전 점검 목적으로 재사용 가능
- **구성 완료**: ✓
- **형식 점검**: ✓
- **안전성 검증**: ✓

## 교정 결과
| 항목 | 보정값 | 정확도 |
|------|-------|-------|
| 반사판 1기 중력보상(고정) | 잠금토크 0.3Nm | ±5% |
| SA 1윙 중력보상(고정) | 잠금토크 0.2Nm | ±5% |
| 클리어런스(상호간섭 검증) | ±5mm 이내 | 합격 |
| LVDT 센서 응답 | 0.1mm/1ms | 합격 |
| 고유진동수 | 127Hz(1축 기준) | >100Hz ✓ |
| 브레이크 응답 시간 | <100ms | 합격 |

## 사용법
위성 통합 본체를 대형 지그 프레임에 수평 안내로 거치. 4개 중력보상 아암을 각 기구(반사판×2, SA×2)에 정렬 후 발화신호 입력. 전개 과정에서 LVDT 센서로 변위·타이밍·상호 간섭을 기록. 초과 클리어런스 또는 비정상 충격 감지 시 비상 브레이크 작동.

## 제한사항
- 위성 질량: 최대 150kg (무게 초과 시 중력보상 오차 증가)
- 전개 속도: 제어 시스템으로 제한(>200mm/s 주의)
- 환경: 실험실 온도 18~25°C (스프링 특성 드리프트 제어)
- 전개 횟수: 50회 연속 시험 후 부품 점검 필수 (마모 감시)
- 관리: 월 1회 윤활, 분기 1회 중력보상 재조정 필수
- 안전성: 각 운영 시작 전 비상브레이크·안전핀 기능 확인 필수
