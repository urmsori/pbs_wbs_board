# 100V 고전압 통합 전원 SCOE(INT-TST-2 15kW 통합부하시험용) - 장비 준비 기록

## 장비 구성
- **통합 전원 SCOE 형식**
  - 입력: 100V 고전압 AC 유틸리티
  - 출력: ±100V DC, 15kW 최대 용량
  - 보호 기능: 제한전류(50A), 접지분리(>100MΩ), 비상차단 인터록
  - 채널 구성: PAY(11kW)/EP(3kW)/COMM(220W)/히터(200W)/HK(80W) 분기
  - 다채널 전류 모니터링: 8채널 이상, 10mΩ 션트
- **구성 완료**: ✓
- **형식 점검**: ✓
- **기본 안전성 검증**: ✓

## 교정 결과
| 항목 | 보정값 | 정확도 |
|------|-------|-------|
| 출력 전압 (±100V) | 0부터 ±100V | ±0.5% |
| 출력 전류 (15kW) | 0부터 150A | ±1% |
| 채널별 전류 시한링(50A) | 합격 | 확인됨 |
| 비상차단 응답 시간 | <10ms | 합격 |
| 접지분리 저항 | >100MΩ @ 500V AC | 합격 |

## 사용법
위성 비행모델의 PCU를 100V DC 입력에 접속. 각 채널(PAY/EP/COMM/히터/HK)을 위성 서브시스템 부하에 개별 연결 후 통합 부하 프로파일 인가. 모든 채널 전류를 동시 모니터링하며 15kW 초과 시 자동 차단.

## 제한사항
- 지속 정격: 15kW (6시간 이상 연속 운영 시 냉각 필요)
- 채널별 분기 전류: 최대 50A (개별 인터럽터로 제한)
- 환경: 실험실 온도 20±5°C, 습도 <70% RH
- 유지보수: 월 1회 절연 시험, 분기 1회 전기 안전성 검증 필수
- 교정: 1년 주기 또는 1,000시간 운영 후 필수
