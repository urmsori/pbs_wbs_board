# Ka 24채널 동시 페이로드 시험 장비(INT-TST-3 RF 종단간용) - 장비 준비 기록

## 장비 구성
- **Ka 24채널 신호원/전력분배 시스템**
  - RF 신호원: 24채널 독립 생성 (f=14.0~14.5GHz Ka-band)
  - 위상/진폭 제어: 개별 채널 독립 제어 가능, ±45° 위상, ±10dB 게인
  - 전력 출력: 각 채널 +23dBm (±0.5dB 균일성)
  - 통합 전력분배기: 24-way 분배(삽입손실 <2dB/채널)
- **다채널 EIRP 동시 측정 장비**
  - 수신 안테나 배열: 24채널 프로브 수신기 (컴팩트 레인지 챔버 #1 연동)
  - 측정 범위: EIRP 30~60dBW
  - 측정 정확도: ±0.5dB (2σ)
  - 샘플레이트: 100ms/채널(24채널 동시계측)
- **노이즈 로딩 시험 장비** (기존 재사용)
  - NPR 측정 범위: 15~25dB
  - 재사용 가능: 대표 채널 NPR 베리피케이션용
- **구성 완료**: ✓
- **형식 점검**: ✓
- **동작 확인**: ✓

## 사용법
위성 통합 형상에서 PAY 도파관-안테나 체인을 컴팩트 레인지 챔버 #1에 정위, 24채널 신호원으로 동시 구동. 각 채널의 EIRP를 동시 측정, 데이터 기록. NPR 검증은 대표 채널에 대해 기존 노이즈로딩 장비 사용.

## 제한사항
- RF 신호 주파수: Ka-band 14.0~14.5GHz 고정 (S-band 미지원)
- 채널당 최대 출력: +23dBm (이상 시 증폭기 보호차단)
- 동시계측 채널 수: 최대 24채널 (부분 계측 시 적응 필요)
- 환경: 챔버 내부 온도 20±3°C
- 케이블 길이: 신호원-분배기 <10m (위상 드리프트 제어)
- 교정: 2주 주기 또는 100시간 운영 후 필수
