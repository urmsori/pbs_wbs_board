# 히터 예산 요구 (채널 배전) — TCS → EPS 회신
입력: examples/ksat8/board/REQ-EPS-TCS-히터.md, examples/ksat8/deliverables/SE/sysreq.md

## 1) 히터 채널 수·정격
| 채널 | 대상 | 정격(W) |
|---|---|---|
| H1 | 배터리 팩 히터 | 40 |
| H2 | 이원추진제 배관/탱크 히터(동결 방지) | 60 |
| H3 | 추력기 캐터리스트/밸브 히터 | 30 |
| H4 | 구조부(중앙실린더 북측) 히터 | 25 |
| H5 | 구조부(중앙실린더 남측) 히터 | 25 |
| H6 | 예비(마진) | 20 |
| **총합** | | **200W** |

## 2) 제어 방식·최대 동시 점등
- 전 채널 서모스탯 자동 제어 기본, H2(추진배관)는 커맨드 오버라이드 가능(FSW TC).
- 최대 동시 점등 시나리오(이클립스 진입 직후, 전 채널 동시): 200W, 100V 버스 기준
  전류 합산 2.0A로 배전 설계.

## 3) 이클립스 중 필수 채널·우선순위
1순위: H1(배터리, 배터리 2.4kWh 이클립스 방전 중 저온 방지 필수)
2순위: H2(추진제 동결 방지, 이원추진제 응고점 이상 유지)
3순위: H3(밸브 동작 확보)
4순위 이하: H4/H5/H6(구조부, 이클립스 짧으면 자연 냉각 여유 있음).

주: sysreq TCS 방열 6kW는 TWTA 방열 예산이며 위 200W 히터는 별도 저전력
예산(작동범위 -10~+60°C 유지용)이다. EPS-U1-DSN 확정 회신이 오면 정정한다(잠정치).
