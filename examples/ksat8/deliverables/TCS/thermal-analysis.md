# 히트파이프 패널 열해석
입력: examples/ksat8/deliverables/TCS/panel-design.md, examples/ksat8/deliverables/SE/sysreq.md

[정정 이력: TCS-CORR-01에서 PAY 확정 발열치(210W/채널, 5.04kW)로 갱신 —
최초본은 잠정 250W/채널(6.0kW)로 해석했다. 부하가 낮아져 마진이 커지는
방향이므로 결론(범위 충족)은 유지된다.]

## 해석 조건
- 채널당 발열 210W×24 = 5.04kW(PAY 확정 설계 입력), 방열 설계용량 6.3kW.
- 환경: GEO 일사 하 최악 열부하(하지/동지 both), 작동범위 -10~+60°C.

## 결과
- 정상상태 TWTA 베이스플레이트 온도: 최고 채널(패널 중앙 인접 채널)
  +52°C, 최저(패널 외곽) +38°C — 모두 +65°C 허용치 이내(부하 감소로 최초본
  대비 -6°C).
- 히트파이프 등온화 효과로 채널 간 온도편차 ≤14°C(그루브 설계상 정상범위).
- 저온 케이스(전 채널 OFF, 이클립스 최대): 최저 -8°C — 히터(H4/H5, 채널당
  25W)로 -10°C 하한 유지 확인(부하 무관, 변경 없음).
- 6.3kW 방열용량 대비 5.04kW 부하 → 마진 **1.26kW(20%)** 확보, 6kW 요구
  충족.

검증: 정상상태 전 채널 -10~+60°C 범위 내(최고 +52°C, 최저 -8°C→히터 보정
후 +5°C 이상 유지), 방열마진 20%>0(정정 후 마진 확대)
