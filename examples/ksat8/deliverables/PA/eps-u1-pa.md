# PCU 기능시험 절차·판정기준 입회 확인

입력: examples/ksat8/deliverables/EPS/pcu-inspection.md (PA-EPS-U1 요청
게시글이 지정한 대상 산출물 — PCU 최종검사 합격)

## 입회 확인 사항
- 판정기준: 100V±2V, 15kW 전 채널, PAY 인러시(12.8A/10ms) LCL 트립여유
- 시험형상 대조: PCU 최종검사(pcu-inspection.md) 합격 형상과 시험 절차서
  대상이 일치함을 확인
- 계측 준비: CAL-EPS-U1(전자부하·DAQ 교정 완료, 12.8A/10ms 과도파형
  포착 가능 확인)·FAC-EPS-U1(전기시험실 #1 예약 확정)과 일정 정합 확인

## 판정
절차서에 판정기준(100V±2V, 15kW, LCL 트립여유)이 명시되어 있고 시험형상이
최종검사 합격 형상과 일치함을 확인 — 입회 승인.

검증: 절차서 판정기준(100V±2V, 15kW, LCL 트립여유) 명시 확인, 시험형상
일치 확인, 입회 완료.
