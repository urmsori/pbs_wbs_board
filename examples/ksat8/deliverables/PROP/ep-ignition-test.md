# 전기추진 계통 점화시험
입력: examples/ksat8/deliverables/PROP/ep-review.md, examples/ksat8/deliverables/PROP/ep-design.md

## 시험 결과
- 4기 이온추력기 개별 점화시험(진공챔버, 배경압 ≤1×10⁻⁵ Torr): 전 채널
  정상 점화, 채널당 소모전력 980~1,015W(정격 1,000W ±2% 이내) — 합격.
- 추력 측정(추력대 검증): 채널당 68~72mN(설계치 70mN ±3% 이내) — 합격.
- 2채널 동시 점화(최대부하 모드): 버스 전류·전압 리플 EPS 확약치
  (≤100mVpp) 이내 확인 — 합격.
- 최소펄스 50ms 점화 응답성 확인 — 합격.

판정: 합격 — 비행모델 인도 가능
검증: 채널당 전력 1,000W±2%, 추력 70mN±3%, 2채널 동시 리플≤100mVpp 모두
규격 이내
