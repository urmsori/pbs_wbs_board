# HAR→STR 회신: 하니스 라우팅 경로·관통부

입력: examples/ksat8/deliverables/STR/str-u1-dsn.md, examples/ksat8/deliverables/STR/str-u2-dsn.md

## 구조 배치(구획)
중앙 실린더(중앙튜브+상/하데크+측판4매) + 남/북 패널(STR-U2, 상판 대칭).
패널 간 거리(측판-패널): 약 150mm(케이블 트레이 여유).

## 관통부(그로밋·브라켓) 예정 위치
- 상판: 4개소(반사판·SA 급전/구동 하니스, Ø40mm 그로밋).
- 하부데크: 2개소(탱크·추력기 배관 인접 회피 경로, 전력 배선 별도 경로, Ø40mm).
- 측판-데크 접속부: 2개소/측판(패널 내부 배선 인입).

## 고전압(100V) 배선-구조 접지 이격
- 이격 거리: **≥25mm**(비절연 기준), 절연슬리브 사용 시 **≥10mm**로 완화 가능.

검증: 관통부 8개소 위치(상판4·하부데크2·측판접속부2/측판), 고전압-접지 이격
25mm(절연시10mm) 회신
