# K-SAT 8 시스템 요구사항 (rev.1)
입력: 없음 (임무 정의 — 유일한 무입력 산출물)

## 임무
GEO(동경 116°E), Ka-band 24채널 중계기, 수명 15년, 발사질량 ≤3,500kg.

## 시스템 예산
| 항목 | 할당 |
|---|---|
| 발사질량 | ≤3,500 kg (추진제 포함) |
| 전력 | 공급 EOL 16kW / 탑재체 11kW |
| 버스 전압 | 100V ± 2V |
| 안테나 지향 | 0.05° (3σ) |
| 중계기 | 24채널 × 36MHz, EIRP 52dBW/채널 |
| 수명 | 15년 (GEO 유지 Δv 750m/s) |

## 서브시스템 상위 요구 (요약)
- STR: 중앙 실린더 1차모드 ≥30Hz(횡), 질량 ≤380kg.
- MECH: 반사판 2기(2.4m)·SA 2윙 전개, 단일고장 허용.
- TCS: TWTA 패널 히트파이프, 작동 -10~+60°C, 방열 6kW.
- PROP: 이원추진제(진입)+전기추진(유지), Δv 합계 2,250m/s.
- EPS: 100V 버스, 15kW 배전, 배터리 이클립스 2.4kWh.
- SA: EOL 16kW, 전개 후 1차모드 ≥0.1Hz.
- AOCS: 지향 0.05°, 모멘텀 휠 + 이온추력기 언로딩.
- OBC: TM 8,000점·TC 2,000점 처리, 이중화.
- COMM: TT&C S-band 상시, 레인징.
- PAY: 24채널, 채널당 EIRP 52dBW, NPR ≥18dB.
- HAR: 100V 절연·대전류, 도파관 손실 ≤0.8dB.
- FSW: 전 서브시스템 관리 — **각 팀의 TM/TC 목록·제어 파라미터를 요청으로 받아라**.
- GS: 관제소 적합성, IOT 30일 계획.

검증: 각 팀 산출물이 자기 항목을 수치 인용해 판정한다.
