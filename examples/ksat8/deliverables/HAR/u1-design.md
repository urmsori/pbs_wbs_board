# HAR-U1 100V 전력 하니스 설계

입력: examples/ksat8/deliverables/SE/sysreq.md, REQ-HAR-EPS-배전(회신 대기
타임아웃 — 잠정 가정 사용), REQ-HAR-OBC-핀맵(회신 대기 타임아웃 — 잠정
가정 사용), REQ-HAR-STR-경로(회신 대기 타임아웃 — 잠정 가정 사용)

## ICD 상태
REQ-HAR-EPS-배전·REQ-HAR-OBC-핀맵·REQ-HAR-STR-경로를 HAR-U1-DSN-01
착수와 동시에 발행(track: EPS/OBC/STR), 8회×20초 폴링에도 회신 없음 →
**잠정 가정**으로 설계 진행(아래 명시). 정식 회신 도착 시 CHK 단계
이후에서 재확인 필요(리스크로 module-fm.md에 기록).

### 잠정 가정
- 모선 전압: 100V±2V (sysreq.md 인용)
- PCU 배전 출력 커넥터: 원형 8핀 파워 커넥터(잠정 p/n PCU-PWR-J1), 채널당
  1핀
- 채널 전류 정격(잠정): 연속 30A/핀
- 100V 절연 이격거리(잠정): 도체간 3mm, 대지간 4mm (항공우주급 100V급
  일반 관행치)
- STR 라우팅(잠정): PCU→부하 간 편도 4m(중앙 실린더 종단→패널 관통부
  경유), 구조 관통부는 그로밋 접지 브라켓 사용
- OBC 모니터링 인터페이스(잠정): 전압/전류 텔레메트리 아날로그 2채널/
  전력계통, MDM류 커넥터(형식 미정, 여유 배선 확보)

## 부하 산정 (대표 채널: PAY TWTA 뱅크 주배전)
- sysreq.md: 탑재체 11kW, 100V 버스 → 채널 다중화 가정(대표 단일 채널
  30A로 설계 검토, 배전 토폴로지는 EPS 회신 확정 후 세부 확정)
- 잠정 채널 정격(30A) 대비 설계 전류 30A로 마진 없는 최악 조건 가정
  (보수적 검토)

## 배선 설계
- 왕복 배선 길이(PCU→부하): 4m 편도 → 8m 왕복
- 도체: AWG10 항공우주급 PTFE 절연(절연정격 200°C), 단면적 5.26mm²
- 배선 저항 R = ρ·L/A = 1.68e-8 × 8 / 5.26e-6 = **0.02554Ω**
- 전압강하 ΔV = I×R = 30A × 0.02554Ω = **0.766V**
- 전압강하율 = 0.766V / 100V = **0.77%**

## 전압강하 판정 기준 (내부 공학 기준)
sysreq.md HAR 항목은 "100V 절연·대전류"만 규정하고 전압강하 상한을
직접 수치화하지 않는다. 버스 레귤레이션 공차가 100V±2V(±2%)이므로,
하니스 IR강하가 레귤레이션 여유를 과도하게 잠식하지 않도록 **내부
설계 기준 ΔV ≤1%(≤1.0V)**를 채택한다(RVW-A 단계에서 재확인).

## 커넥터 배정
- PCU측: 잠정 PCU-PWR-J1(8핀 원형, 채널당 1핀, 30A/핀)
- 부하측: HAR 측 정합 커넥터 동일 형식(대향)
- 절연: 도체간 3mm·대지간 4mm 이격(잠정), 커넥터 포팅 처리로 저압
  환경(발사 상승 중 Paschen 최소점 부근) 코로나 리스크 저감

## 검도 대상
- 케이블 사양표, 커넥터 핀맵, 전압강하 계산서(위), 절연 이격거리 표

## 판정 (전압강하, 내부 기준 ≤1%)
설계 예측치 0.77% ≤ 1% → **여유 있음**(23% 마진). EPS 실측 커넥터
정격 확정 시 재계산 필요(잠정 가정 리스크).
