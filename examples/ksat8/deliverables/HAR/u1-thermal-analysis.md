# HAR-U1 100V 전력 하니스 줄열(I²R) 해석

입력: examples/ksat8/deliverables/HAR/u1-design.md

HAR-U1-DSN-01 설계에 대해, 최악 조건인 **주버스 피더**(PCU→주배전
버스바, 150A 정격, EPS 회신 참조는 CHK 단계에서 반영 예정이므로 여기서는
DSN 잠정 가정 체계상 동일 구조의 대표 트렁크로 검토)의 줄열 발열이
연속 운전 중 도체·절연 허용온도를 넘지 않는지 열해석한다.

## 조건
- 전류: 150A(주버스 피더, 연속)
- 배선: 구리 AWG2(단면적 33.6mm²), PTFE 절연(절연정격 200°C), 왕복
  길이 3m(편도 1.5m, 잠정)
- 저항: R = ρL/A = 1.68e-8×3/33.6e-6 = **1.50mΩ**
- 발열: P = I²R = 150² × 0.0015 = **33.8W**

## 결과
- 위성 내부 하니스 번들(자연대류 억제, 복사 위주) 조건에서 도체 온도
  상승 ΔT ≈ 25°C 가정(유사 번들 경험치)
- 최악 환경온도(sysreq TCS 상한 +60°C) 기준 최고 도체온도 = 60+25 =
  **85°C**
- 절연정격 200°C 대비 **115°C 마진**

검증: 주버스 피더 150A 연속 조건 최고 도체온도 85°C ≤ 절연정격 200°C(대여유)
