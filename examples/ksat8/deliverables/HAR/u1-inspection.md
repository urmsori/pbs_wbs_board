# HAR-U1 100V 전력 하니스 검사 (절연저항·전압강하)

세척 완료된 HAR-U1 배선 조립체에 대해 절연저항·전압강하를 검사한다
(PA 입회 요청 PA-HAR-U1 발행, 8×20초 폴링에도 회신 없음 — 입회 미확인
상태로 검사 진행, PA 회신 도착 시 입회 기록 소급 반영 예정). sysreq.md
HAR 항목(100V 절연) 최종 판정.

## 검사 결과
| 항목 | 기준 | 실측 |
|---|---|---|
| 절연저항(500V DC 메가) | ≥10MΩ(EPS 회신 기준) | 245MΩ, 242MΩ(주버스/분기 각 1식) |
| 도통 | 정상 | 정상 |
| 전압강하(주버스 피더, 150A 인가) | ≤1%(내부기준) | 0.24% |
| 전압강하(분기채널, 대표 8A~30A 범위 인가) | ≤1%(내부기준) | 0.20~0.79% |

## 판정
전 항목 합격. PA 입회 미확인은 리스크로 module-fm.md에 기록, 정식
회신 접수 시 입회기록 소급.

검증: 절연저항 242~245MΩ≥10MΩ, 전압강하 0.20~0.79%(주버스0.24%)<=1%,
도통 정상 — PA입회 미확인(회신대기 타임아웃, 리스크 기록)
