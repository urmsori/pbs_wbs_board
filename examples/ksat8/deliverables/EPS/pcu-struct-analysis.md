# PCU·배전유닛 구조해석

입력: examples/ksat8/deliverables/EPS/pcu-distribution-design.md

발사 준정적 10g(STR sysreq 준용) 기준, PCU 섀시(주버스 피더·S3R 모듈·
LCL 33채널 카드) 체결부 응력·고유진동수 해석.

## 결과
- 체결부 최대응력: 알루미늄 섀시 기준 안전여유 SF 2.1(항복 대비).
- 유닛 1차 고유진동수: 195 Hz(위성 1차모드 30Hz(sysreq STR) 대비 충분히
  이격, 동적 커플링 우려 없음).

검증: 10g 준정적 SF2.1, 고유진동수195Hz(sysreq STR 30Hz 대비 이격)
