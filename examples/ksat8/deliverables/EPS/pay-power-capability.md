# EPS→PAY 회신: 11kW 공급·100V 전력품질 확약

입력: examples/ksat8/deliverables/SE/sysreq.md

## 확약 용량
- 탑재체(24채널 중계기) 배정 용량: **11.0 kW**(sysreq 정합), 채널당 균등
  배분 시 458 W/채널 상당까지 수용 가능하도록 PCU·배전을 설계 중.
- 채널 구성별 실제 W/A 내역은 REQ-EPS-PAY-부하(발신, PAY 회신 대기 중)로
  별도 확인 예정 — 현재 확약은 sysreq 총량(11kW) 기준.

## 100V 버스 전력품질
- 정상상태 조절 범위: 100V±2V(98~102V), 리플 ≤100 mVpp.
- 과도응답: 부하 스텝(±2kW 이내) 시 ±2V 이내로 5 ms 내 정착.
- TWTA 기동 순시전류: 채널별 인러시 제한회로(소프트스타트, 상승시간
  ≥10 ms) 내장 전제로 대응 — 순차 기동 시 정상 공급, 24채널 동시 기동은
  권장하지 않음(스케줄링 필요, PAY 회신 시 재확인).

검증: 확약 용량 11kW≥11kW(sysreq 정합), 리플 100mVpp·과도응답 5ms가
일반 TWTA 전원 규격(리플<1%, 정착<10ms) 이내.
