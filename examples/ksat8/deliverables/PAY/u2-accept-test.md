# PAY-U2 TWTA 세트 수락시험

입력: examples/ksat8/deliverables/PAY/u2-iqc.md, examples/ksat8/deliverables/PAY/u1-dsn.md

교정된 RF파워미터·스펙트럼분석기(CAL-PAY-U2)로 28기 개별 측정:
- 포화출력: 196~204W(배분200W 대비 ±4W 이내) — 전기 PASS.
- DC입력(OBO3dB): 302~318W(배분310W 대비 범위내) — 전기 PASS.
- 효율(RF/DC, OBO3dB): 31.5~33.1%(배분32.3% 근방) — 전기 PASS.
- 이득 편차: ±0.3dB 이내(설계 해석 가정치 이내).

검증: 28기 전수 포화출력·DC입력·효율 배분치 대비 PASS
