# AOCS-U1 지향 제어계 형상관리 배포 기록

입력: examples/ksat8/deliverables/AOCS/u1-rb.md (CM-AOCS-U1 요청 게시글이
지정한 대상 산출물 — AOCS-U1-RB 검토회 판정)

## 배포 대상
- 제어법칙 문서: AOCS-U1-DWG-CTRL-001 (대역폭 0.02Hz, 게인표)
- 센서·액추에이터 배분표: AOCS-U1-DWG-ALLOC-001 (별추적기 2기/자이로 2기/
  모멘텀휠 4기 배분)
- 판정 근거: AOCS-U1-RB 확정(BASELINE 확정, AOCS-U1-BL-001) — 지향오차
  RSS 123.1arcsec(0.0342°) ≤ 0.05°(마진 31.6%), 제어대역폭 0.02Hz(SA
  1차모드 대비 6.0배 이격)

## 배포
- 베이스라인 ID: AOCS-U1-BL-001
- 개정: Rev A(최초 배포)
- 배포일: 2026-08-27
- 배포처: PUR(AOCS-U2 장비 구매), TST(HIL 시험) 대기 — 이 기준선을 입력으로 사용
- 승계 리스크: 정렬오차 배분(현재 잠정 50arcsec)은 REQ-AOCS-STR-정렬 정식
  회신 도착 시 재계산 조건 — RB 판정문서(u1-rb.md)에서 그대로 승계

## 형상관리 처리
1. RB 판정 문서(u1-rb.md) 대비 산출물 목록 대사 — 일치
2. 베이스라인 등록 완료, 구매·시험 단계 처리 가능 상태로 전환

검증: RB 판정 대비 산출물 목록 일치 확인, 베이스라인 AOCS-U1-BL-001 등록
(정렬오차 재계산 조건 승계).
