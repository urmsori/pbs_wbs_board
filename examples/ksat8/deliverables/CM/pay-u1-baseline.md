# PAY-U1 중계기 패널 설계 형상관리 배포 기록

입력: examples/ksat8/deliverables/PAY/u1-rb.md (CM-PAY-U1 요청 게시글이
지정한 대상 산출물 — PAY-U1-RB BASELINE 확정)

## 배포 대상
- 24채널 중계기 패널 설계: 링크예산·전력/열 배분·채널배치도
- 판정 근거: PAY-U1-RB BASELINE 확정(PAY-U1-BL-001) — EIRP 52.43dBW
  (최악 52.07)≥52dBW, NPR 19.5dB(최악 19.0)≥18dB

## 배포
- 베이스라인 ID: PAY-U1-BL-001
- 개정: Rev A(최초 배포)
- 배포일: 2026-08-27
- 배포처: PAY-U1(제작)·PAY-U2(TWTA 수락) 대기 — 이 기준선을 입력으로 사용
- 승계 리스크: RVW-A 조건(TST 단계 개별조정 포함)을 그대로 승계

## 형상관리 처리
1. RB 판정 문서 대비 배포 대상 대사 — 일치
2. 베이스라인 등록 완료, 제작·TWTA 수락 단계 처리 가능 상태로 전환

검증: RB 승인 대비 산출물 목록 일치, 베이스라인 PAY-U1-BL-001 등록.
