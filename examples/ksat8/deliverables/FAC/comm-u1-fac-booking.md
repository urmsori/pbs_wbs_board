# RF 시험(전파암실) 시설 예약 확인서 (COMM-U1 트랜스폰더)

입력: examples/ksat8/deliverables/COMM/comm-u1-ins.md (REQ-COMM-FAC-시설
요청 게시글이 지정한 대상 산출물 — COMM-INS-01 GO 판정, RF시험 투입 전
시설 확인)

## 예약 대상
전파암실(anechoic chamber), COMM-U1 트랜스폰더(SN COMM-FM-001) RF시험
(주파수응답·EIRP·레인징 지연·TM/TC 루프백).

## 예약 내역
- 시설: 전파암실 #1(S-band 대응, 정재파비 측정 가능, 유효 시험거리 5m)
- 예약 기간: 2026-09-01 ~ 2026-09-03(2일, 셋업 0.5일 + 시험 1일 + 철수 0.5일)
- 사전 확인: COMM-U1-INS-01(GO 판정, 핀맵 일치·중량 1.8kg) 확인 완료 —
  전파암실 투입 가능 형상
- 병행 서비스: CAL-COMM-U1(계측장비 교정), PA-COMM-U1(품질입회)와 일정
  정합 확인

## 운전 기록(소급)
comm-u1-tst.md는 CAL/FAC 실회신 대기 타임아웃으로 "가정 기반 잠정"
시험을 이미 수행했다(정직 기록). 본 예약 확인은 소급 확인이며, 예약
자체에 시설 충돌·부적합 사유가 없음을 확인해 시험 결과의 시설 측
전제가 유효했음을 뒷받침한다.

검증: 시설 예약 확정(전파암실 #1), 시험 시점(2026-09-01 인근)과 실제
COMM-TST-01 수행에 시설 충돌·부적합 없음 소급 확인.
