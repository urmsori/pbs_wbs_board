# COMM-U1 트랜스폰더 유닛 제작

입력: examples/ksat8/deliverables/COMM/comm-u1-iqc.md, examples/ksat8/deliverables/COMM/comm-u1-baseline.md

입고검사 통과 부품으로 baseline 회로(수신기/명령복호기/TM변조기/SSPA 2W/
다이플렉서)를 PCB에 실장하고 RF 모듈 간 세미리지드 케이블로 접속했다.
제작 기록: 실장 SN COMM-FM-001, 납땜 공정 J-STD-001 Class 3 준수, 정전기
관리(ESD) 작업대 사용.

검증: SN COMM-FM-001 발급, 실장 완료(육안 검사 통과 — 상세 검사는
COMM-INS-01에서 수행).
