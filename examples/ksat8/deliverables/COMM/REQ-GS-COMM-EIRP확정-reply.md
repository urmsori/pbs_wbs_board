# COMM → GS 회신: TT&C 하향 EIRP 확정치

입력: examples/ksat8/deliverables/COMM/comm-u1-fm-package.md

안테나 정정(NCR-COMM-01) 결과 재계산이 불필요했으므로 최종 확정 하향
EIRP는 기존 설계/시험치와 동일하다: **설계 5.0dBW / RF시험 실측
4.8dBW(마진 내)**. 관제소 적합성 판정에는 실측치 4.8dBW를 보수적으로
사용할 것을 권고한다.

검증: comm-u1-fm-package.md FM 인도 사양과 일치, 안테나 정정으로 인한
변경 없음.
