# COMM-U1 TT&C 트랜스폰더 RF 아키텍처 설계

입력: examples/ksat8/deliverables/SE/sysreq.md, examples/ksat8/deliverables/EPS/comm-power-allocation.md, examples/ksat8/deliverables/OBC/REQ-COMM-OBC-IF-reply.md

## 1. 주파수·변조·레인징 계획 (S-band, sysreq "COMM: TT&C S-band 상시·레인징")
- 상향(명령): 2025.0–2110.0 MHz, 단일 지정 채널 2087.5 MHz(대역폭 ≤1.5MHz).
- 하향(원격측정): 2200.0–2290.0 MHz, 단일 지정 채널 2255.5 MHz(대역폭 ≤4MHz).
- 명령 변조: PCM/PSK/PM, 부반송파 16kHz, 데이터율 2kbps(OBC 회신 TC
  16워드/프레임·최대 10cmd/s를 여유 있게 수용).
- 텔레메트리 변조: PCM/PSK/PM, 부반송파 65.536kHz, 데이터율 4kbps 상시
  (OBC 회신 TM 32워드/프레임·1Hz 기준 프레임을 충분히 수용, 고속 서브프레임
  4Hz 구간도 버스트 8kbps로 수용).
- 레인징: PN 코드(CCSDS 표준 부호, 주 코드 길이 2²²−1) + 코히런트 턴어라운드
  비 240/221(표준 S-band). 레인징 채널은 TM/TC와 동일 캐리어에 결합
  변조(레인징 부반송파 억압 방식).

## 2. 트랜스폰더 블록다이어그램 (요약)
안테나×2(LGA, 반이중) → 다이플렉서 → 수신기(이중, 핫스탠바이 아님·콜드
절체) → 명령복호기(1553B 이중 버스로 OBC 접속, §3) → [레인징 턴어라운드
경로] → TM 변조기(OBC TM 32워드/1Hz 프레임 수신, 1553B) → 송신기(SSPA)
→ 다이플렉서 → 안테나.

## 3. OBC 인터페이스 반영
- MIL-STD-1553B 이중 버스(주/예비), 콜드 스탠바이 절체 — OBC 회신대로 COMM
  명령복호기·TM변조기가 각각 1553B RT(Remote Terminal)로 동작.
- TM 배정 500점을 32워드/프레임 구조에 매핑(안전마진 포함).

## 4. 전력 정합 (EPS 회신 반영)
- 상시 부하 150W(수신기 이중 대기+명령복호+TM변조+SSPA 저전력 유지) 이내로
  회로 정격을 잡는다. 레인징/고출력 TM 구간 피크 220W(≤10분/회, 궤도당
  ≤4회) 이내에서 SSPA 정격 출력을 정한다(§5 링크버짓에서 SSPA 출력 W값 도출).
- 버스 100V±2V 직결, DC-DC 컨버터 자체 2차 레일 생성. 버스 리플 ≤100mVpp,
  부하 스텝 과도응답 ±2%/5ms 이내로 COMM 측 입력 필터를 설계한다.

## 5. 안테나 배치·시야 — 가정(잠정, STR 미회신)
REQ-COMM-STR-안테나(2026-08-27 게시)에 8×20초 폴링 2회(총 320초) 회신
없음. 다음을 **잠정 가정**으로 진행하고, STR 실회신 도착 시 정정 게시글로
반영한다:
- 가정: 저이득 안테나(LGA) 2기, 위성체 +Z(지구지향면 반대쪽 상단)·−Z(하단)
  각 1기 배치로 반구 대칭 확보. 두 안테나 시야를 합쳐 4π의 상시 가시(단일
  고장 허용, 반사판·SA 전개 시 상호 차폐 없음)를 가정.
- 가정 근거: sysreq "COMM: TT&C S-band 상시" 요구를 만족하려면 GEO에서
  자세가 어떤 상태여도(전이궤도 텀블 포함) 최소 한 안테나가 지상국을
  보는 배치가 표준이므로 이를 기본값으로 채택.

검증: sysreq TT&C S-band 상시·레인징 요구 대비 — 상향 2087.5MHz/하향
2255.5MHz 지정, PN 레인징+240/221 턴어라운드로 상시·레인징 항목 충족(수치
인용). §5는 잠정 가정임을 명기.
