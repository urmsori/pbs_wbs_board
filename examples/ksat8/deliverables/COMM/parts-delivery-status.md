# COMM → AIT 회신: NCR-COMM-02 부품 입고·IQC 현황

입력: examples/ksat8/deliverables/COMM/module-fm.md, examples/ksat8/deliverables/COMM/comm-u1-fm-package.md, examples/ksat8/deliverables/COMM/comm-u1-iqc.md

## 현황 (2026-08-27 기준)
- PO-COMM-U1-001~005(수신기×2, 명령복호기, TM변조기, SSPA, 다이플렉서)
  발주 완료(comm-u1-fm-package.md 이월항목 기재치). 입고예정일 2026-09-10(다이플렉서)/09-12(수신기·
  복호기·변조기)/09-15(SSPA).
- 실물 입고·정식 IQC(수령 검사)는 **미완료** — 오늘(08-27) 기준 입고예정일
  전이므로 정상 대기 상태다. comm-u1-iqc.md는 입고 전 체크리스트(외관·
  스펙시트 대조 절차)만 확정해 둔 상태.

## INT 통합조립 착수에 미치는 영향
**영향 없음**으로 판단한다. AIT에 인도되는 대상은 module-fm.md·
comm-u1-fm-package.md에 기록된 **완성 비행유닛 SN COMM-FM-001**이며,
COMM-U1 체인(MFG→ASY→INS[GO]→TST[7항목 PASS]→PA입회)이 이미 전부
DONE되어 통합 투입 가능 형상이다. PO-COMM-U1-*는 이 유닛의 예비품·
후속 생산분 재고 확보용 발주로, INT-TST-3을 포함한 통합시험 일정의
전제조건이 아니다.

## 정정 예고
09-10~15 입고 후 정식 IQC 결과가 baseline과 다르면(불일치 발견 시)
정정 게시글로 갱신한다. 통합조립 착수를 지연시키지 않는다.

검증: SN COMM-FM-001은 인도 완료(전 체인 DONE), PO 부품은 예비품 성격 —
NCR-COMM-02는 정상 생산일정(입고 대기)이며 INT 착수에 영향 없음.
