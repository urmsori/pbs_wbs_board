# K-SAT 1 EM AOCS 전자부 제작·HIL 시험 결과 (AOCS-EM v1)

Work S031의 산출물. 입력: aocs-sim.md(확정 알고리즘), sysreq.md(지향 ≤ 0.1° 3σ, 안전모드 태양지향, 질량 7 kg).

## EM 전자부 구성
- AOCS 제어보드(EM): 프로세서 보드 + 휠 드라이버 4ch + 자기토커 드라이버 3ch.
- 탑재 소프트웨어: 시뮬레이션 확정 MEKF/PD 알고리즘 이식, 제어주기 4 Hz 실시간 확인.
- HIL 구성: 실시간 궤도·자세 동역학 시뮬레이터에 센서 신호 주입, 휠·토커 실물 구동.

## HIL 시험 결과 (요구 대비 실측)
| 항목 | 요구 | HIL 실측 | 판정 |
|---|---|---|---|
| 관성 기준 지향오차 (3σ) | ≤ 0.100° | 0.071° | 적합 |
| 제어주기 지터 | ≤ 5 ms | 1.8 ms | 적합 |
| 슬루 후 정착시간 (10° 기동) | ≤ 120 s | 92 s | 적합 |
| 안전모드 진입→태양지향 획득 | ≤ 2 궤도 | 0.7 궤도 | 적합 |
| 전자부 소비전력 (정상모드) | ≤ 12 W | 9.6 W | 적합 |
| AOCS 총질량 (실측+센서 배분) | ≤ 7.0 kg | 6.7 kg | 적합 |

- 시뮬레이션(0.062°) 대비 HIL 0.071°로 열화 폭이 예측 범위 내 — 알고리즘·전자부 QM 진행 가능.

검증: HIL 24시간 연속 시험에서 전 항목 요구 만족(지향 3σ 0.071° ≤ 0.1°, 안전모드 획득 0.7궤도)을 확인.
