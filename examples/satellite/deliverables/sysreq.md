# K-SAT 1 시스템 요구사항 (SYS-REQ v1)

Work S001의 산출물. 모든 모듈·형상 Work의 최상위 입력.

## 임무
- 지구 저궤도(550 km 태양동기궤도) 지구관측 기술검증, 임무수명 2년.

## 최상위 예산
| 항목 | 배분 |
|---|---|
| 발사 질량 | ≤ 50 kg (구조 20, EPS 8, AOCS 7, COMM 5, 탑재체·하니스 10) |
| 궤도평균전력 | ≥ 60 W 발생, 버스 소비 ≤ 45 W |
| 자세지향 정확도 | ≤ 0.1° (3σ) |
| 다운링크 | S-band ≥ 2 Mbps, 링크마진 ≥ 3 dB |

## 모듈 배분 요구
- STR: 1차 고유진동수 ≥ 45 Hz, 준정적 하중 12 g 견딜 것 (→ S010)
- EPS: 28 V 버스, 방전심도 ≤ 30 % (→ S020)
- AOCS: 관성 기준 지향, 안전모드 태양지향 (→ S030)
- COMM: 상향 64 kbps, 하향 2 Mbps, 모듈 단독 인증 필요 (→ S040)

## 형상 단계 정의 (최종 위성만 해당)
- **EM**: 전기 기능 통합 검증. **QM**: 인증 수준 환경시험. **FM**: 수락 수준
  시험 후 인도. 모듈의 내부 단계는 각 모듈이 정한다.

검증: 질량·전력 배분 합계가 예산 이내임을 표에서 확인(48/50 kg, 45/60 W).
