# COMM QM 트랜시버 인증시험 (Work S041)

EM 검증(S040, comm-em.md)을 통과한 설계로 제작한 QM 트랜시버의
모듈 단독 인증시험 결과. SYS-REQ v1의 "모듈 단독 인증 필요" 요구를 충족한다.

## 인증시험 결과 (요구 대비 실측)

| 시험 | 조건(인증 수준) | 요구 | 실측 | 판정 |
|---|---|---|---|---|
| 사인 진동 | 5–100 Hz, 준정적 12 g×1.25 | 구조 건전성 유지 | 공진 변화 < 3 %, 손상 없음 | PASS |
| 랜덤 진동 | 14.1 grms, 축당 2분 | 시험 후 기능 정상 | 기능시험 전 항목 정상 | PASS |
| 열진공 | -30/+60 °C, 8 사이클, <1e-5 torr | 전 온도 기능 정상 | 락·BER 성능 유지 | PASS |
| 열진공 후 BER | 2 Mbps, Eb/N0 9.6 dB | ≤ 1e-5 | 4.1e-6 | PASS |
| EMC 전도성 방출 (CE) | MIL-STD-461 CE102 | 한계선 이하 | 여유 6 dB | PASS |
| EMC 복사성 방출 (RE) | MIL-STD-461 RE102 | 한계선 이하 | 여유 4 dB | PASS |
| EMC 감응성 (RS) | RS103, 20 V/m | 오동작 없음 | 오동작 없음 | PASS |
| 질량 | 실측 | ≤ 5 kg (배분) | 4.7 kg | PASS |

시험 전·중·후 기능시험(상향 64 kbps 커맨드, 하향 2 Mbps 텔레메트리)에서
성능 저하 없음을 확인했다. QM 형상(S003) 통합 투입 가능.

검증: 진동·열진공·EMC 인증 수준 시험 전 항목 PASS, 시험 후 BER 4.1e-6 ≤ 1e-5로 요구 충족 확인.
