# K-SAT 1 FM AOCS 제작·교정 결과 (AOCS-FM v1)

Work S032의 산출물. 입력: aocs-em.md(HIL 검증 완료 전자부·알고리즘), sysreq.md(지향 ≤ 0.1° 3σ, AOCS 질량 ≤ 7 kg).

## FM 제작 구성
- FM 센서: 별추적기 1기, 관성센서(자이로) 1조, 태양센서 6면, 자기장센서 2조 — 비행 인증 부품으로 제작.
- FM 구동기: 반작용휠 4기(피라미드 배치), 자기토커 3축. 제어보드는 EM 동일 설계의 FM 제작품.
- 탑재 소프트웨어: EM HIL에서 확정한 MEKF/PD 이식본, 제어주기 4 Hz 동일.

## 교정 결과표
| 항목 | 허용치 | 교정 후 잔차 |
|---|---|---|
| 자이로 바이어스 (3축) | ≤ 1.0 °/h | 0.12 / 0.09 / 0.15 °/h |
| 별추적기 광축 정렬오차 | ≤ 60 arcsec | 18 arcsec |
| 반작용휠 정렬·스케일오차 | ≤ 0.5 % | 0.21 % |
| 자기장센서 하드아이언 잔차 | ≤ 200 nT | 85 nT |

## 수락시험 결과 (요구 대비 실측)
| 항목 | 요구 | FM 실측 | 판정 |
|---|---|---|---|
| 관성 기준 지향오차 (3σ, 폐루프 시험대) | ≤ 0.100° | 0.068° | 적합 |
| 안전모드 진입→태양지향 획득 | ≤ 2 궤도 | 0.8 궤도 | 적합 |
| 소비전력 (정상모드) | ≤ 12 W | 9.9 W | 적합 |
| AOCS 총질량 (실측) | ≤ 7.0 kg | 6.8 kg | 적합 |

- 교정 반영 후 지향 0.068°로 HIL(0.071°)과 동등 수준 — FM 인도 및 위성 조립(AIT) 투입 가능.
