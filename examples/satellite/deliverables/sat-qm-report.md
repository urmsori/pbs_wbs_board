# K-SAT 1 QM 형상 통합·인증시험 보고서 (Work S003)

입력: sat-em-report.md(S002), str-stm-report.md(S010), comm-qm.md(S041), sysreq.md(SYS-REQ v1).

## QM 형상 구성
- STM 구조(정적시험 완료 프레임, S010) + QM 트랜시버(모듈 단독 인증 완료, S041)
  + EM 전장(EPS·AOCS, S002 통합 검증품)으로 조립. 탑재체는 질량더미.
- EM 이슈 반영: 트랜시버 전원 입력단 필터 보강·하니스 접지 개선, 데이터버스
  종단저항·실드 처리 조정(sat-em-report 이슈 1·2).
- 총 조립 질량 45.9 kg ≤ 50 kg (STR 17.4 + EPS 7.6 + AOCS 6.7 + COMM 4.7 + 더미·하니스 9.5).

|---|---|---|---|---|
| 저수준 사인 스윕 | 5–100 Hz | 1차 고유진동수 ≥ 45 Hz | 56.8 Hz (STM 단독 58.2 Hz와 정합) | PASS |
| 사인 진동 | 준정적 12 g × 1.25 | 구조 건전성 유지 | 공진 변화 2.1 % < 5 %, 손상 없음 | PASS |

## EM 이슈 해소 확인
1. **송신 돌입전류 버스 리플** — 필터 보강 후 리플 진폭 1/3 수준으로 감소,
   전 시험 기간 래치오프 0회. 해소 확인.
2. **데이터버스 간헐 재전송** — 종단·실드 조정 후 72시간 연속 시험에서 재전송 0회. 해소 확인.

전 항목 PASS — 인증 완료, FM 제작·수락시험 단계 진행 가능.
