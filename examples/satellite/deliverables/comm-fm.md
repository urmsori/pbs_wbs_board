# COMM FM 트랜시버 제작·수락시험 (Work S042)

QM 인증(S041, comm-qm.md)으로 확정된 설계·공정으로 비행용(FM) 트랜시버를
제작하고, 수락(acceptance) 수준 시험을 수행한 결과. 수락 레벨은 SYS-REQ v1의
FM 정의("수락 수준 시험 후 인도")에 따라 인증 레벨보다 축소해 적용했다.

## 수락시험 결과 (요구 대비 실측)

| 시험 | 조건(수락 수준) | 요구 | 실측 | 판정 |
|---|---|---|---|---|
| 랜덤 진동(워크맨십) | 10.0 grms(인증 14.1 grms −3 dB), 축당 1분 | 시험 후 기능 정상 | 기능시험 전 항목 정상 | PASS |
| 열사이클 | -20/+50 °C(인증 -30/+60 °C 축소), 4 사이클 | 전 온도 기능 정상 | 락·BER 성능 유지 | PASS |
| 열사이클 후 BER | 하향 2 Mbps, Eb/N0 9.6 dB | ≤ 1e-5 | 3.2e-6 | PASS |
| 하향 데이터율 | S-band 텔레메트리 | ≥ 2 Mbps | 2 Mbps 연속 전송 확인 | PASS |
| 링크마진 | 550 km 최악 기하, 실측 EIRP·G/T 반영 | ≥ 3 dB | 4.1 dB | PASS |
| 상향 커맨드 | 64 kbps | 수신·복호 정상 | 커맨드 처리 정상 | PASS |
| RF 출력·주파수 | 송신 스펙 | 설계 공차 이내 | 공차 이내 | PASS |
| 질량 | 실측 | ≤ 5 kg (배분) | 4.6 kg | PASS |

시험 전·중·후 기능시험에서 성능 저하 없음을 확인했다. FM 트랜시버는
FM 형상 통합·인도에 투입 가능하다.
