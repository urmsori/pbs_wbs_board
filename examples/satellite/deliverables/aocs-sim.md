# K-SAT 1 AOCS 알고리즘 시뮬레이션 결과 (AOCS-SIM v1)

Work S030의 산출물. 입력: sysreq.md(지향 정확도 ≤ 0.1° 3σ, 안전모드 태양지향, AOCS 질량 7 kg).

## 알고리즘 구성
- 자세 결정: 별추적기 + 자이로, MEKF(승법 확장칼만필터), 4 Hz 갱신.
- 자세 제어: 반작용휠 4기(피라미드 배치) PD + 피드포워드, 모멘텀 덤핑은 자기토커 B-dot.
- 안전모드: 태양센서 + 자기장계만으로 태양지향 스핀 안정화(B-dot + 태양추종).

## 몬테카를로 결과 (1,000 케이스, 궤도 5주기, 센서·관성 파라미터 분산 반영)
| 항목 | 요구 | 시뮬 결과 (3σ) | 판정 |
|---|---|---|---|
| 관성 기준 지향오차 | ≤ 0.100° | 0.062° | 적합 |
| 자세 결정오차 | (배분 0.03°) | 0.018° | 적합 |
| 슬루 후 정착시간 (10° 기동) | ≤ 120 s | 87 s | 적합 |
| 안전모드 태양지향오차 | ≤ 15° | 8.4° | 적합 |
| 휠 모멘텀 사용률 | ≤ 80 % | 63 % | 적합 |

- 지향오차 0.1° 초과 케이스 0/1,000 — 알고리즘 확정, EM 탑재(S031)로 진행 가능.
- 구성품 질량 합계 6.6 kg으로 배분 7 kg 이내.

검증: 몬테카를로 1,000케이스 전건에서 지향오차 3σ 0.062° ≤ 0.1° 및 안전모드 태양지향 수렴을 확인.
