# TRANS 파트 계획(TRANS-01 취합) — 버스 왕복 시각표

입력: examples/wedding/deliverables/BG/brief.md,
examples/wedding/deliverables/BG/reply-trans-버스.md

## 전제
집결지 **대전복합터미널 정문 앞**(경부선 대합실 쪽), 탑승 인원 **82명**
(신부측 38 + 신랑측 44), 45인승 2대(정원 90, 예비 8석), 연락 총무
**이광수**(신부측 사촌오빠, 010-2345-6789, 당일 09:00부터 통화 가능).
대전~서울 마포(라온컨벤션) 고속도로 이동 약 2.5시간 가정.

## 당일 시각표(왕복)
| 시각 | 내용 |
|---|---|
| 08:30 | TRANS-01 → 이광수 총무 전화, 최종 탑승 인원·좌석 배분 확인 |
| **09:00** | 대전복합터미널 정문 앞 **집결·상행 출발**(2대) |
| 09:00~11:30 | 이동(2.5시간, 정체 대비 여유 10분 포함) |
| **11:40** | 라온컨벤션 도착, 하차 |
| 11:40~11:50 | 정비·화장실, 로비 이동 |
| 11:50~12:00 | VEN-USH-01 안내로 축의대→좌석 이동 |
| 12:30 | 본식 시작(여유 30분 확보) |
| 13:00~15:00 | 하객 뷔페 이용(FOOD plan.md 뷔페 시간대) |
| **14:30** | 귀환 버스 **하행 출발**(뷔페 여유 있게 이용 후 승차,
  기사 대기·재확인 위해 대전복합터미널 하차조 우선 안내) |
| 14:30~17:00 | 이동(2.5시간) |
| **17:00** | 대전복합터미널 도착, 해산 |

## 준비물
버스 2대(45인승) 배차 확정, 좌석표(신부측/신랑측 구분), 기사 연락처,
이광수 총무 연락처 공유(TRANS-01·VEN-USH-01 양쪽).

## 리스크
82명 예약 대비 예비 8석이 있어 당일 추가 탑승 요청이 들어올 수 있다 —
09:00 집결 시점에 이광수 총무가 최종 인원을 확정해 주지 않으면 좌석
배정이 늦어질 수 있다(08:30 사전 통화로 최소화하되 완전 해소는 어려움,
미해결 리스크로 남김).

## 검증
회신 1건(REQ-TRANS-BG-버스)을 입력으로 확정했다. 왕복 시각표(상행 09:00,
하행 14:30) 확정, 예비 좌석 처리 리스크 1건 정직하게 명시.
