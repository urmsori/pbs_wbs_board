# DVD 파트 계획 (본식영상)
입력: DVD-MAIN-01(2cam-plan.md), DVD-SUB-01(audio-plan.md) —
회신 2건(REQ-DVD-VENUE-전원, REQ-DVD-MC-식순)을 입력으로 확정.

## 역할
- DVD-MAIN-01(메인 캠) — 리드, 2캠 배치·컷포인트
- DVD-SUB-01(오디오/서브캠) — 오디오 수음

## 당일 타임라인
| 시각 | 내용 | 담당 |
|---|---|---|
| 11:00 | 콘센트 확인, B캠 8m 연장케이블 배선(카펫 아래 고정) | DVD-MAIN-01 |
| 11:20 | A캠(정면 고정) 세팅·화이트밸런스 | DVD-MAIN-01 |
| 11:30 | 사운드체크, XLR 라인아웃 연결 테스트(콘솔 무대 좌측 4m) | DVD-SUB-01 |
| 11:45 | 무선 핀마이크 채널 스캔·배터리 확인 | DVD-SUB-01 |
| 12:20 | 테스트 롤(5분) | DVD-MAIN-01 |
| 12:25 | 혼주 입장부터 본 롤 시작 | DVD-MAIN-01 |
| 12:25–12:52 | 식순 전체 촬영(컷포인트는 2cam-plan.md) | DVD-MAIN-01+SUB-01 |
| 13:00–13:30 | 원판 중 촬영은 서브캠만 대기(스냅 우선 슬롯이라 메인은 철수 준비) | DVD-SUB-01 |
| 14:00 | 철수 | 전원 |

## 큐
- 11:30 음향감독(VEN-SOUND-01) 신호로 라인아웃 연결 테스트
- 12:25 사회자 혼주 입장 안내 신호로 본 롤 시작
- 12:52 예식 종료 안내 신호로 A캠 정지, B캠은 원판 스틸용 대기

## 준비물
캠 2대(A 고정·B 이동), 8m 연장케이블, XLR 케이블 2조, 무선 핀마이크 3조
(성혼선언문·신랑·신부)+예비배터리, 샷건마이크(라인아웃 백업용).

## 리스크
- B캠 8m 연장케이블이 하객 동선과 교차 가능 — 카펫 아래 고정 필수,
  설치 후 VENUE 세팅팀 육안 확인 요청(2cam-plan.md).
