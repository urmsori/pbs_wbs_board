# 부케 제작·인도 (FLO-01)
입력: 자기 트랙(-), BG 회신(examples/wedding/deliverables/BG/reply-flower-부케.md),
MAKEUP 회신(examples/wedding/deliverables/MAKEUP/reply-flower-완료시각.md — 신부 도착 11:50)

## BG 회신 요약
스타일: 화이트 카라 + 그린 유칼립투스, 라운드 폼(드레스 미니멀 실크에 맞춤).
토스 진행: O — 받을 사람 박지민(신부 친구, 축가 듀엣). 서브(토스용) 부케
1개 별도 제작(본식용과 톤 동일, 소형).

## 제작·인도 계획
| 시각 | 내용 |
|---|---|
| 당일 07:00 | 본식용 메인 부케·토스용 서브 부케 제작 완료(작업장) |
| 09:30 | 식장 이동 출발(냉장 보관 차량) |
| 10:30 | 식장 도착, 냉장 보관(로비 서비스룸) |
| 11:45 | 신부 대기실로 이동 대기 |
| **11:50** | 신부 도착 즉시 메인 부케 전달(MAKEUP MU-DIR-01 도착 알림 신호) |
| 12:48(퇴장 직전) | 서브(토스용) 부케를 진행요원 편에 준비 — 퇴장 후 토스 타이밍은 BG/MC와 별도 조율 |

## 리스크
- 토스 타이밍(퇴장 직후 vs 다과 인사 중)이 MC 확정 식순에 명시돼 있지
  않음(REQ-DVD-MC-식순 회신에는 없음) — 잠정: 퇴장(12:48) 직후 로비에서
  진행 가정. 정확한 시점은 MC·BG 확인 후 정정(CORR) 예정.
