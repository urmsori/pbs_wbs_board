# FLOWER 파트 계획 (부케·꽃장식)
입력: FLO-01(bouquet.md), FLO-02(venue-decor.md) — 회신 3건
(REQ-FLOWER-BG-부케, REQ-FLOWER-VENUE-반입, REQ-FLOWER-MAKEUP-완료시각)을
입력으로 확정.

## 역할
- FLO-01(플로리스트) — 리드, 부케 제작·인도
- FLO-02(설치팀) — 단상 장식 설치

## 큐
- 11:00 대관 시작 즉시 → FLO-02 화물 엘리베이터 최우선 사용(VENUE 구두 재확인)
- 11:50 MU-DIR-01 도착 알림 → FLO-01 메인 부케 즉시 전달
- 12:48 퇴장 신호 → FLO-01 서브 부케를 진행요원에게 전달(토스 진행)
- 13:30 다과 인사 종료 → FLO-02 철거 시작

## 준비물
메인 부케 1(화이트 카라+유칼립투스), 서브 토스용 부케 1(동일 톤 소형),
아치 골조·생화 자재, 버진로드 라인 플라워, 포토테이블 장식재, 냉장
운송 차량.

## 리스크
1. 화물 엘리베이터가 1대뿐 — 세팅팀·PHOTO/DVD 장비 반입과 시간대가
   겹치면 대기 발생 가능(venue-decor.md).
2. 부케 토스 정확한 타이밍(퇴장 직후 vs 다과 중)이 MC 식순에 명시돼
   있지 않아 잠정(퇴장 직후 12:48)으로 진행 — 확인 시 CORR 예정
   (bouquet.md).
