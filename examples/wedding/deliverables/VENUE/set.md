# VEN-SET-01: 홀 세팅(좌석·원판 위치·반입 동선)

입력: examples/wedding/deliverables/BG/brief.md,
examples/wedding/deliverables/VENUE/reply-flower-반입.md(자기 트랙),
examples/wedding/deliverables/VENUE/reply-photo-wonpan.md(자기 트랙),
examples/wedding/deliverables/VENUE/reply-bg-별실.md(자기 트랙)

## 세팅 순서(시각)
- **11:00** 대관 개시. 화훼(FLOWER) 반입과 동시 시작 — 화물 엘리베이터 →
  후면 반입구(reply-flower-반입 참조). 세팅팀은 객석 의자열부터 배치.
- **11:00~11:30** 객석 의자열 배치(250석 기준, 신랑측/신부측 좌우 분리),
  단상 앞 통로(신부 입장로) 확보. 화훼팀은 단상 아치 골격 설치.
- **11:30~12:00** 화훼 세부 마감(reply-flower-반입 골격 12:00 완료 기준),
  축의대 로비 2테이블+잠금함 설치(reply-bg-별실), 포토테이블 자리 확보
  (GIFT팀 반입은 GIFT 파트가 별도 진행, VENUE는 위치만 로비 축의대 옆으로
  배정).
- **12:00~12:20** 전체 최종 점검(좌석·화훼·축의대·포토테이블 위치 확인).
- **12:20** 세팅 마감, 하객 입장 대비.

## 원판 촬영 위치
단상 **이동 없이 그대로** 사용(reply-photo-wonpan). 예식 종료 즉시 좌석
정리 없이 단체 대열로 전환 — 13:00~13:30 단상 구역 독점 사용.

## 준비물
250석 의자·리본, 화훼 반입용 화물 엘리베이터 사전 예약, 축의대 잠금함 2개.

## 리스크
화물 엘리베이터가 1대뿐이라 화훼·포토테이블·GIFT 반입이 겹치면 11:00~12:00
사이 병목이 생길 수 있다 — VEN-SET-01이 반입 순서를 화훼 우선으로 통제하고,
GIFT 반입은 11:30 이후로 유도한다(GIFT 파트에 통보 필요, REQ 미발행 상태 —
GIFT-01 자체 조율 요망).
