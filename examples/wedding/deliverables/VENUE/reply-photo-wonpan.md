# VENUE → PHOTO 회신: 원판 촬영 장소·조명·30분 독점 슬롯

입력: 없음(VENUE 시설·타임라인 정보)

1. **장소**: 이동 없이 **단상 그대로** 촬영(별실·로비 이동 시 연로하신
   조부모님 이동 부담이 커지고, 30분 제한 내 동선 낭비가 생김). 예식이
   끝난 자리에서 좌석 정리 없이 바로 촬영 대열로 전환.

2. **조명**: 상시 조명(단상 스팟)만으로는 단체 원판에 부족할 수 있음 —
   **촬영용 보조조명(스트로보 2대) 추가 반입 권장**. PHOTO팀이 지참 시
   VEN-LIGHT-01이 단상 좌·우 콘센트(DVD 2캠과 공유 회로, REQ-DVD-VENUE-전원
   회신 참조)를 제공하되, **동시 사용 총 부하가 콘센트 정격을 넘지 않는지
   PHOTO·DVD 장비 소비전력을 사전에 알려달라**(리허설 D-7 전까지).

3. **30분 독점 사용**: 가능. **13:00~13:30 단상 구역은 원판 전용**으로
   비워둔다. 다음 순서인 양가 다과 인사(13:30~13:40)는 혼주 VIP 라운지
   에서 별도 준비하므로 단상과 겹치지 않는다.

검증: 단상 그대로 촬영, 보조조명 반입 권장(부하 사전 확인 요청), 13:00~13:30
단상 독점 사용 가능 회신.
