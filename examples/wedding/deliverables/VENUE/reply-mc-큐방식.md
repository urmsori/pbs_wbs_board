# VENUE → MC 회신: 음향·조명 큐 전달 방식

입력: 없음(VENUE 자체 운영 방식 — 음향·조명 콘솔 배치안)

1. **수신 방식**: 인이어 없음(당일 세팅 리스크·비용상 미채택). 육성 진행 +
   **수신호** 채택. 사회자는 무선 핸드마이크 1대 소지, 콘솔과는 시야 확보된
   상태에서 큐시트(사전 배포)로 순서를 맞추고 실시간은 수신호로 보정한다.
   - 신호1(마이크를 눈높이로 살짝 들어올림) = "음악/조명 시작 신호"
   - 신호2(손바닥을 아래로 천천히) = "페이드아웃/전환 신호"
   - 신호3(손가락으로 원 모양) = "예정대로 진행, 대기"

2. **담당자 위치·이름**: 음향·조명 콘솔은 무대(주례석 자리) 정면 좌측 4m,
   사회자 동선에서 항상 시야 확보되는 위치에 1개소로 통합 운영.
   - 음향: **VEN-SOUND-01(음향감독)**
   - 조명: **VEN-LIGHT-01(조명감독)** — 콘솔 공유, 같은 위치에서 동시 운영

3. **리드타임**: 음악 시작 신호는 사회자 멘트 종료 예상 **3초 전** 사전 신호
   (마이크 라인 열림·트랙 큐잉 시간 확보). 조명 전환(장면 전환용 디밍/스팟)은
   멘트 종료와 **동시(0초)** 신호로 맞춘다. 리허설(D-7)에서 실제 멘트 길이로
   1회 합을 맞추고, 필요 시 사회자 큐대본에 초 단위 타임코드를 병기해 달라.

검증: 육성+수신호 채택, 콘솔 위치 무대 좌측 4m(시야 확보), 음악 리드타임 3초/
조명 리드타임 0초로 회신.
