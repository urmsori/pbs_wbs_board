# VEN-SOUND-01: 음향 운영 계획

입력: examples/wedding/deliverables/VENUE/reply-music-음향.md(자기 트랙),
examples/wedding/deliverables/VENUE/reply-mc-큐방식.md(자기 트랙),
examples/wedding/deliverables/VENUE/reply-dvd-전원.md(자기 트랙)

## 마이크 채널 배정(무선 4채널 + 유선 스탠드 1)
| 채널 | 용도 | 종류 |
|---|---|---|
| W1 | 사회자 | 무선 핸드 |
| W2·W3 | 듀엣 축가(신부친구 2인) | 무선 핸드 |
| W4 | 솔로 축가(MR) | 무선 핸드 — 듀엣 종료 후 핸드오프 20초 |
| S1(유선) | 성혼선언문 낭독(신랑아버지) | 유선 스탠드(단상 고정) |

## MR·반주 재생 순서
1. 12:30 개식 — 배경 없음(사회자 육성)
2. 신부 입장 — **라이브 피아노**(피아니스트, 단상 좌측 배치)
3. 성혼선언문 — S1 유선 마이크
4. 축가1(듀엣, 피아노 반주) → 축가2(솔로, MR 재생, mp3/wav D-3(10/22)
   전달분 사용)
5. 퇴장 — 밝은 MR 재생

## 큐 수신 방식
사회자 육성+수신호(reply-mc-큐방식 참조). 콘솔은 무대 좌측 4m, VEN-LIGHT-01
과 통합 위치. 음악 신호 리드타임 3초 전.

## 외부 라인아웃
DVD 2캠 수음용 XLR 라인아웃 2채널(L/R) 콘솔에서 제공(reply-dvd-전원).

## 준비물
무선 수신기 4채널, 유선 스탠드 1, XLR 케이블 2, MR 파일 백업 USB 2개(정・부).

## 리스크
무선 4채널을 예비 없이 전량 사용 — 리허설(D-7) 전 배터리·채널 간섭 점검을
반드시 마쳐야 하며, 1채널이라도 장애 시 즉시 대체할 여분 마이크가 없다
(구매 검토 필요, 미해결 리스크로 남김).
