# 예식 리허설 기록 (D-7, PLAN-01 주관)
입력: examples/wedding/deliverables/MC/plan.md, examples/wedding/deliverables/MUSIC/plan.md, examples/wedding/deliverables/BG/plan.md, examples/wedding/deliverables/VENUE/plan.md, examples/wedding/deliverables/PHOTO/plan.md, examples/wedding/deliverables/MAKEUP/plan.md

## 실측
- 신부 입장 워킹: 55초(버진로드 22m, 화동 선행 포함) — FIX-MUSIC-입장곡루프로 확정 요청.
- 화동 워킹: 7세(서준)는 단독 완주, 6세(하윤)는 중간 멈춤 2회 → **이모(BG-AUNT-01)가 중간 지점까지 동반 후 손 놓는 방식**으로 확정. 당일 개식 전 별실에서 1회 더 연습.
- 성혼선언 낭독(신랑 아버지): 1차 1분 40초·더듬음 2회 → 문안 2문장 축약, 2차 1분 10초 통과.

## 발견 → 발행 (source=REH)
1. 신랑 입장 음악 미정(MC plan 리스크) → FIX-BG-신랑입장곡 → 잔나비 인트로 20초 확정(퇴장곡과 같은 곡, 구간 분리 사용 — MC 멘트로 중복감 상쇄).
2. 입장곡 루프 미정 → FIX-MUSIC-입장곡루프 → 인트로 8초 + 1절 37초 + 아웃트로 10초 = 55초 확정.
3. 소회의실 배정·반입 병목(FOOD/FLOWER/GIFT 리스크) → FIX-VENUE-배정확정 → 소회의실 A(14:00~14:50) 정식 배정, 반입 FLOWER 11:00~11:20 / GIFT 11:20~11:40 분리.
4. PHOTO·MAKEUP의 MC 식순 미회신 2건 → 진행측이 확정 식순으로 회신(원판 유도 12:52, 혼주 시술 마감 12:20).

## 잔여 리스크 (런시트에 비고로 승계)
- 무선 마이크 4채널 전량 사용, 예비 없음 → 솔로 축가는 유선 예비 1개 스탠바이(음향감독).
- 원판 8분 버퍼(12:52 종료→13:00 시작) → MC가 폐식 즉시 직계가족 잔류 안내(회신 반영).
- 버스 예비 8석 당일 추가 탑승 → 총무(BG-STEWARD) 판단으로 선착순.

검증: 발견 4건 전부 게시글로 발행·회신 완료, 실측 3건 기록.
