# VENUE 요청 회신 — 식순·원판·다과 인사 시간 (REQ-VENUE-BG-식순확정)
입력: brief.md(당사자 의사)

신랑신부(BG-BRIDE·BG-GROOM)가 VENUE 잠정안을 검토 후 확정한다.

1. 예식(개식~퇴장) **12:30~13:00** — 그대로 확정.
2. 원판 촬영 **13:00~13:30** — 그대로 확정(BG의 원판 명단 8개 조합 기준
   충분히 가능하다고 판단, family-photo-list.md 참조).
3. 양가 다과 인사(폐백 대체) **13:30~13:40** — 그대로 확정.
4. 13:40~14:00 하객 뷔페 이동·답례품 수령·정리 — 이견 없음. 혼주는
   다과 인사 종료 즉시(별도 이동 없이 도보 1분 이내) 혼주 테이블로
   이동 가능하다고 확인.

전 구간 VENUE 잠정안대로 확정 처리해 달라. 리허설(D-7)에서 실측 시간으로
재점검 예정.
