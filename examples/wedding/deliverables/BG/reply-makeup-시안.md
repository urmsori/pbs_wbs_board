# MAKEUP 요청 회신 — 신부 시안·샵 출발 시각 (REQ-MAKEUP-BG-시안)
입력: brief.md(당사자 의사)

신부(BG-BRIDE)가 확정한다.

1. **시안**: 확정됨 — 화사한 웨이브 업스타일 + 내추럴 글램 메이크업
   (드레스가 미니멀 실크 라인이라 헤어·메이크업은 화사하게 대비).
2. **시술 장소**: 샵(신부 단골샵, 서울 강남 소재)에서 시술 후 이동.
3. **이동시간**: 샵→라온컨벤션(마포)까지 차량 약 40분(여유 포함 50분
   가정 권장).
4. **희망 출발 시각**: 시술 약 3시간 소요 + 이동 50분 + 현장 여유
   40분(본식 12:30 기준 역산) → **샵 도착 08:00, 출발(샵→식장) 11:00**
   목표. MAKEUP 파트에서 실제 시술 소요시간 기준으로 미세 조정해 달라.
