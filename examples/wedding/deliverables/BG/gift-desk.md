# 축의대 인선·운영 (양가 각 2명, 사촌 이상 친족)
입력: brief.md(당사자 의사), examples/wedding/deliverables/VENUE/reply-bg-별실.md(회신)

## 인선 (brief 예민 요구 — 반드시 사촌 이상 친족)
- 신부측: 이지훈(사촌오빠, BG-COUSIN-01 대표) + 박은채(사촌언니)
- 신랑측: 김서준(사촌형, BG-COUSIN-02 대표) + 김도현(사촌동생)

## 위치·설비 (VENUE 회신)
그랜드홀 입구 로비(엘리베이터 하차 정면), 양가 각 1테이블 총 2테이블
좌우 배치. 테이블마다 잠금 가능한 서랍형 보관함 1개씩 비치.

## 운영 절차
| 시각 | 무엇을 |
|---|---|
| 11:00 | 축의대 세팅(방명록, 봉투함, 볼펜) — 각 조 2명 배치 |
| 11:30~12:25 | 하객 접수(봉투 수령 즉시 잠금함에 투입, 방명록 서명 안내) |
| 12:25 | 잠금함 1차 봉인, 축의대 담당 2명 중 1명은 예식 참관, 1명은 잔류 접수 |
| 12:30~13:00 | 예식 중 늦은 하객 접수 계속(잔류 인원) |
| 13:40 | 접수 마감, 양가 잠금함 각각 BG-STEWARD(양가 총무)에게 봉인 상태로 인계 |
| 13:40~14:00 | 총무가 신랑신부 확인 하에 개봉·집계, 결과를 신랑신부에게 구두 보고 |

## 봉투 인계 절차 (신뢰 확보)
- 인계는 반드시 2인 이상 동석(축의대 담당 1인 + BG-STEWARD)한 자리에서
  진행, 인계 시각·잠금함 상태를 서로 확인 후 구두 확인.
- 집계 후 현금은 즉시 신랑측/신부측 각 대표 보호자(BG-DADG/BG-MOMB)
  에게 전달, 당일 자택 이동 전까지 총무가 보관.

## 리스크
- 접수 피크(11:50~12:20)에 축의대 대기줄이 길어질 수 있음 — VENUE
  안내요원과 동선 분산(2테이블 좌우 배치)으로 완화.
