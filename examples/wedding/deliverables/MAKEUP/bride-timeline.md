# 신부 시술 타임라인 (MU-DIR-01, 원장)
입력: 자기 트랙(-), BG 회신(examples/wedding/deliverables/BG/reply-makeup-시안.md)

## BG 회신 요약
시안 확정(화사한 웨이브 업스타일 + 내추럴 글램), 시술 장소는 강남 단골샵,
샵→식장(마포) 이동 약 40분(여유포함 50분), 목표 샵도착 08:00·출발 11:00.

## 확정 타임라인 (본식 12:30 역산)
| 시각 | 내용 |
|---|---|
| 08:00 | 신부 샵 도착 |
| 08:00–10:00 | 헤어(업스타일) 시술 (2시간) |
| 10:00–10:30 | 메이크업(내추럴 글램) (30분) |
| 10:30–10:50 | 드레스 착장(미니멀 실크 라인) |
| 10:50–11:00 | 최종 점검(헤어핀·메이크업 리터치), 이동 준비 |
| **11:00** | **샵 출발** |
| 11:00–11:50 | 식장 이동(약 50분, 여유 포함) |
| **11:50** | **식장 도착 — 신부 준비 완료** |
| 11:50–12:00 | 대기실에서 부케 수령(FLOWER FLO-01), 드레스 최종 정돈 |
| 12:00 | PHOTO 스냅 시작 가능 |

## 큐
- 08:00 샵 도착 확인 → MU-DIR-01
- 11:00 출발 5분 전, MU-DIR-01이 식장(PHOTO PHO-MAIN-01)에 출발 통보
- 11:50 도착 즉시 MU-DIR-01이 부케팀(FLO-01)·스냅팀(PHO-MAIN-01)에 도착 알림

## 리스크
- 강남→마포 이동 50분은 일요일 낮 기준 여유치이나 결혼식 시즌 예식장
  주변 정체 가능성 있음 — 10분 이상 지연 시 11:50 도착이 밀리며 이는
  뒤이은 원판 30분 슬롯(13:00~13:30)에는 영향 없으나 스냅 준비 컷이
  줄어든다. 지연 시 대기실 스냅 생략하고 바로 본식 동선으로 합류.
