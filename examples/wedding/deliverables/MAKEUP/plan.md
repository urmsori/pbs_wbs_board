# MAKEUP 파트 계획 (헤어메이크업)
입력: MU-DIR-01(bride-timeline.md), MU-ASST-01-GROOM(groom-family-timeline.md),
MU-ASST-01-HANDOFF(helper-handoff.md) — 회신 1건(REQ-MAKEUP-BG-시안)을 입력으로
확정. REQ-MAKEUP-MC-식순은 8×15초 폴링 초과로 잠정치(12:25) 사용 중.

## 역할
- MU-DIR-01(원장) — 리드, 신부 시술(샵)
- MU-ASST-01(부원장) — 신랑·혼주 현장 시술, 헬퍼 이모님 인계

## 당일 타임라인
| 시각 | 내용 | 담당 |
|---|---|---|
| 08:00 | 신부 샵 도착 | MU-DIR-01 |
| 08:00–10:00 | 신부 헤어(업스타일) | MU-DIR-01 |
| 10:00–10:30 | 신부 메이크업 | MU-DIR-01 |
| 10:30–10:50 | 드레스 착장 | MU-DIR-01 |
| 10:50–11:00 | 최종 점검, 이동 준비 | MU-DIR-01 |
| **11:00** | **신부 샵 출발** | MU-DIR-01 |
| 11:00 | 신부 어머니 헤어·메이크업 시작(현장) | MU-ASST-01 |
| 11:15 | 신부 어머니 한복 착장 시작(헬퍼 인계) | MU-ASST-01+헬퍼 |
| 11:40 | 신랑 헤어·메이크업 | MU-ASST-01 |
| 11:52 | 신랑 아버지 | MU-ASST-01 |
| **11:50** | **신부 식장 도착** | MU-DIR-01 |
| 12:00 | 신부 스냅 시작 가능(PHOTO 인계) | MU-DIR-01 |
| 12:04 | 신랑 어머니 | MU-ASST-01 |
| 12:16 | 신부 아버지(최소 터치업) | MU-ASST-01 |
| 12:25(잠정) | 혼주 전원 준비 완료 | MU-ASST-01 |

## 큐
- 08:00 신부 도착 확인 → MU-DIR-01
- 11:00 출발 5분 전 → PHO-MAIN-01·FLO-01에 도착 예정 통보
- 11:15 신부 어머니 메이크업 완료 → 헬퍼 이모님 한복 착장 시작 신호
- 11:50 신부 도착 → FLO-01(부케 전달)·PHO-MAIN-01(스냅 시작) 동시 알림

## 준비물
헤어·메이크업 풀세트(신부용/현장용 별도), 한복 소품(고름·노리개·버선),
현장 조명 거울, 무선 통신(도착 알림용).

## 리스크
1. 신랑·혼주 5인 현장 준비 총 소요(85분)가 가용시간(11:00~12:25 잠정)과
   정확히 일치 — 버퍼 0분(groom-family-timeline.md).
2. 혼주 입장 정확 시각이 잠정치(REQ-MAKEUP-MC-식순 미회신) — 실제
   시각이 더 이르면 버퍼가 마이너스가 될 수 있음, 회신 도착 시 CORR.
