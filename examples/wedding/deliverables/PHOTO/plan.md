# PHOTO 파트 계획 (본식스냅·원판)
입력: PHO-MAIN-01(dongseon.md), PHO-SUB-01-CUE(wonpan-cue.md), PHO-SUB-01-GEAR(gear.md) —
회신 3건(REQ-PHOTO-VENUE-원판, REQ-PHOTO-MAKEUP-완료시각, REQ-PHOTO-BG-가족명단)을
입력으로 확정. REQ-PHOTO-MC-식순은 8×15초 폴링 초과로 잠정치 사용 중.

## 역할
- PHO-MAIN-01(메인 스냅) — 리드, 준비실~본식 동선·전체 취합
- PHO-SUB-01(서브 스냅) — 원판 진행표·장비 백업

## 당일 타임라인 (분 단위)
| 시각 | 내용 | 담당 |
|---|---|---|
| 10:30 | 현장 도착, 장비 체크리스트(gear.md) 수행 | PHO-SUB-01 |
| 12:00 | 대기실 스냅 시작(신부 도착 직후) | PHO-MAIN-01 |
| 12:15 | 로비 착석 안내 스냅 | PHO-SUB-01 |
| 12:25 | 혼주 입장 리액션 | PHO-SUB-01 |
| 12:29–12:30 | 신랑·신부 입장 | PHO-MAIN-01 |
| 12:33 | 성혼선언문 클로즈업 | PHO-MAIN-01 |
| 12:36–12:44 | 축가 2팀 | PHO-MAIN-01 |
| 12:48 | 퇴장 | PHO-MAIN-01 |
| 12:52 | 예식 종료, 원판 대형 유도 시작 | PHO-SUB-01 |
| **13:00–13:30** | **원판 8조합 진행(단상 독점)** — 순번은 wonpan-cue.md | PHO-MAIN-01+SUB-01 |
| 13:30–13:40 | 양가 다과 인사 스냅 | PHO-SUB-01 |
| 13:40 | 철수 | 전원 |

## 큐 (누가·언제·무엇을·누구 신호로)
- 12:00 MU-DIR-01 도착 알림 → PHO-MAIN-01 대기실 스냅 시작
- 12:52 사회자 종료 안내(예상) → PHO-SUB-01 즉시 원판 1순위(직계가족) 호명
- 13:30 정각 → PHO-SUB-01 다과 인사장으로 전원 유도

## 준비물
바디 2+예비1, 렌즈(24-70/70-200/35mm), 메모리카드 듀얼슬롯, 클립온
스트로보 2+예비배터리, 원판용 삼각대 1 (상세 gear.md).

## 리스크
1. 예식 종료(12:52)~원판 시작(13:00) 8분 버퍼가 하객 인사로 소진되면
   30분 슬롯이 25분 이하로 줄 수 있음(dongseon.md).
2. 8개 조합 연속 촬영이라 한 조합이라도 지연되면 마지막 순번(신랑신부
   단독)이 축소될 위험(wonpan-cue.md).
3. 12:15~12:52 세부 타이밍이 잠정치(REQ-PHOTO-MC-식순 미회신) — 실제
   식순과 어긋나면 포지션 이동 컷이 어긋날 수 있음, 회신 도착 시 CORR.
