# 사회 리허설 점검 항목 (MC-리허설항목)
입력: MC-식순초안(order-draft.md) / MC-큐대본(cue-script.md) /
REQ-MC-VENUE-큐방식 회신(VENUE/reply-mc-큐방식.md) /
REQ-MC-BG-식순취향 회신(BG/reply-mc-식순취향.md)

D-7 리허설(REH)에서 아래를 사회자(MC-01) 주관으로 확인한다.

1. **무선 핸드마이크 상태**: 배터리·수신 감도, 사회자용 1대 단독 채널 확인.
2. **수신호 3종 합**: 신호1(시작)/신호2(페이드아웃)/신호3(대기)를 VEN-SOUND-01·
   VEN-LIGHT-01과 실제 멘트 길이로 1회 이상 맞춘다(회신에서 요청한 사항).
3. **성혼선언문 동선·마이크 높이**: 김태영(신랑 아버지) 낭독 경험 없음 —
   단상 옆 계단 이동, 마이크 스탠드 높이, 낭독 속도를 반드시 사전 점검.
4. **혼주 호명 순서**: 신랑측(김태영·최윤정) → 신부측(이광호·박선희) 순서로
   실제 착석 동선까지 맞춰본다(관례 뒤집힌 순서라 실수 위험).
5. **마이크 핸드오프 20초**: 축가① 듀엣→축가② 솔로 전환 시 무선 핸드 2대
   회수·전달 동선을 무대 옆에서 실측, 20초 내 가능한지 확인(VEN-SOUND-01 보조).
6. **화동 동선과의 겹침**: 화동 2명(6·7세, 리허설 없이는 못 걷는 조카들)의
   입장 동선이 신랑신부 입장·혼주 입장과 겹치지 않는지 별도 확인 필요
   (화동 담당 파트와 조율 — 현재 회신 없음, 필요 시 추가 REQ).
7. **축가 전환 멘트 타이밍**: 라이브 피아노(듀엣)에서 MR(솔로)로 넘어가는
   음향 전환이 매끄러운지, 조명 리드타임 0초가 실제로 지연 없이 걸리는지.
8. **원판 촬영 전환 멘트**: 예식 종료~원판 이동 30분 제한을 지키도록,
   종료 안내 멘트에서 바로 이동 유도가 되는지 촬영 파트와 리허설 중 확인.

검증 방식: 각 항목 리허설 당일 체크(○/×), 미흡 항목은 재점검 또는
CORR 게시글로 갱신.
