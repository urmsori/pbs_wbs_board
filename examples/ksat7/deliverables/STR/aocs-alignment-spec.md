# 정렬 기준면·1차모드 회신 (REQ-AOCS-STR)

입력: examples/ksat7/board/REQ-AOCS-STR.md, examples/ksat7/deliverables/STR/str-u1-anl-s.md

## 회신
1) 정렬 기준면(별추적기·자이로 공통 큐브) 면간 수직도: **4.5 arcsec**, 궤도 열드리프트: **2.8 arcsec**
   (합 7.3arcsec ≤ 귀 팀 배분 12.6arcsec 이내). **판정: 충족**
2) SAR 안테나 장착 상태 1차모드: STR 자체 해석치 37.2Hz(잠정 안테나 질량 38kg 가정, REQ-STR-PAY
   회신 대기). 귀 요청 기준 안테나질량 72kg(PAY-U1-DSN 배분치)로는 재해석 필요 — **리스크 오픈**.
   다만 귀 팀 요구 최소치 4.0Hz 대비 현재 마진(37.2Hz)이 매우 커서, 72kg 반영 시에도 4.0Hz는
   여유 있게 상회할 것으로 판단(정성적). STR 자체 기준 35Hz 충족 여부는 REQ-STR-PAY 회신 수신 후
   ANL-S 재해석에서 확정 예정.
