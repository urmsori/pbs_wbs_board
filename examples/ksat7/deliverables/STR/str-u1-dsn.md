# STR-U1 1차구조체 설계

입력: examples/ksat7/deliverables/SE/sysreq.md (STR ≤45kg, 1차모드≥35Hz, 준정적10g)

## 형상
알루미늄 허니컴 샌드위치 패널 6면체 버스 본체(중앙 튜브 + 4측판 + 상/하판).
중앙 튜브(CFRP, Ø400mm)가 발사체 인터페이스~SAR 안테나 장착 상판까지 주하중 경로.
상판에 SAR 안테나(전개형) 힌지 4점 장착 인터페이스 배치(REQ-STR-PAY 회신 대기 중, 잠정 안테나
질량 38kg·PCD 500mm 4점 M10 체결로 가정하고 설계 진행).

## 질량 예산 (잠정, ANL-S 단계에서 확정)
| 부재 | 질량(kg) |
|---|---|
| 중앙 튜브(CFRP) | 9.5 |
| 측판 4매(Al 허니컴) | 14.0 |
| 상/하판 | 11.0 |
| 브래킷·체결류 | 6.5 |
| **합계** | **41.0** (≤45kg 목표 대비 마진 4.0kg) |

## 다음 단계
ANL-S(구조해석)에서 SAR 안테나 장착 상태 1차모드·준정적 10g 마진 검증, ANL-T(열해석) 병렬 진행.
REQ-STR-PAY 회신 수신 시 안테나 질량·장착 인터페이스로 상판 설계 갱신.
