# PROP-U1 성능해석 (Δv·추진제 예산, 4년 수명)

sysreq 판정 기준: Δv 25m/s, 홀추력기 300W급, 제논 예산.

## 4년 궤도유지 시나리오
- 대기항력 보상 포함 연간 Δv 소요 ≈6.1m/s(550km LEO 태양활동 평균), 4년
  누적 ≈24.4m/s. sysreq 25m/s 대비 여유 0.6m/s(2.4%) — 낮음, 태양활동 고조기
  대비 별도 마진 필요 플래그.
- 총 추진제 소요: 24.4m/s 기준 mp=280×(1-exp(-24.4/14,710))≈0.465kg. 설계
  마진(unit1-prop-design 30%) 적용 예산 0.62kg으로 재계산 시 등가 Δv여유
  25×(0.62/0.465-1)... → 예산 0.62kg은 25.6m/s 상당(mp 재변환), sysreq
  25m/s 대비 여유 0.6m/s(2.4%) 확보.
- 탱크 최대 탑재 1.1kg(unit1-prop-design) 대비 소요 0.62kg → 탑재여유 77%
  유지(추가 태양활동 고조기 대비 여유로 활용 가능).

## 판정
Δv 예산 0.6m/s 여유(2.4%, 낮음 — 플래그) 확보하나 탱크 탑재 여유(77%)로
충전량 상향(최대 1.1kg 충전)하면 실질 Δv 여유 ≈9.2m/s(37%)까지 확대 가능 —
CHK 단계에서 충전량을 설계치(0.62kg)에서 여유치(1.0kg)로 상향 권고.

검증: sysreq Δv25m/s 대비 설계치 여유2.4%(낮음, 플래그) → 탱크여유 활용 시
37%까지 확대 가능(권고), 300W/1500Isp 가정 정합
