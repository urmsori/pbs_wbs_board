# PAY-U1 안테나 방사시험 품질보증 입회 확인서

입력: examples/ksat7/deliverables/PAY/u1-ins.md, u1-antenna-design.md

## 입회 대상
능동위상배열 안테나 방사패턴 시험(PAY-U1-TST) 착수 전 입회.

## 입회 확인 사항
1. 선행 최종검사(u1-ins.md) 결과 대조 — 개구 평탄도 0.42mm(허용≤0.5mm) PASS,
   T/R모듈 1,200개 전기 연속성 전수 PASS, 실측질량 72.3kg 확인
2. 시험 형상(CM 베이스라인 PAY-U1-BL-001) 대비 시험체 형상 일치 확인
3. 시험 전 CAL·FAC 서비스 완료 상태 확인 — CAL-PAY-U1(계측장비 교정), FAC-PAY-U1
   (전파무향실 예약) 병행 처리 확인
4. 시험 절차서(방사패턴·NESZ 측정 시나리오) 검토 — sysreq 판정기준(개구 손실
   등)과 정합 확인

## 판정
입회 결과 이상 없음(No Finding). PAY-U1 방사패턴 시험 착수 승인.

검증: 최종검사 결과(평탄도 0.42≤0.5mm, T/R모듈 1200/1200 PASS, 질량72.3kg) 및 시험
형상 일치 확인, 입회 완료(이상 없음).
