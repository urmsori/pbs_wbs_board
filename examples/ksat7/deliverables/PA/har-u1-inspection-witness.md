# HAR-U1 검사(INS) 품질보증 입회 기록

입력: examples/ksat7/deliverables/HAR/u1-cleaning.md, u1-thermal-analysis.md

## 입회 대상
세척 완료(u1-cleaning.md, 청결도 이상無)된 HAR-U1 배선 조립체 2식의 도통·절연저항·
펄스 시 전압강하 검사(HAR-U1-INS-01)에 입회.

## 입회 확인 사항
1. 세척 결과 문서 대조 — 육안검사(백라이트) 이상無, 잔류 플럭스 검출 없음 확인
2. 도통시험: 2식 전 배선 도통 정상(단선 없음) 확인
3. 절연저항시험: 2식 전 배선 절연저항 규정치(≥100MΩ @500VDC) 이상 확인
4. 펄스 시 전압강하: sysreq.md 판정기준(≤3% @펄스) 대비 설계치(u1-thermal-analysis.md
   전압강하 0.85~1.70%) 이내에서 실측 결과 확인 — 판정기준 이내

## 판정
입회 결과 이상 없음(No Finding). HAR-U1 배선 조립체 2식 검사 합격, 다음 단계(조립/시험)
진행 가.

검증: 도통·절연저항·펄스 전압강하(0.85~1.70%≤3% 기준) 3개 항목 입회 확인, 2식 모두 합격.
