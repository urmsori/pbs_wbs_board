# HAR-U1 검사(INS) 품질보증 입회 기록

입력: examples/ksat7/deliverables/HAR/u1-cleaning.md, u1-thermal-analysis.md,
examples/ksat7/deliverables/HAR/u1-inspection.md(정정 근거, PA-HAR-U1-CORR-01)

## 정정 이력 (PA-HAR-U1-CORR-01, source=AUDIT-4)
최초 기재(정정 전)는 검사 착수 시점에 설계 예측치(u1-thermal-analysis.md
0.85~1.70%)를 잠정 인용했으나, 감사(AUDIT-4)에서 검사 완료 후 산출물
(u1-inspection.md)의 실측치와 대조한 결과 표기가 실측치가 아닌 설계 예측치임이
확인되어 아래와 같이 실측치로 정정한다. 판정(합격) 자체는 변경 없음.

## 입회 대상
세척 완료(u1-cleaning.md, 청결도 이상無)된 HAR-U1 배선 조립체 2식의 도통·절연저항·
펄스 시 전압강하 검사(HAR-U1-INS-01)에 입회.

## 입회 확인 사항
1. 세척 결과 문서 대조 — 육안검사(백라이트) 이상無, 잔류 플럭스 검출 없음 확인
2. 도통시험: 2식 전 배선 도통 정상(단선 없음) 확인
3. 절연저항시험: 2식 전 배선 절연저항 실측 245MΩ/238MΩ(규정치 ≥100MΩ @500VDC 대비
   2배 이상) 확인
4. 펄스 시 전압강하(실측, u1-inspection.md): 정상운전 계통1 0.86%/계통2 0.87%,
   단일고장(계통1 단독 전량부담) 1.72% — sysreq.md 판정기준(≤3% @펄스) 이내

## 판정
입회 결과 이상 없음(No Finding). HAR-U1 배선 조립체 2식 검사 합격, 다음 단계(조립/시험)
진행 가.

검증(정정): 도통 2/2 정상, 절연저항 245/238MΩ(≥100MΩ), 펄스 전압강하 정상운전
0.86~0.87%·단일고장 1.72%(≤3% 기준) 실측치로 3개 항목 입회 확인, 2식 모두 합격.
