# OBC→COMM 고속 인터페이스·재생버퍼 사양 (REQ-COMM-OBC 회신)

입력: examples/ksat7/deliverables/SE/sysreq.md, OBC-U1-DSN 설계 진행분(2TB 저장부)

REQ-COMM-OBC 3개 질의에 회신한다.

## 1) 고속 인터페이스 종류·보장 처리량
- 인터페이스: SpaceWire(SpW), 다운링크 전용 1채널.
- 보장 처리량: 850 Mbps (sysreq X-band 800Mbps 대비 마진 6.25%).

## 2) 재생 버퍼 심도·언더런 여유
- 레코더 출력단 elastic 버퍼: 256 Mbit(32MB).
- 800Mbps 연속 하향 기준 버퍼 재생 여유 320ms, 언더런 마진 ≥15%
  (레코더 판독 대역폭 ≥ 920Mbps로 설계, 하향 800Mbps 대비 15% 여유).

## 3) 원시 2TB 중 1회 접촉당 재생 가능 범위
- 표준 접촉시간 가정(잠정, GS 팀 확인 전): 8분(480s) @ 800Mbps
  = 384 Gb ≈ 48 GB/접촉.
- 2TB 저장 용량 기준 약 40회 접촉분 여유 저장 가능(누적 미하향분 버퍼 역할).

## 잠정 사항
- SAR 원시데이터 순간/평균 유입률은 REQ-OBC-PAY 회신 대기 중(8회×20초 폴링
  초과, 무응답) — 본 사양의 기록(write) 대역폭은 sysreq X-band 800Mbps·2TB
  저장을 근거로 한 설계 목표치(≥920Mbps 판독, 기록 ≥1.2Gbps 설계 여유)이며,
  PAY 실회신 도착 시 정정 여지가 있다.
- GS 접촉시간 8분은 잠정 가정(GS 미확인) — 실측 접촉시간 확정 시 재생 가능
  범위 재계산 필요.

검증: 인터페이스 처리량 850Mbps ≥ 하향 800Mbps(마진 6.25%), 재생버퍼
언더런 마진 ≥15% — REQ-COMM-OBC 요청 3항목 전부 수치 회신.
