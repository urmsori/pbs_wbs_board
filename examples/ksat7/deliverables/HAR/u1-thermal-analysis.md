# HAR-U1 대전류 펄스 배선 줄열 해석

입력: examples/ksat7/deliverables/HAR/u1-design.md, examples/ksat7/deliverables/SE/sysreq.md

## 조건
- 펄스 전류 I = 36.0A, 펄스 지속 ≤90s/궤도 (sysreq.md)
- 배선 저항 R = 0.01917 Ω (왕복 6m, AWG10, u1-design.md)
- 도체 단면적 A = 5.26mm², 구리 밀도 8960kg/m³, 비열 c = 385 J/kg·K
- 주변 환경온도: TCS SAR송수신기 열부하 관리 범위 -15~+45°C (sysreq.md TCS
  항목) → 최악조건 +45°C 채택
- 절연재: 항공우주용 PTFE 절연 와이어 등급 정격 200°C (일반 규격 기준)

## 줄열 계산 (단열 근사, 보수적 — 대류·전도 방열 무시)
- 소모전력 P = I²R = 36.0² × 0.01917 = 24.85 W
- 90s 펄스 에너지 Q = P × t = 24.85W × 90s = 2236.5 J
- 도체 질량 m = A × L × 밀도 = 5.26e-6 m² × 6m × 8960kg/m³ = 0.2828 kg
- 온도상승 ΔT = Q / (m × c) = 2236.5 / (0.2828 × 385) = **20.5°C**

## 판정
최악 주변온도 45°C + ΔT 20.5°C = 도체 최고온도 **65.5°C** ≤ 절연재 정격
200°C → 대여유(134.5°C 마진). 단열 근사(방열 무시)로 보수적 계산했음에도
충분한 여유 확보. 90s 펄스가 궤도당 1회(주기 대비 짧음)이므로 궤도 간
방열로 정상상태 복귀 가능.

검도 대상 자료로 HAR-U1-CHK-01에 전달.
