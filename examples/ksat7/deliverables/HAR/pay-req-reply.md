# REQ-PAY-HAR 회신 — 대전류 펄스 배선 요구 확인

입력: examples/ksat7/board/REQ-PAY-HAR.md, examples/ksat7/deliverables/HAR/u1-design.md

## PAY 요구 (REQ-PAY-HAR)
- 첨두전류 40.0A (1.8kW / 45V, 펄스 중 최저 모선전압 기준)
- 이중화 2계통 분산급전, 계통당 20.0A
- 계통당 배선저항 상한 0.0675Ω (전압강하 ≤3% @펄스 만족용)
- EMC 차폐(펄스 스위칭 노이즈) 요구

## HAR-U1 설계 대조 (u1-design.md)
- 배선: AWG10 트위스트 페어, 왕복 6m, 저항 R = 0.01917Ω/계통
  → PAY 저항 상한 0.0675Ω 대비 **72% 여유**
- 계통당 20.0A 인가 시 전압강하 ΔV = 20.0A × 0.01917Ω = 0.383V
  → 0.383V / 45V(최저 모선전압) = **0.85%** ≤ 3%
- 단일계통 고장 가정(40.0A 전량 한 계통 부담) 시에도
  ΔV = 40.0A × 0.01917Ω = 0.767V → 0.767/45 = **1.70%** ≤ 3% (단일고장
  허용 여유 확인, sysreq MECH "단일고장 허용" 원칙과 정합)
- EMC 차폐: 배선 편조 실드 + 단일점 접지(SPG) 적용 예정(HAR-U2 INS 단계
  차폐 검사로 최종 확인)

## 판정
계통당 20.0A·저항≤0.0675Ω 조건에서 전압강하 0.85% ≤ 3% **만족**.
단일계통 전량 부담(40.0A) 조건에서도 1.70% ≤ 3% **만족** — 설계 변경 불요.
