# HAR-U1 대전류 펄스 배선 제작/조립

입력: examples/ksat7/deliverables/HAR/u1-iqc.md, examples/ksat7/deliverables/CM/har-u1-release.md

## 공정
1. AWG10 케이블 2계통(이중화) 각 3m 편도 절단, 왕복 6m 배선 구성
2. 전원 커넥터(잠정 PCDU-PWR-J4 정합) 압착 단자 접속(극당 2핀 병렬)
3. 편조 실드 슬리브 장착, 단일점 접지(SPG) 단자 접속
4. 계통 라벨링(계통1/계통2), 커넥터 극성 표기

## 결과
2계통 배선 조립체 각 1식(총 2식) 완성. 육안상 압착 불량·피복 손상 없음.
세척(CLN) 단계로 인계.
