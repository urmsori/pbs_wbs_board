# HAR-U1 대전류 펄스 배선 설계 (SAR 1.8kW)

입력: examples/ksat7/deliverables/SE/sysreq.md, REQ-HAR-EPS(회신 대기 타임아웃 — 잠정 가정 사용)

## ICD 상태
REQ-HAR-EPS를 HAR-U1-DSN-01 착수와 동시에 발행(track: EPS), 8회×20초
폴링에도 EPS 회신 없음 → **잠정 가정**으로 설계 진행(아래 명시). EPS 회신
도착 시 CHK 단계에서 재확인 필요(리스크로 module-fm.md에 기록).

### 잠정 가정 (EPS 배전 커넥터·채널 정격)
- 모선 전압: 50V±5V (sysreq.md 인용)
- PCDU 배전 출력 커넥터: 4핀 파워 커넥터(원형, 잠정 p/n PCDU-PWR-J4), 극당
  2핀 병렬
- 채널 전류 정격(잠정): 연속 20A/핀 × 2핀 병렬 = 40A/극, 펄스(≤90s) 60A/극
  허용 가정

## 부하 산정
- SAR 첨두 펄스 부하: 1.8kW, 최대 90s/궤도 (sysreq.md)
- 펄스 전류 I = P/V = 1800W / 50V = 36.0A
- 잠정 채널 정격(60A 펄스) 대비 여유 40% → 채널 배분 타당

## 배선 설계
- 왕복 배선 길이(PCDU→SAR 송수신기, 위성 내부): 3m 편도 → 6m 왕복
- 도체: AWG10 트위스트 페어(단면적 5.26mm²), 구리 저항률 ρ=1.68e-8 Ω·m
- 배선 저항 R = ρ·L/A = 1.68e-8 × 6 / 5.26e-6 = 0.01917 Ω
- 펄스 시 전압강하 ΔV = I×R = 36.0A × 0.01917Ω = 0.690V
- 전압강하율 = 0.690V / 50V = **1.38%**

## 커넥터 배정
- PCDU측: 잠정 PCDU-PWR-J4 (4핀, 극당 2핀 병렬, 20A/핀)
- SAR송수신기측: HAR 측 정합 커넥터 동일 형식(대향)
- 접지/차폐: 배선 편조 실드 접지, 단일점 접지(SPG) 적용

## 검도 대상
- 케이블 사양표, 커넥터 핀맵, 전압강하 계산서(위)

## 판정 (sysreq.md HAR 항목: 펄스 시 전압강하 ≤3%)
설계 예측치 1.38% ≤ 3% → **여유 있음** (EPS 실측 커넥터 정격 확정 시
재계산 필요 — 잠정 가정 리스크).
