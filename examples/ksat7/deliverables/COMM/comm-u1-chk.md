# COMM-U1 X-band 송신계 도면 검도

입력: examples/ksat7/deliverables/COMM/comm-u1-dsn.md, comm-u1-anl-s.md, comm-u1-anl-t.md

## 검도 항목
1. BOM: 변조기(DVB-S2 ASIC 1) / 업컨버터(1) / SSPA(GaN, RF10W, 1) / 도파관+아이솔레이터(1식) /
   안테나(18dBi, 1) / 장착 브래킷(1) — 5부품 + 브래킷, 질량 합계 3.0kg(배정치와 일치).
2. 치수: 브래킷 볼트홀 4×M8 PCD150mm±0.05mm, STR 회신 규격과 일치 확인.
3. 공차: SSPA 베이스플레이트 평면도 0.05mm(열접촉 저항 관리용, ANL-T 결과 반영).
4. 인터페이스 라벨: SpW 커넥터 핀맵, 50V 급전 커넥터 극성 표기 확인.
5. 결함: 없음(3건 사소 지적 — 커넥터 라벨 폰트 크기 확대 요청, RVW 단계로 이관).

판정: 도면-해석-ICD 3자 정합 확인, 결함 없음(사소 지적 3건은 RVW에서 처리).
