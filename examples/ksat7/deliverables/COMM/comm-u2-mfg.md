# COMM-U2 S-band TT&C 장착·배선

입력: examples/ksat7/deliverables/COMM/comm-u2-iqc.md

## 조립 기록
1. 트랜스폰더를 버스 내부 패널에 4점 체결.
2. S-band 안테나(옴니, 기존 버스 헤리티지 안테나 재사용) 급전선 연결, VSWR 1.08 확인.
3. 전원(50V→내부 DC-DC 변환, 트랜스폰더 자체 레귤레이터) 및 커맨드/텔레메트리
   데이터 버스(CAN) 하네스 연결.

## 조립 후 기능 예비통전
- 업링크 64kbps 수신 락 확인, 다운링크 2Mbps 송출 확인(기저대역 루프백)

판정: 장착·배선 완료, 기능 예비통전 정상. CLN 단계로 인계.
