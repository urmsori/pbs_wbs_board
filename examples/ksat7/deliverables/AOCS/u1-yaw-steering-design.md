# AOCS-U1 요 스티어링 제어계 설계
입력: examples/ksat7/deliverables/SE/sysreq.md

## 지향오차 RSS 배분
sysreq AOCS 항목(지향 0.02° 3σ, 요 스티어링 ±4°, 안정도 0.003°/s)을 아래로 배분한다.

| 오차원 | 배분 | 근거 |
|---|---|---|
| 센서(별추적기) 측정오차 | 0.0035° | AOCS-U2 수락시험 판정 기준 |
| 자이로 전파오차 | 0.0040° | AOCS-U2 수락시험 판정 기준 |
| 정렬오차(별추적기-자이로-본체) | 0.0035° | REQ-AOCS-STR(STR 정렬 기준면) 입력 필요 |
| 제어계 잔류오차 | 0.0180° | 본 설계(제어법칙) |
| **RSS 합계** | **0.0197°** | ≤ sysreq 0.02°, 마진 1.5% |

## 요 스티어링 프로파일
- 목적: SAR 관측 중 지구자전에 의한 도플러 편이 보상.
- 요각 프로파일: 궤도 위도에 따라 정현적으로 변화, 최대 ±4.0°(sysreq 정합), 변화율 ≤0.05°/s.
- 안정도 요구(관측 노출시간 중): 0.003°/s(sysreq 정합), 본 설계 목표 0.0026°/s(마진 13%).

## 제어대역폭 목표
- 폐루프 대역폭(-3dB): 0.8 Hz.
- 위상여유 ≥45°, 이득여유 ≥6dB 목표(AOCS-U1-ANL-S에서 해석 확정).
- SAR 안테나(전개형 구조물)가 제어루프 부하에 물려 있으므로, 제어대역(0.8Hz)이
  안테나 1차모드를 최소 5배 이상 이격해야 제어-구조 연성(control-structure
  interaction)이 없다 → 안테나 1차모드 ≥4.0Hz 필요. STR에 정렬 기준면
  안정도와 함께 이 강성 조건을 확인 요청한다(REQ-AOCS-STR).

## 센서·액추에이터 1차 사이징
- 별추적기(STT) 1기 + 예비 1기: 측정정확도 배분 0.0035°.
- 자이로(IMU) 1기(3축) + 예비: ARW 배분, 전파오차 배분 0.0040°.
- 반작용휠 4기(3축+여유 1기, 단일고장 허용): 최대토크 ≥0.10 N·m, 모멘텀 ≥12 N·m·s
  (요 스티어링 ±4° 기동을 소요시간 이내 수행하는 데 필요한 토크 여유 포함).
- 마그네토커 3기(모멘텀 덤핑).

## sysreq 판정 근거
RSS 배분 0.0197° ≤ sysreq 0.02°(3σ), 요 스티어링 ±4.0° 정합, 안정도 목표
0.0026°/s ≤ 0.003°/s. 최종 판정은 AOCS-U1-TST(HIL) 실측으로 확정한다.
