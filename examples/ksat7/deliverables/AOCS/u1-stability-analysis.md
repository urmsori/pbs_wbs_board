# AOCS-U1 제어루프 안정성 해석
입력: examples/ksat7/deliverables/AOCS/u1-yaw-steering-design.md

## 해석 방법
선형화 플랜트(반작용휠+본체 강체모드) + 안테나 1차모드(가정 4.0Hz, REQ-AOCS-STR
회신 대기 중 잠정치)를 포함한 개루프 전달함수의 보드선도 해석.

## 결과
| 항목 | 목표 | 해석 결과 |
|---|---|---|
| 폐루프 대역폭 | 0.8 Hz | 0.79 Hz |
| 위상여유 | ≥45° | 52.3° |
| 이득여유 | ≥6 dB | 8.1 dB |
| 안테나모드 이격(대역폭 대비 배수) | ≥5배 | 5.06배(4.0Hz 잠정치 기준) |

## 판정
위상여유 52.3°≥45°, 이득여유 8.1dB≥6dB PASS. 안테나 1차모드는 REQ-AOCS-STR
회신(STR 실측/해석치)으로 확정 필요 — 잠정치 4.0Hz로는 이격 배수 5.06배로
목표(5배) 충족하나 마진이 1.2%로 작아, STR 회신 도착 시 재확인 권고.
