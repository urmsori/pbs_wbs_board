# PCDU·슈퍼캡뱅크 구조해석

입력: examples/ksat7/deliverables/EPS/pcdu-pulse-design.md, examples/ksat7/deliverables/SE/sysreq.md

준정적 10g(sysreq STR 항목 인용) 가진 시 슈퍼캡뱅크 체결부(M5×8) 최대응력
118MPa(알루미늄 6061-T6 항복강도 276MPa 대비 안전여유 SF=2.3), 섀시 1차
고유진동수 212Hz(위성 1차구조 목표 35Hz 대비 충분히 이격, 커플링 우려 없음).

검증: 준정적10g 응력여유 SF2.3(충족), 고유진동수212Hz로 구조 커플링 없음.
