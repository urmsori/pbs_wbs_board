# 1.8kW 펄스 파형 공급 확약 (REQ-PAY-EPS)

입력: examples/ksat7/board/REQ-PAY-EPS.md, examples/ksat7/deliverables/EPS/pcdu-pulse-design.md

파형(첨두 DC 1.8kW, 5s×최대18회/궤도, 듀티6%, 상승/하강<1ms)을 검토했다.
- 궤도당 총 버스트시간 5s×18=90s = sysreq 최대치와 정확히 일치.
- 슈퍼캡 분담 에너지/버스트 ≈ 1.8kW×5s×0.35 ≈ 3.15kJ, PCDU 재충전 능력(≤200W)
  기준 완전재충전 소요 **15.8s**. 궤도주기(~5700s, 550km) 대비 18회 균등분산 시
  평균 간격 ~316s로 재충전 여유 충분.
- 판정: **조건부 가능**. 조건: 연속 두 버스트 사이 간격 ≥20s(재충전 여유
  마진 포함) 유지. 상승/하강 <1ms 트래피조이드는 PCDU 출력단 슬루제한
  레귤레이터로 대응 가능(설계 확정, EPS-U1-CHK에서 도면 반영).
- 모선 전압강하(펄스 중) 예측: 45V 하한 근접 시 최대 -1.8V(약 -3.6%),
  50V±5V 규격(45~55V) 이내.

검증: DoD≤30% 조건에서 5s×18회/궤도·듀티6% 파형 조건부 공급 가능(버스트간격≥20s), 전압강하 예측 -3.6%(규격내)
