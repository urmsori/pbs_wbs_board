# 배전 커넥터·전류정격 회신 (REQ-HAR-EPS)

입력: examples/ksat7/board/REQ-HAR-EPS.md, examples/ksat7/deliverables/EPS/pcdu-pulse-design.md

- 모선 전압: **50V±5V**(45~55V).
- 주배전 커넥터: MIL-DTL-38999 III 원형, 전력핀 8핀, 핀당 정격 **40A**.
- SAR 펄스 전용 채널(슈퍼캡·배터리 하이브리드 출력단): 전용 2핀(공급+리턴),
  연속정격 **45A**(1.8kW/50V=36A, 마진1.25배), 펄스 서지정격 90A(≤90s).
  권장 배선 굵기 8AWG.
- 전압강하 ≤3% @펄스 판정용 예산: 45~55V 기준 3% = 1.35~1.65V. 36A 기준
  허용 왕복 케이블저항 **≤41.7mΩ**(HAR 측 케이블 길이·굵기 산정에 사용).

검증: 모선50V±5V·펄스채널45A연속/90A서지·전압강하예산41.7mΩ 회신
