# 위성통합상태 1.8kW 펄스 흡수·계측 설비 구성·교정 기록

## 장비 구성
- **고속 DAQ 시스템**
  - 메인 모듈: 18-비트 동시샘플 DAQ (200kHz 최대 샘플율)
  - 채널: 16개 (EPS 버스 전압/전류 4채널 + PAY 센서 8채널 + 보조 센서 4채널)
  - 에지 포착 대역폭: <0.5ms (<1ms 요구사항 충족)
  - 메모리: 512GB SSD + 네트워크 스토리지(NAS) 연동
- **인라인 계측 프로브 세트**
  - 전압 프로브: 버스 레일(±30V 동작범위), 정확도 ±0.1%
  - 전류 프로브 (홀 센서): 배터리-PCDU 하니스 인라인(±50A, 0.2A 해상도)
  - HAR 커넥터 정합형 분기 패드 (핀아웃 확인 완료)
- **저장 용량**: 20궤도 연속 로깅 가능 (샘플율 100kHz, 16채널 기준 ~1.2TB/20궤도)
- **동기화**: GPS-타이밍 기준 시계 (분산 재구성용 나노초 정확도)

## 교정 결과
| 항목 | 보정값 | 정확도 |
|------|-------|-------|
| 전압 측정 (±30V) | 0부터 +30V, 선형도 확인 | ±0.1% |
| 전류 측정 (±50A) | 0부터 +50A, 오프셋 영 | ±0.2% |
| 에지 포착 지연 시간 | 0.35ms (1kHz 스텝) | <0.5ms |
| 다채널 시간 스큐 | <50ns (16채널) | <100ns |
| 저장 시스템 처리율 | 204.8Mbps (200kHz×16) | 충분(1Gbps 링크) |

## 사용법
위성을 정격 540W EOL 부하에서 운영하고, EPS 배터리-PCDU-PAY 실 하니스에 인라인 프로브를 기존 고정점 그대로 접속 후 DAQ 레코드 시작.

## 제한사항
- 위성 정상부하: 540W ±50W 범위만 보증 (범위 초과 시 프로브 안정성 저하)
- 펄스 연속 시간: 18회×5s = 90s 한계(스테이션홀딩 능력) 후 슈퍼커패시터 재충전 18.9s 필요
- 환경: 실험실 온도 20±2°C (프로브 온도 드리프트 제어)
- 케이블 길이: 프로브-DAQ 거리 <10m (신호 감쇠 제한)
- 재검교정: 200시간 운영 후 또는 프로브 교체 시 필수
