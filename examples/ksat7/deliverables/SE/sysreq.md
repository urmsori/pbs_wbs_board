# K-SAT 7 시스템 요구사항 (rev.1)
입력: 없음 (임무 정의 — 유일한 무입력 산출물)

## 임무
저궤도 550km, C-band SAR 스트립맵 3m / 스팟 1m, 수명 4년, 발사질량 ≤300kg.

## 시스템 예산
| 항목 | 할당 |
|---|---|
| 발사질량 | ≤300 kg (마진 15%) |
| 궤도평균전력 | 620 W 공급 / 540 W 소비 (EOL) |
| SAR 첨두 펄스 부하 | 1.8 kW, 최대 90 s/궤도 |
| 지향 | 0.02° (3σ), 요 스티어링 ±4° |
| 데이터 | X-band 800 Mbps, 원시 2 TB 저장 |
| Δv | 25 m/s (홀추력기) |

## 서브시스템 상위 요구 (요약)
- STR: 1차구조 ≤45kg, 1차모드 ≥35Hz(SAR 안테나 장착 상태), 준정적 10g.
- MECH: SAR 2단 전개·SA 3윙 전개, 전개충격 ≤40g, 단일고장 허용.
- TCS: SAR 송수신기 첨두 열부하 관리(-15~+45°C), 배터리 5~+25°C, 히터 ≤40W.
- PROP: Δv 25m/s, 홀추력기 300W급, 제논 예산.
- EPS: 모선 50V±5V, SAR 펄스 1.8kW 버스트 대응(슈퍼커패시터/배터리 하이브리드), DoD ≤30%.
- SA: EOL 900W, 전개 후 1차모드 ≥0.5Hz.
- AOCS: 0.02°, 요 스티어링 ±4°, 안정도 0.003°/s.
- OBC: 처리여유 ≥50%, 원시 2TB, SpW/CAN.
- COMM: S-band 64k/2M, X-band 800Mbps(DVB-S2).
- PAY: C-band 능동위상배열(전개형), 펄스 1.8kW, NESZ ≤ -19dB.
- HAR: 대전류 펄스 배선(전압강하 ≤3% @펄스), EMC 차폐.
- FSW: 비행 관리 + SAR 촬영 시퀀서, 안전모드.
- GS: 수신 3개소, 초기운용 30일, SAR 보정 계획.

검증: 각 팀 인도 산출물이 자기 항목을 인용해 수치로 판정한다.
