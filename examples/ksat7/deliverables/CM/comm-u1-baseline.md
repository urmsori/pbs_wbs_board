# COMM-U1 형상관리 배포 기록 (X-band 송신계)

입력: examples/ksat7/deliverables/COMM/comm-u1-rb.md

## 배포 대상
- 도면·BOM·ICD 3건 반영본: COMM-U1-DWG-001 (송신계 배치도, 커넥터 라벨 폰트 확대
  반영), COMM-U1-BOM-001, COMM-U1-ICD-001
- 판정 근거: COMM-U1-RB 승인(Design Approved) — RVW-A(조건부 승인, 커넥터 라벨
  폰트 확대 반영)·RVW-B(승인, TCS 통합 열해석 재확인 리스크) 종합

## 배포
- 베이스라인 ID: COMM-U1-BL-001
- 개정: Rev A (조건 1 반영 완료 배포)
- 배포일: 2026-08-27
- 배포처: PUR(부품 구매) 대기 — 이 기준선을 입력으로 사용
- 승계 리스크: INT 단계에서 TCS와 -Y측판 공유 열예산 재확인 필요(COMM 단독 판정 범위
  밖) — module-fm.md 리스크로 승계

## 형상관리 처리
1. RB 판정 문서와 도면·BOM·ICD 목록 대사 — 일치, 커넥터 라벨 폰트 확대 반영 확인
2. 베이스라인 등록 완료, 구매 단계 처리 가능 상태로 전환

검증: RB 판정 대비 조건 1(라벨 폰트 확대) 반영 확인, 조건 2(TCS 열예산)는 INT
리스크로 승계, 베이스라인 COMM-U1-BL-001 등록.
