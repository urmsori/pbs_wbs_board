# MECH-U1 전개충격 재검증 (PAY 실측 ICD 반영)

입력: examples/ksat7/deliverables/MECH/mech-u1-anl-s.md, examples/ksat7/board/REQ-MECH-PAY.md,
examples/ksat7/deliverables/PAY/mech-deployment-reply.md

## 변경 입력
- 패널 관성: 잠정 4.2kg·m² → 실측 **루트 46.7 / 팁 44.0 kg·m²**(약 10배 증가).
- 잠금 예비하중 ≥15N·m, 래치 결합력 ≥500N, 잠금 반력 힌지축 최대 850N.

## 재해석 결과
관성이 크게 증가해 동일 스프링·댐퍼로는 종단각속도가 낮아지나(관성↑→가속 느림) 축적
운동에너지(∝Iω²)가 커 잠금 시 반력이 sysreq 40g 한계에 근접. 댐퍼 점성계수를 실측
관성비(약×10)에 맞춰 재조정(1단 댐퍼 계수 +180%, 2단 +165%) 후 재계산한 결과
착지충격 **36.4g** — sysreq 전개충격≤40g 대비 마진 3.6g(9%). **판정: 조치 후 충족**
(마진이 STR-U1보다 타이트하므로 리스크 등급: 중간/YELLOW로 관리, 실물 시험(TST)에서
반드시 실측 검증).
단일고장: 이중화 릴리즈·잠금 구조는 관성 변경과 무관, 기존 판정(단일고장점 없음) 유지.

## 조치
댐퍼 사양 변경을 MECH-U1 도면(MECH-U1-DWG 뎀퍼 사양) 개정 필요 — CM에 개정 통보,
PUR-MECH-U1(댐퍼 구매)에 신규 사양 반영 권고. 최종 확정은 TST(정현/전개시험) 실측치.
