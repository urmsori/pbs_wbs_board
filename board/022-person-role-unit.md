사용자 지적: K-SAT 3(20건)은 실제 위성을 만들었다고 보기엔 WBS/PBS가 너무
적다. 원인은 v2.3의 "혼자 할 수 있으면 쪼개지 않는다"에서 **"혼자"가
에이전트 1개로 해석**된 것이다. 에이전트 하나가 트랙 전체를 맡으니 수십
명 몫의 일이 Work 하나로 뭉쳐졌다. 실제 위성 개발은 300명 이상이 참여하고,
Work 수는 사람 수 × 인수인계에서 나온다.

산출물: RULES.md v2.4 —
① "혼자"의 기준은 에이전트가 아니라 **사람(역할)**이다. Work = 한 사람이
   한 번에 맡는 인수인계 단위. "남" = 다른 사람(역할).
② `owner`에는 사람(역할) 이름을 쓴다(예: STR-DSN-03). 에이전트는 실행
   주체일 뿐이며 **한 에이전트가 여러 사람의 역할을 나눠 맡는다** — 같은
   에이전트가 두 역할을 다 맡고 있어도 역할이 다르면 인수인계는 게시글이다.
③ 내부 단계 = 한 사람이 혼자 하는 일(본문 작업 기록)로 재정의.
검증: 사람 300명 이상 규모의 예시(examples/ksat4)를 이 단위로 실제로 돌린다.
