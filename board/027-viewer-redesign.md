사용자 요청: HTML 뷰어를 처음부터 설계해서 다시 만들라.

기존 구조의 한계(백지 재설계의 근거):
① 같은 Gantt를 모드별(모듈/사람/계층)로 3벌 미리 렌더해 큰 보드에서 파일이
   비대해지고, 접기·상세가 별도 details 섹션으로 흩어졌다.
② 줌이 "내부 폭 배율" 편법이라 시간 눈금이 없고, 확대해도 축이 안 따라온다.
③ 화살표가 항상 전부 그려져 큰 보드에서 실타래가 된다. 선택한 Work의
   사슬만 보는 방법이 없다.
④ 다크 모드 없음, 세로 스크롤 시 축·라벨 고정 없음.

산출물 설계:
- python = 파서·검사기·JSON 내장기. JS = 단일 렌더러(모드는 묶음 함수일 뿐).
- 시간 눈금 있는 축(고정), 라벨 열(고정), 행 가상화(보이는 행만 그림).
- 줌: 버튼·핀치·ctrl+휠, 화면 맞춤. 그룹/서브트리는 Gantt 안에서 접는다.
- Work 클릭 → 선행·후행 사슬 강조 + 상세 패널. 화살표는 기본 "선택 사슬만".
- 상태는 아이콘+색(○ 대기 · ◐ 진행 · ● 완료), 라이트/다크 대응.
- CLI(인자·--ready·경고 출력)는 기존과 동일 — 규칙과 소도구는 그대로 쓴다.
